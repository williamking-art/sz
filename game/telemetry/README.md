# `game/telemetry/` —— 遥测（可选层）

> 上级规范：[`game/README.md`](../README.md)

## 职责

记录**运行时观测数据**（而非游戏状态）：结算耗时、AI 调用统计、异常计数等，用于开发期定位问题与调优。
**不参与游戏逻辑**，删掉不影响游戏运行。

| 文件 | 职责 |
|---|---|
| `store.py` | 遥测存储：SQLite（标准库 `sqlite3`，**零第三方依赖**） |
| `__init__.py` | 包说明（A2：SQLite 遥测存储） |

## 关键约定

1. **绝不进结算主链的强依赖**：写遥测失败必须静默吞掉（不能因为遥测把月度结算搞崩）。
2. **不存敏感真值**：写日志前过一遍脱敏口径（同 `game/ai/desensitize.py`）。
3. `.gitignore` 已忽略 `*.log` 等运行产物；遥测库文件不要入库。
4. 做性能排查时可读 `_dev_tools/game-dev/analytics/` 与 `replay/`（开发辅助，不入库）。
