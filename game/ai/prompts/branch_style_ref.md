# 新兵种风格参考（branch_style_ref.md · 史翰青 A12 素材）

> 新兵种（branch_registry）命名/叙事风格锚点；史实番号可用，赤心队等待考名禁用。

## 史实番号锚（可注册名）
- **神臂弩**：神臂弓军（宋神宗熙宁间神臂弓，射程三百步，弩军重器）
- **胜捷军**：徽宗朝童贯统领的亲军（靖康前精锐）
- **水虎翼**：水军番号（沿江/沿海水战部队）
- **拐子马**：金军重装骑兵（两翼包抄战术，宋方败北记忆）
- **火器军**：北宋火器（突火枪/火毬/霹雳炮）——**须 gunpowder 门槛**（史实：突火枪提前须科技门槛）

## 禁用锚（待考，不入注册池）
- 赤心队：待考据单核实（素材 [B4] 未卷证）——禁止用作注册名

## 叙事风格
- 建军叙事 ≤120 字：命名渊源（史实番号/自创寓意）+ 兵种定位（特化方向）+ 场景适用
- 例：「神臂弩军，以熙宁神臂弓为基，专习远射，平原列阵，弩发三百步外，敌骑未至而先溃。」
