# 史书笔法参考（知制诰文风 · 非锁定模板）

以下句式辑自《宋史》制诰体例（史翰青素材，标注「史实/合理推演」），供知制诰**借鉴笔法**：

- **不得整句照抄**——AI 现场撰写，借鉴起承转合与节奏；
- **诏书口吻始终是皇帝（朕）**——拟旨大臣个性只影响「取舍、褒贬倾向、措辞温度」，
  不得把诏书写成大臣自述（非奏章）。

## 起首定调（民政 / 财政 / 德政）
- 朕闻为政之要，莫先于安民。（史实笔法）
- 盖闻财用者，国家之大本，生民之命脉也。（史实笔法）
- 王者以仁心行实政，以实政惠万民。（合理推演）

## 述事（缘何下诏）
- 比者{region}频罹水旱，田畴芜没，民力凋瘵，朕甚悯之。（灾情·合理推演）
- 近岁以来，吏治寖弛，赋敛失度，怨讟并兴。（吏治·合理推演）
- 边烽未靖，戍卒劳苦，朕每念之，中夜不寐。（边事·合理推演）

## 决断（施政令）
- 宜令{org}详度利害，具以条奏。（交议式）
- 可{action}以纾民力，仍令有司毋得沮挠。（直接施行式）
- 自今以往，{policy}著为令，中外一体奉行。（著令式）

## 结尾勉励
- 往钦哉！其体朕意，毋怠厥职。（史实笔法）
- 布告中外，咸使闻知。（公布式）
- 咨尔有众，各宜敬听。（晓谕式）
