# content/ministers/paperdoll — 北宋官员 2D 布娃娃换装

> **2026-10-21 新建**：本目录是**代码模块**（不只是资产），此前无 README、也未在上级索引中单列。
> 设计基线见 `_dev_tools/game-docs/docs/百官换装系统_v4设计稿_2026-10-17.md`（**未落地**，v3 已作废）。

## 模块职责

| 文件 | 职责 |
|---|---|
| `__init__.py` | 公共入口：导出数据模型、注册表、渲染引擎与召对控制器 |
| `model.py` | 数据模型/契约：插槽、绝对 Z 序、锚点、`FaceDNA`（7 维五官）、情绪状态机、`MinisterAudienceProfile` |
| `registry.py` | 资产注册表：3 套素体 + 7 维五官库 + 8 大装备插槽；按姓名/生年/籍贯/特质确定性派生 Visual DNA |
| `engine.py` | 装配/渲染引擎：自底向上 10 层严格叠加、810×1080 画幅、PNG 输出；素材源为烘焙后的 2D 工笔图层（PNG RGBA） |
| `controller.py` | 召对/廷辩控制器：JSON 配置驱动展示、Live2D 式微动态、AI 情绪联动、品色/鱼袋随升迁自动换装 |
| `rules.py` | 公服规制校验：品色（绿/绯/紫）、借绯借紫、佩鱼、禁忌（补子/龙纹/清制顶戴等）拦截 |

## 素材与配置

- `configs/`：JSON 配置（素体/装备/召对档案等）；`layers/`：分层 PNG 素材；`samples/`：样例输出。
- 素材生产管线与定格标准见 `docs/百官换装系统_v4设计稿_2026-10-17.md`；**v4 未落地前，本目录代码与素材
  只作可运行原型，不得当成游戏内已上线功能**。

## 边界

- 只读 `content`/` ministers` 数据与 `assets` 素材；**不写游戏状态、不改数值、不参与结算**。
- 前端召对面板通过后端/API 取图或配置；**不得**在前端复制本目录的坐标/规则算法。
- 立绘/换装是表现层：缺失素材时降级为占位，不得用随机立绘冒充指定人物（缺失≠臆造）。
