# 大臣立绘生成规范（分层管线）

> 目的：新增大臣时，**照本规范出图即可有机融入既有 42 人体系**，不需要改代码、不需要手工对位。
> 一键复现：`python game/content/ministers/layers/_lay2.py`
> 复核：`python game/content/ministers/layers/_src/_verify_layers.py`

---

## 一、体系结构（为什么是分层的）

立绘 = **官服层**（姿态 × 服色，共 4×6=24 张）⊗ **头部层**（每人 1 张，共 42 张）。

两层分开的原因：官级会变（升贬换服色），人脸不会变。分层后「换官服」只是一次贴换，
不用为每个官级重画一张人脸。合成由 `data.py::compose_portrait()` 完成，带缓存。

```
layers/body_{pose}_{tier}.png   官服层：全不透明，绢底背景由它提供
layers/head_{name}.png          头部层：背景透明（绢底不可见），底部渐出
layers/_offsets.json            各姿态头部质心相对正立的偏移，合成时平移头部对位
```

## 二、硬性技术参数（出图必须满足，否则管线接不住）

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 810×1080（3:4） | `ratio 3:4`，`size 1K`，管线内统一 `resize` |
| 绢底色 | ≈ `#C4A877` (196,168,119) | **全部官服层与立绘必须同色同纹**，否则叠合处显色差 |
| 人物朝向 | 正面、半身（头+颈+肩+胸） | 头部层与官服层按同一构图裁切 |
| 头顶（冠顶）位置 | y ≈ 0.10H（约 108px） | 太高会被裁切，太低则头部层压到衣领 |
| 头部质心 | y ≈ 0.18H，x ≈ 0.50W | `_offsets.json` 依赖此基准测量 |
| 肩线 | y ≈ 0.40H（约 432px） | 头部层底部渐出带 0.44H–0.62H 需落在此之下 |
| 左右留白 | 人物主体不触左右边 | 管线会做边缘列延展消伪影，触边会被拉伸 |
| 头部质心跨姿态偏移 | **≤ ±30px** | 抹除带（见五）按此带宽设计，超界会残留 |

## 四、图生图：其余三姿态（每服色各 3 张）

从**同服色基线**出发做 i2i，**只改姿态**：

```
保持人物面容、年龄、官服颜色、幞头形制、构图、人物大小与位置、绢底纹理完全不变，
仅将姿态改为{姿态}：{姿态描述}。其余一切不变。
```

| 姿态 | 档键 | 描述 |
|---|---|---|
| 正立 | `zheng` | 双手垂于身侧（= 基线，无需生成） |
| 拱手 | `gongshou` | 双手于胸前合抱 |
| 持笏 | `chihu` | 双手捧笏板于胸前 |
| 拢袖 | `longxiu` | 双手拢于袖中，垂于腹前 |

**三条铁律**（违反则头部层无法对位）：
1. 不得改人物大小与位置——头部质心偏移必须留在 ±30px 内（实测：拱手 +25.8/+16.8，持笏 −9.1/+5.8，拢袖 −8.8/+20.9）。
2. 不得改绢底——背景是官服层提供的，24 张必须无缝互相替换。
3. 不得改幞头形制——冠形一改，头部层叠上去就会「双帽」。

产出落盘为 `layers/_src/_base_{tier}.png`（正立）与 `layers/_src/_pose_{pose}[_{tier}].png`。

## 五、后处理（脚本自动完成，此处仅解释为何必须）

### 5.1 官服层「净身」——擦掉官服层自带的头/帽

官服层出图时**必然自带一个头和幞头**。但最终头像是头部层提供的另一个人头——
两顶帽形不同，叠起来就是「双帽 / 帽翅残留」（拱手姿态下最刺眼，因为头部被平移了 26px）。

所以管线按官服层自身前景提取头部轮廓并擦成绢底，再由头部层覆盖：

- `y < 0.36H` 全宽擦除 → 冠顶、脸、颈
- `y 0.36–0.45H`、`x 0.22–0.78W` 擦除 → 帽翅下尖（实测残留在 y≈0.43–0.45H）
- **不越过 0.45H** → 头部层自 0.44H 起渐透明，擦到胸口会露出空白造成「发白」
- 填充用**逐行左右镜像铺展**（就地取自掩膜边界外的绢底），边界天然连续、无接缝
- 前景阈值 `TOL=26`：过低会把整片绢底纹理误判为前景

> 推论：**官服层不需要画好头**——画了也会被擦掉。把精力放在颈部以下的衣纹、革带、袖型。

### 5.2 头部层抠图

`portraits/{名}.png` → 连通域清理：阈值取前景 → 只保留含头心的最大连通域（丢弃绢底纹理碎斑）→ 填洞 → 羽化。
保留连通域是必须的：旧版全局阈值会把绢底纹理留成半透明 ghost，在洋红底上一望即知。
另加「内部保实」（腐蚀核心区强制 alpha=1），否则幞头翅这类**细薄结构**会被高斯模糊洗成半透明。

## 六、新增大臣 SOP

1. **出立绘**：按第三节出 `portraits/{名}.png`（810×1080、3:4、正面半身、绢底同色、头顶 y≈0.10H）。
   已有成品图也行，只要构图接近。
2. **跑管线**：`python game/content/ministers/layers/_lay2.py`
   —— 自动完成：生成官服层 → 测姿态偏移 → 净身 → 抠头部层（42→43 张）。
3. **复核**：把新人名加进 `layers/_src/_verify_layers.py` 的 `names` 列表后运行，
   肉眼确认无 ghost 帽檐、无灰月牙、无边缘条带。
4. **建档**：在 `content/ministers/data.py::MINISTERS` 追加一条
   （`born / role / faction / traits / nobility / rank / portrait="" / in_office / loyalty / corruption`）。
   **姿态与服色无需配置**，自动派生：
   - 服色 ← `rank`（`rank_tier()`；`in_office=False` 留空品级 → 士人襕衫；宗室 → 亲王）
   - 姿态 ← `minister_pose()`（军将/近臣→持笏；≥58 岁老臣→拢袖；言官→拱手；其余按姓名哈希定正立/拱手）
