# `game/audio/` —— 音频（骨架 + 可选 TTS）

> 上级规范：[`game/README.md`](../README.md)

## 职责

音频资源清单与**可选**语音合成（大臣朗读）。当前是**规划性骨架**：功能可缺失，缺失时静默降级。

| 文件 | 职责 |
|---|---|
| `manifest.py` | **音频资源清单**（规划性骨架）：音频文件与用途的映射 |
| `tts.py` | **大臣语音朗读**：`edge-tts` **可选层**，非阻塞（不可用时不报错、不朗读） |
| `__init__.py` | 包说明（规划性骨架） |

## 关键约定

1. `edge-tts` 是**可选依赖**：导入/调用失败必须静默降级，绝不能让它影响结算或启动。
2. 音频资源本体放 `game/assets/audio/`（当前为空骨架）；本目录只放**清单与逻辑**。
3. 合成产物是**缓存/产物**：不要入库（`.gitignore` 已覆盖常见音频产物目录；新增请补规则）。
