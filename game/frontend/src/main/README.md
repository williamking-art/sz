## 🔴 纪律

- 🔴 **token 不进渲染进程**（P1-10）：由主进程 `webRequest` 拦截注入 `Authorization`，
  渲染进程拿不到凭据。改网络层时不要为了方便把 token 传到 `renderer/`。
- 后端地址/端口在此解析后传给渲染进程，**不要在渲染进程里再写一份**。
