# renderer/utils — 展示层工具

> 纯函数工具。**只做展示层转换，不含业务判定**。

## 文件（3 个）

| 文件 | 行 | 职责 |
|---|---:|---|
| `effects.ts` | 155 | 事件 effects → 中文描述 / 吉凶判定 |
| `format.ts` | 47 | 展示层格式化，**对齐 `game/ui/gui_common.py`**，保证双轨数值表述一致 |
| `portrait.ts` | 22 | 立绘 URL 统一解析（2026-09-19 整改；2026-09-27 修 `app://` 打包态） |

## 纪律

- `format.ts` 是**前后端数值表述的第二轨**。改它必须同步核对 `game/ui/gui_common.py`，否则同一数值在界面与后端说话不一致。
- `portrait.ts` 同时要处理**开发态与 `app://` 打包态**两种 URL 形态 —— 2026-09-27 刚修过一次，只改一边会导致打包后立绘全裂。
- `__tests__/` 有 3 个用例（effects / format / portrait），改这三个文件**必须跑**。
