# renderer/hud — 常驻 HUD

> 全屏常驻的信息层：顶栏、左右侧栏、地图题签。宣纸卡片 + 描金标题。

## 文件（5 个）

| 文件 | 行 | 职责 |
|---|---:|---|
| `TopBar.tsx` | 355 | 顶栏（核心读数） |
| `Dock.tsx` | 199 | 入口坞 |
| `RightStrip.tsx` | 183 | 右侧竖排信息条 |
| `LeftTodo.tsx` | 81 | 左侧常驻**在办栏**：宣纸卡片，描金标题「在办」 |
| `MapCartouche.tsx` | 22 | 地图题签：让全屏地图拥有自己的标题与纪年，**不占用地图交互** |

## 纪律

- **`MapCartouche` 是纯展示层**，加交互会与地图手势冲突 —— 要交互请走 `map/`。
- HUD 读数一律**来自 store/API**，组件内不要自己算（口径单点）。
- 缺失读数显示「**未定义**」，不回落 0/1.0 假装无事（根 `AGENTS.md §3-3`）。
