## 🔴 纪律（`frontend/AGENTS.md` 禁区）

- 🔴 **React 层不复制结算算法**：读数算法单点在 `core/`，后端只做薄壳，这里只发请求。
- 🔴 **不得仅在界面端造默认值**：改接口字段须同时核对
  ①后端序列化/API ②TS 类型 ③组件测试；缺失值一律显式呈现「未定义」，**不得回落 0/1.0**。
- 新增端点时**后端与本文件同时改**，两边不一致就是静默错误。
