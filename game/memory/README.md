# `game/memory/` —— 记忆层（对话记忆 + 记忆图谱）

> 上级规范：[`game/README.md`](../README.md)

## 职责

给"人"（皇帝/大臣/朝局）**留下可追溯的历史**：谁在什么时候说过什么、做过什么、关系如何演变。
供 AI 叙事取上下文、供 UI 展示"前情"，以及支撑"大臣记得你上次怎么对他"。

| 文件 | 职责 |
|---|---|
| `dialogue_memory.py` | **对话记忆库**：召对/对话的存储与检索（供后续 prompt 拼上下文） |
| `memory_graph.py` | **记忆知识库**：Phase 3a 升级为 **SQLite 数据库化**（一轮游戏 = 一个 SQLite 库），记录事件/关系/兴衰 |

## 关键约定

1. **落库不在结算主链上做重活**：记忆写入要容忍失败（缺库/锁库时不阻断月度结算）。
2. **一轮游戏一个库**：库文件生命周期与存档绑定；读档时应能对应到正确库（不要跨局串记忆）。
3. **AI 只读不放真值**：给模型的上下文请走 `game/ai/desensitize.py` 的档位化，不要把国库/内帑真值写进记忆再喂给模型。
4. 记忆是**可丢**数据（丢了不影响账本），所以不要把权威数值只存在这里（POP 挂载律：账本在 POP/国库）。
