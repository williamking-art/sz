## 一、盐课 / 酒课史实量级

史实锚：熙宁十年（1077）赋税统计（<宋史·食货志>体系）：
- 榷盐、茶、酒（税钱）合计 1583.6万贯/年，占货币岁入 27.7%
- 酒课单独约 1010-1311万贯/年（《文献通考·征榷考》：东京一州酒课即 40万贯+）
- 榷盐净利约 700-900万贯/年（庆历后）

裁决：
- **SALT_COIN_BASE = 50万贯/月（600万贯/年）**，折史实榷盐净利约 70%；因游戏"工商+二税折色"科目已隐含部分榷货收入，不重复计满。
- **WINE_COIN_BASE = 10万贯/月（120万贯/年）**，仅取史实酒课 ~12% 作为"内帑净入"——史实酒课多数归地方军资库，进内帑者本就是小头。
- 上调后回放货币岁入年化约 4060万 → ~4700万贯，仍落在"全口径 3000-5000万贯"区间内。

## 二、grain_yield 双口径与太仓平衡

回放实测（12 个月）：太仓 1879-1941万石 稳定，cap=2000 常年近满；月粮产本色读数 406万石/月，月出军粮 162.5万石/月 + 官吏粮 ~0.04 → 净盈余被 cap 截断。
- **结论：LAND_TAX_RATE_BENEFIT=0.10 下太仓是"满仓"而非"枯竭"**。team-lead 顾虑的"本色104×arrival<80"基于旧写死 MILITARY_GRAIN_MONTHLY，实际军粮公式算出的 162.5万石/月仍被满足。
- 建议保持 0.10（防灾/战缓冲可提至 0.12），GRANARY_START_CAP=2000、DISASTER_RELIEF_GRAIN=20 保留作太仓消耗口。
- 双口径裁决：land 层（46000万亩×1.0=46000万石/年）为"垦田总产"；州层（Σgrain≈11750万石/年）为"税粮基础"。**锁年单位下以州层为税基、land 层为产量参照是自洽的**，二者相差 3.6 倍属正常（总产 vs 可税粮）。

## 三、俸禄 / 兵费史实佐证

- **OFFICIAL_PAY_PER_MONTH=30**：史实有品官员约 2-4万，月俸中位数 15-30贯（宰相300/枢密200/县令20-30），岁支官俸约 500-700万贯。30 取中位偏上，合理。
- **重大发现（量纲 bug 实证）**：回放中 officials=13.0(万)、clerks=104.0(万)，但官禄公式 ÷10000 → 官禄 0.02万石/月、官俸 0.0万贯/月，俸禄轴读数失真。若字段按"万人"计，13万官×30贯=390万贯/月，超史实 3-6 倍。**待 audit-core 裁决字段语义**（officials 改 2-4万 或 保持13万 但调 OFFICIAL_PAY_PER_MONTH 至 8-10）。
- **SOLDIER_PAY_PER_MONTH=0.5**：禁军料钱 0.3-1贯/月、厢军 0.2-0.5贯/月，0.5 为禁厢均值，合理。garrisons=75万×0.5=37.5万贯/月（450万贯/年），史实军俸约 1200-1500万贯/年，游戏取 1/3——军费大头在粮，粮轴 162.5万石/月=1950万石/年 与史实军粮岁支 ~2000万石 吻合。
- **CLERK_PAY_PER_MONTH=2.0**：胥吏月给 0.5-2贯，2 为上限，偏高但可留。
- **SOLDIER_GRAIN_PER_MONTH=2.0**：禁军月粮 2-2.5石，合理。

## 四、grain_price 量纲

GRAIN_PRICE_MIN=0.4 / MAX=2.5 贯/石 即史实常平米价区间（丰 0.4-0.7、灾 1.5-2.5），回放实际 0.72-1.18 落在区间内，**"贯/石"自洽**；注释"石/贯"错位需改（audit-core 已标）。
