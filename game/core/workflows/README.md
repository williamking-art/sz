| 代码域 | 责任 | 现有候选 | 不负责 |
|---|---|---|---|

## 流程约束

提案 → 校验/确认 → 执行 → 结果回报。简单命令可跳过不适用步骤，但**必须有显式路径**。
命令入口不得私自复制业务规则。
