# foundation — 基础与账本层

> 2026-10-06 · 阶段 0（架构基线）· 本包为空骨架：未移动实现、未改 import

## 子包

- `state/` GameState、初始状态构建与状态字段注册
- `ledger/` POP/钱粮/物料权威账户与读写 API（含迁移期桥接）
- `persistence/` 存档读写与版本迁移
- `common/` numeric、errors 等无领域语义的共享工具

## 不变量（承架构方案 4.2）

1. POP 真账继续在**治所级**；路级 POP 是**只读派生聚合**。迁移不得改变挂载位置或下沉/聚合语义。
2. 钱、粮、商品保持**单一权威载体**；读数是派生结果，不创造第二本账。
3. **缺失、零、默认系数保持可区分**；迁移不得借重构补造默认值。
4. 存档升级只能**显式、幂等**迁移；兼容入口不得覆写已下沉的真账。

## 依赖

- 业务域可依赖 foundation；**foundation 不得反向导入业务包**（GameState 顶层不导业务模块，扩展用延迟装配）。
