# foundation/common — 无领域语义的共享工具

> 只放**真正无领域语义**的通用工具。判据：任何业务域都能用，且不携带任何玩法口径。
> 有领域语义的东西**不属于这里**（例如 `registries` 是领域注册表，故放 `foundation/` 顶层而非本目录）。
> 依据：架构方案 §6-5。

## 模块（2 个）

| 模块 | 行 | 职责 |
|---|---:|---|
| `numeric.py` | 116 | **数值工具单一权威**（5 个接口）。解析与换算的唯一出处，**别处不得再写一套解析** |
| `errors.py` | 22 | 核心错误类型 |

## 纪律

- **先查这里有没有，再定义新的通用函数**；重复的解析/换算逻辑是口径分裂的源头。
- 业务域之间共享的**领域**逻辑不属于本目录——那属于 `foundation/` 顶层或某个 `domains/*`。
  判不准时，看它是否携带玩法含义：携带 ⇒ 不属于 `common`。
