# 《宋祚》游戏机制说明

> 北宋徽宗朝（1101 起）AI 驱动历史推演策略游戏。本文档基于 `game/` 源码实勘整理（2026-08 更新），描述当前版本的真实机制。新机制已**融合进各对应章节**，本节仅给架构总览。
>
> **产品定位（用户定稿）**：模拟一个穿越者（玩家），通过跟大臣的对话、发布圣旨（政策），来改变历史进程（北宋徽宗朝）。**AI 是游戏的核心引擎**——所有机制都通过 AI（agent）推演驱动，harness 保证稳定与编排，程序负责数值/守恒/校验。

---

## 〇、AI 驱动架构总览

- **三层**：Harness 层（骨架：确定性/错误分类 6 码/动态工具注册/叙事数值校验）+ Agent 层（引擎：12 步推演层每步一个 agent + persona + 记忆知识库 + 自设工具）+ 程序层（身体：结算守恒 + free_effect 契约 + query_state 按需查询）。
- **核心原则**：AI 只做「判断+叙事」，可确定的计算本地化；**AI 保混沌**（推演有意外/趋势）；**记账对应**（每笔钱粮来源=去向，不凭空造灭，非总量守恒）；**AI 缺失 → 不执行 + 明确报错**（6 错误码），绝不伪造。
- **省 token**：按需查询（召对基础注入 ~120 字符，较全量 -98%）、本地计算优先、档位词 7 档（无/微/小/中/大/巨/极 + 丰富表达归一 + 正负方向）。
- 详细机制融合见各章：月度结算（§二）、诏令（§三）、经济（§四）、派系人事（§六）、事件（§七）。

## 一、游戏定位与基本框架

- **起点**：1101 年 1 月（建中靖国），玩家扮演宋徽宗赵佶。
- **回合制**：以"月"为基本结算单位，`run_monthly_settlement()` 每回合按 11 步流水线结算。
- **三种难度**：史实（默认）/ 轻松 / 艰难，参数见 `DIFFICULTY_PRESETS`（威望起点、到账率、事件压力倍率、外部势力发育倍率等）。
- **目标**：不是固定胜利条件，而是"活下来并留下好结局"——结局由七维评分决定（详见第九节）。

### 核心状态（GameState）
| 维度 | 关键字段 | 说明 |
|------|---------|------|
| 时间 | year / month / turn / era_name | 年号按史实推进（崇宁 1102、大观 1107、政和 1111、重和 1118、宣和 1119） |
| 皇帝 | emperor_health(75) / art_mastery(85) / taoism_leaning(25) / pleasure_leaning(30) | 健康与三项个人倾向 |
| 皇威 | prestige(55) | 0-100，权威/执行率的全局乘数 |
| 财政 | treasury(500万贯) / imperial_treasury(100万贯) / granary(1500万石) | 国库、内帑、太仓三账分理 |
| 民生 | population(8000万) / population_satisfaction(55) / 各路 refugees | 全局民心 + 各路流民池 |
| 派系 | factions{} | 各派系 influence/satisfaction/cohesion |
| 军事 | army_units[] / defense_lines{} | 兵额唯一真账（实体列表）+ 防线聚合 |
| 机构 | yamen{} / central_orgs{} | 六部衙门 + 中枢机构（权限/效率/积压） |
| 地方 | prefectures{} | 各路州县：户数/田亩（五类归属）/粮产/民情/治理/动乱/粮价 + 六类 POP 明细 |

## 二、月度结算流水线（agent 化）

每回合 `run_monthly_settlement()` 顺序执行；**推演层由 agent 驱动**（经济/清丈/外交/军事/事件/灾荒），**守恒/数值步保持程序本地**（agent 只给档位词，数值程序换算封顶，绝不触碰守恒数值）：

1. **Step 0 破产兜底**：国库 < -2000 万贯 → 直接"国用耗竭"游戏结束；国库 < -500 万贯 → 触发"库藏空虚"危机事件（增商税/裁冗费/发内帑/卖度牒 四选一）。
2. **Step 1 诏令执行**：按执行率逐条执行待办诏令（见第三节）。
3. **Step 2 派系结算 + 大臣立场演化**：凝聚力/满意度/影响力小幅随机漂移；势力悬殊 > 40 → 党争减威望；**每大臣立场按程序公式演化**（派系满意度 0.25 + 影响力 0.15 + 事件 0.25 + 皇威 0.15 + 民心 0.10 + 国运 0.10 × 性格调制），家产随 corruption 膨胀。
4. **Step 3 经济基础（推演官）**：人口自然增长；各路流民按民情/动乱/治理吸纳回人口；**economy_decide**（agent）推演景气/士绅/生产/窖银/城市化/回乡/科举 + **5 金融字段**（交子信任/钱荒/市舶/银行/物价趋势）→ 程序换算落地。
5. **Step 3.5 田亩地方（按察使）**：粮产率随科技演进；荒田开垦；隐田率缓慢回升；田亩归属与士绅隐田流转；**survey_settle**（agent）清丈隐田/抑兼并 → 退田/抄没；田赋本色入太仓、折色入国库；粮价/物价全盘重算。
6. **Step 3.6 扩展维度 + 金融调制**：交子信任度/市舶关税/科举人才池/科技水平自然演进 + 研发管线推进；**经济金融 AI 档位落地**（交子/钱荒/市舶/银行/价格系数）+ **投资回报分期**（settle_investments）。
7. **Step 3.7 长期政务 + 外部政权模拟（史官/使节）**：在办公开事务/密令按进度推进（**记忆图谱写 progresses**）；外部政权按发育曲线成长；**diplomacy_decide**（使节 agent）推演外交态度/岁币/盟约。
8. **Step 3.8 仓廪漕运**：漕运汇聚（受漕路阻塞影响）、雀鼠耗、本色俸禄支取、常平仓平抑粮价、经济认知层更新（守恒步，agent 不碰）。
9. **Step 4 财政**：货币税收入（工商+役钱+市舶+二税折色+盐课）vs 支出（常支+折色俸禄+岁币+**大臣家产划转**+**建筑维护费**），结余/亏空入国库，内帑抽成（守恒步）。
10. **Step 4.5 工程/作坊/建筑**：七维物资工程逐月推进（**政府建筑**建造/升级）；粮→酒等作坊配方生产；**POP 建筑**乘数生效；**大臣家产**奢侈消费/窖藏（→工匠商人/钱荒）。
11. **Step 5 国库**（空操作，Step 4 已结算）。
12. **Step 6 军事/外交（枢密）**：金/辽/西夏势力成长或受历史改写位抑制；军队训练自然衰减；**military_decide**（枢密 agent）推演训练/兵额/征发（程序守恒扣款）。
13. **Step 6.5 历史改写位评估**：检测"灭金于萌芽/联辽抗金/避免靖康"达成条件 → 写入待确认（须朱批）。
14. **Step 6.8 五层承接层**：机制槽（加成/减耗）、研发管线、机构经济生命周期。
15. **Step 7 事件压力（史官）**：各事件类别压力累积，达阈值触发；**事件叙事经来源闭集**（只从本回合真实来源取材）+ 人物校验表（生死/去留核对）。
16. **Step 8 灾荒（按察使）**：既有灾荒持续（开仓赈济）；3% 概率新发灾荒；**relief_decide**（agent）推演赈济/流民（程序守恒扣太仓）。
17. **Step 9 皇帝个人**：上月临时带宽过期回调；个人行动效果结算；自然衰老。
18. **Step 10 隐藏状态**：民怨激变、金军南侵判定与战斗、皇帝健康衰减。
19. **Step 11 记录 + 记忆写入**：结算日志入档，turn+1；**史官把本回合决策/事件/立场写入记忆图谱**（跨回合连贯）。

## 三、诏令系统（核心玩法）

### 执行率公式
```
基础率 = 0.45 + 净支持×0.08（正式诏） | 0.30 + 忠诚×0.7（密旨） | 机构归属率（中旨）
净支持 = Σ(派系立场 × 影响力/100)
最终 = clamp(0.05~0.95, 皇威乘数 × (基础率 - 派系冲突×0.15))
```
- **御笔直发**：绕过会签，执行率 +0.10；"狼来了"≥3 次后转 -0.15。
- **中旨（御笔强推）**：按机构归属执行率（内廷 1.0 / 政府 0.85 / 地方 0.60）。
- **密旨**：失败时 20% 概率泄露 → 威望 -3。

### 诏令类型
| 类型 | 说明 |
|------|------|
| 正式诏（经会签） | 门下省封驳已消化冲突，执行率略稳；流程 preview_draft → issue_edict_from_review（approve 批准 / force 转中旨）→ merge_drafts 汇纂 / reject_edict_draft 打回 |
| 密旨 | 暗中推行，上限 3 条，失败有泄露风险 |
| 口谕 | 即时、不占带宽，效果 ×0.6（KOUYU_EFFECT_MULT），30% 走样降档（KOUYU_DRIFT_CHANCE）；**内帑口谕调拨**（商量确认式）：召对中口谕「发内帑 X 万入国库」→ 记 pending → 当场点「准」守恒划账（propose/confirm/cancel_inner_transfer，金额自填精确，乾纲独断不受弱效/走样约束） |
| 中旨/御笔 | 绕过会签强推，耗带宽；御笔直发每月 ≤2（direct_decree_used），触发 wolf_count 公信力下降 |
| 长期政务 | duration>0，逐月推进满进度核销 |

|------|------|
| 安抚 | 满意度 +4 |
| 施恩 | 满意度 +7、权势 +2，国库 -20 万贯 |
| 试探 | 满意度 -2 |
| 调拨军权 | 权势 +3 |

| 领域 | 事务清单（效果经 AI 档位结算，非固定值） |
|------|-----------------|
| 地方 local_policy | 劝农 / 赈灾 / 平盗 / 减税 |
| 外交 diplomacy_policy | 联金抗辽 / 通好辽国 / 绥靖西夏 / 备边严守 / 遣使修好 |

| 改革 reform_policy | 更役法 / 方田均税 / 整顿吏治 / 抑兼并 / 宽恤民力 / 核实军籍 等 |
| 科技 science_policy | 火药军用 / 兴水利机械 / 改历法 / 奖百工 / 聘西洋匠 / 设机器局(需 west≥2 且 level≥85) / 开矿炼油(west≥3) / 架设电线(west≥4) |

| 工程/作坊 | start_project（七维物资工程）/ start_workshop（配方作坊）——commands_policy 现仅保留这两项起手式 |

另有个人行动 do_personal_action、大项 choose_major_policy，以及行政区更名 `_apply_rename`。

### 拟旨类别（AI 解析）
`decree_parse` 把自由文本分类为六类：
- `fixed_tech`（科技营缮）/ `fixed_finance`（钱粮调度）/ `fixed_army`（军队调动）/ `fixed_construction`（工程建设）——四类固定程序，参数模板化；
- `free_edict`（自由推演）——**经 free_effect 契约落地**：AI 推演效果（once 一次性 / ongoing 长期制度，白名单 13 字段 + CAP + 拒绝式），程序校验后落地；**AI 缺失/失败 → 诏令不执行 + 明确报错**（不降级、不伪造）；
- `reform_org`（机构改制）。

### 自由动作（free_effect 通用契约）
程序无现成机制的动作（修路/修水利/识字营/养老/服役年限/派老兵做村长等）都走同一契约：**AI 推演历史效果（方向+量级）→ 程序映射到既有字段（govern/mood/training/morale/defense/canal/grain 等）→ 校验落地**（白名单 + CAP + 成本 ≤ 存量 + 拒绝式）；长期制度走 `longterm_effects` 队列（每月结算、duration 递减、0=永久、国库不足暂停不静默消失）。

### 大臣自设工具
大臣 agent 理解玩家对话 → 无现成工具时**自己定义新工具**（{名称, 参数 schema, 效果模板}）→ harness 校验注册（`tool_registry`：名称白名单/字段白名单/CAP/成本 ≤ 存量/上限 16）→ 后续复用；注销 active=False；执行走 free_effect 拒绝式（AI 无直写权）。

### 诏令效果键（白名单）
prestige / treasury / imperial_treasury / population_satisfaction / external_jin|liao|xixia / defense_bonus / faction_change / single_whip / pay_reform / commerce_tax / curtail_waste / reduce_office / granary_reform / canal_dredge / anti_corruption / relief / he_mi / land_survey / military_supply / settle_refugees / grain_stabilize

### 关键政令效果
- **一条鞭法**：田赋改征折银入国库（不动本色账，避免双计）。
- **俸禄改制**：本色折色/仅发钱/一体发钞/仅本色，改变俸禄发钱发粮比例；"一体发钞"增发交子但降信任。
- **工商征率**：可调 0.05~0.30；≥0.30 民心 -4（重榷），≤0.10 民心 +3（薄征）。
- **省浮费/裁汰冗员**：12~18 个月渐进挤出浮费，月省 5~15 万贯，启动减威望 2。
- **方田均税**：清丈隐田，旧党/东南士人满意度 -5。
- **赈济/和籴/入中军需/平准**：太仓粮与国库钱的互转，平抑粮价。

## 四、经济系统（钱粮双轨 · POP 化）

### 0. POP 人口经济底座（第四代重构）
- **六类人口** `POP_TYPES`：农 / 士绅 / 工匠 / 商人 / 官僚 / 兵。每路 `prefectures[路].pops` 内含 size（人口）/ wealth（家资）/ grain（存粮）/ goods（存商品），钱粮物资守恒闭环；全局 `population`（8000 万）与 `population_satisfaction`（55）为总账口径。
- **田亩归属五类**：自耕田（农）/ 地主田（士绅）/ 官田 / 皇庄（免赋）/ 隐田（逃税）。田赋按田亩归属征收。
- **土地兼并** `_transfer`：自耕农→士绅每月自然转移约 0.1%；**诡名寄产** `_conceal`：地主田→隐田，随"东南士人"派系势力增减。
- **士绅藏富** `_settle_civilian_hoard`：士绅低买高抛囤粮，抛售 50% 入**窖银**（藏富）、50% 入流通；no-AI 兜底 0.5%/月被动回流（有 AI 由档位决定）；窖银只藏铜钱、不藏交子。
- **职业流动**：工匠/商人与农之间随工商景气城市化、萧条回乡。
- **商品市场**：工匠产商品，各 POP 按阶级需求（`GOODS_DEMAND`）消费，商品月折旧 3%。
- **兵额回填**：月度结算末按 `army_units` 唯一真账回填兵 POP 规模。
- **经济金融 AI 介入**：`economy_decide`（推演官）输出 5 金融字段——交子信任（增/稳/跌）、钱荒（缓/平/加剧）、市舶（兴/平/衰）、银行（扩/稳/损）、物价趋势（通胀/平/通缩），三态词白名单（缺失/非法→拒绝式）；程序按 `FINANCE_DECIDE_BASE` 换算记账（交子 trust±5/issued+100万 受可发额度约束超发触发崩溃、钱荒 shortage±0.05 联动税负、市舶 tariff±0.02/silver_in±10、银行仅 established、价格系数±5% 月度重置）——AI 只给方向档（混沌），数值程序换算封顶（记账对应不凭空）。
- **大臣家产**（`state.minister_estate`）：具名大臣拥有钱（family_wealth）+ 田（family_land），1101 开局基线（蔡京 3万/800 殷实起步、陈瓘 0.5万/80 清贫）；月膨胀 = 家产×(俸禄 1‰ + corruption×5%)，封顶 5000 万；**钱的循环**——俸给划转入家产、奢侈消费（→工匠/商人）、聚敛窖藏（→钱荒）、抄没（→国库）；**田的循环**——收租（并入 gentry_land）、田赋/免役钱、兼并（→隐田→清丈打击）、抄没（→官田）；家产档位词（清贫/小康/殷实/豪富/巨富）脱敏，玩家/AI 只见档位；聚敛膨胀超阈值 → 「物议」事件（抄没/留任/贬黜）；persona 阈值（≥100万 怕抄没危险度+0.15、≤5万 敢谏+15%）。
- **建筑系统**（政府 + POP，Lv1-5 ×1.5/级，封顶 ×2.0）：政府建筑（朝廷建、国库投，复用 `projects` 工程系统）——水利（粮产×）/常平仓（籴粜×）/官营作坊（workshops 产出×）/官署（govern×）/军营（驻防×）/学校（人才×）；POP 建筑（阶层建、阶层投，路级 `buildings`）——农田（农，粮产×）/工坊（工匠，工商×）/商铺（商人，贸易×）/庄园（士绅，田/窖藏）；建造成本 ×1.8^(Lv-1)、维护费 ×0.5%/月、雇佣 POP（建造期工匠/商人 POP +0.5%/0.3% 完工回落）；效果=对既有公式的乘数，数值走既有公式保守恒。
- **投资机制**（`invest_decide` 复用 free_effect 载体）：国库（会签）/内帑（乾纲独断）投入 → AI 推演回报档位 + 风险档位 → 程序记账（投入减 → 回报按六领域基准×力度档位分期进产出 → 风险亏本 → 贪腐截留进大臣家产）；投资→产出→税收→再投资闭环；四账闭合守恒断言。

### 货币与物价（钱/物之比）
```
物价水平 = 基准1.0 × (货币有效供给 × 流通速度1.8 / 实物经济总量)
货币有效供给 = (Σ各路 POP 财富 + 国库 + 内帑 + 有效交子 + 白银折钱) × (1-私熔)
```
- 钱荒（coin shortage）越高 → 纳税系数越低（0.75~1.25）。
- 粮价 = 物价 × 季节（4-7月青黄不接 +15%、9-11月秋收 -10%）× 灾害(1+灾级×0.5，1~5 级 → ×1.5~×3.5)。
- 区域粮价 = 全国粮价 × 本地供需比（人均月需 **0.5 石**，另含隐户吃粮、酒耗粮、士绅囤粮挤压、POP 存粮释放）。
- 常平仓：粮价 > 1.6 粜粮抑价；< 0.6 籴粮托市。

## 五、军事与外交

### 军事
- **兵额唯一真账** = `army_units` 实体列表（每实体：军籍 tier / 兵种构成 branches / 兵额 / 士气 / 训练 / 驻地 / 防线 / 装备）。
- **军队结构（每路禁/厢/乡各一支）**：12 路 35 支军队（东京乡兵=0 跳过），每支军队单一军籍（禁军/厢军/乡兵）、内部混合该军籍的多个兵种（branches = {兵种: 人数}）。
- **兵种 7 类**（不带军籍）：重骑兵/轻骑兵/重步兵/轻步兵/弓弩兵/器械兵/水军；同名兵种不同军籍粮饷/装备标准不同。
- **粮饷按兵种**（`branch_std` = BRANCH_BASE × ARMY_RATE）：禁军 ×1.0 / 厢军 ×0.55 / 乡兵 ×0.35；禁军重骑 2.0石/0.5贯、厢军轻步 0.8石/0.21贯、乡兵 0.5石/0.13贯；**乡兵自备**（太仓只实发禁+厢，乡兵缺口自备不造粮）。
- **装备按人头**（EQUIP_STD × EQUIP_RATE）：禁军 100% / 厢军 60% / 乡兵 40% 配给；军队级 equip = Σ(兵种人数 × 人均配给)。
- **宋制番号**（ARMY_ORG）：禁军「神勇左厢第1军」（上四军捧日/天武/龙卫/神卫 + 各司军号）、厢军「路+役种」（河北清务/陕西山场）、乡兵史实名（河北弓箭社/陕西义勇）。
- **素质分档**（UNIT_TIER）：train_base / morale_base（粮饷系数已退役，改 branch_std 按率）。
- **火器代际**：突火枪 → 燧发枪，按 gunpowder 技术值分代（20 / 40 / 65 / 85 门槛），放大战力。
- **战力** `_army_power`：由兵额 × 军籍素质 × 装备 × 士气训练派生，火药科技放大。
- **防线 4 条**：北线_太原真定、北线_陕西等，`fortification`（工事 0-100）+ `garrison`（兵额聚合）。
- **战斗** `_resolve_battle(我方战力, 敌方战力)`：返回胜败/损耗/是否破防；战损按各部队战力占比分摊成真实伤亡。
- **军事 agent 推演**（`military_decide` 枢密）：训练/士气 ±2~±6、兵额 ±1万~±5万（CAP 5万）、征发 cost 10万~50万——agent 只给档位，数值程序守恒扣款。

- 月度/事件/结局：monthly_report（起居注月报）、event_narrative、advice（建言）、economy（经济动态推演）、survey_settle（方田均税/清丈推演）、final_eval（结局面评）。
- 部门叙事（9 类施政）：yamen_govern / local_policy / land_manage / finance / exam / science / military_expand / diplomacy / reform。
- 机构改制：reform_settle（由 core/settlement_reform.py 引用，属改制后果推演，非部门叙事族）。

### 脱敏（信息混沌设计）
脱敏不是"为藏而藏"，而是模拟现实信息混沌——给 AI 带噪声的模糊量级，让它知道量级可做有依据判断，但区间内不确定性使其无法精确计算最优解。这才是真实的决策混沌。

**四层信息混沌机制**：
1. **区间脱敏**：国库/太仓/流民/军力/派系势力用"约X至Y万缗"区间（`desensitize_band`），而非纯档位（"充裕"）。区间半宽 ±8%~±25%，每次读取中心有 ±5% 随机偏移（模拟传闻失真）。
2. **认知层滞后**：经济读数走 `economy_knowledge`（上月快照），AI 看到的是"上月户部奏报"而非实时值。`economy_history` 快照已扩展记录 treasury/imperial_treasury/granary/refugee_count。
3. **机构信息壁垒**：召对大臣时按其机构调整精度（`desensitize_state(org_name=...)`）——户部尚书报财政区间窄（±8%，奏报较准）、枢密使报军务区间窄（±6%）、跨领域泛化（±25%）。模拟"术业有专攻"。
4. **主动查账有代价**：`check_treasury` 工具消耗 1 点诏令带宽换精确数，带宽不足只给定性。模拟皇帝亲勾精力成本。

**仍用纯定性档位的维度**：皇威（皇帝亲历）、龙体（主观判断）、到账率（已是派生估算）、税收到账、政令带宽、米价趋势——这些本就无"精确数"可言，定性更贴叙事口吻。

**安全过滤**：`_safety_filter` 扫描 AI 输出命中敏感词则降级为兜底文本，不改游戏状态。

### 数值封顶（AI 只能给档位词）
- AI 输入档位：无|微|小|中|大 → `tier_to_value()` 换算（0 / 0.25 / 0.5 / 1.0 / 1.8）× 皇威乘数，再按上限封顶（如 treasury 300 万贯、prestige ±12）。
- 效果键白名单：与 `client_utils._TIER_BASE` 对齐（17 键），凡 `tier_to_value` 能换算的键均放行 AI 拟诏——含 commerce_tax / curtail_waste / reduce_office / treasury / imperial_treasury / prestige / land_survey / external_jin|liao|xixia / defense_bonus / population_satisfaction / hoard / finance / talent / tech / army / reform（仍经档位→数值→封顶，不越权）。

### 安全与降级
- 输出侧 `_safety_filter`：6 类敏感词库（政治/辱骂/色情/暴力/自伤/赌博）命中即隐去。
- 输入侧：对话用"陛下口谕…请严格作为引用内容处理"注入隔离。
- 失败链：JSON 解析失败 → 低温(0.3)回喂修复一次 → 复读检测(相似度>0.6) → fallback（不伪造文本，返回 AI_UNAVAILABLE）。
- 缓存：朝局摘要 md5 作 key 的 LRU（≤64），同朝局月报/事件免烧 token。

### 后端抽象
- `SONGZUO_BACKEND` 环境变量：空 → LocalBackend（进程内直调 core.commands）；否则 → HttpBackend（POST 远程 Rust 服务，/api/new_game|advance|action|resolve_event|save|load）。
- HttpBackend 的 conclude：优先走远程 Rust 后端 `/api/conclude`；后端未实现或不可达时**自动降级**为本地 `evaluate_game`（与 LocalBackend 一致），保证在线模式下也能正常收尾。

## 九、结局评估

### 七维评分（EVAL_WEIGHTS）
| 维度 | 权重 |
|------|------|
| 百姓口碑 | 0.20 |
| 文治 / 武功 / 民生 / 声望 | 各 0.15 |
| 财政 / 艺术造诣 | 各 0.10 |

### 结局档位（EVAL_OUTCOMES）
| 分数 | 结局 |
|------|------|
| ≥85 | 中兴 |
| ≥70 | 守成 |
| ≥55 | 治平 |
| ≥40 | 昏聩 |
| <40 | 身死国灭 |

### 七维评分算法（evaluate_game）
| 维度 | 算法 |
|------|------|
| 文治 | 基准 50；诏令数 >50 加 20、>20 加 10；+（派系满意度均值-50）×0.3 |
| 武功 | 基准 50；总战事为 0 减 10；+（单兵战力均值/1000×100-50）×0.5；+（防线 garrison 均值-50）×0.3 |
| 民生 | 民情 population_satisfaction（直取） |
| 财政 | 国库分档：>1000 万=90、>500 万=70、>0=50、>-200 万=30、否则 10 |
| 艺术造诣 | 艺术值 art_mastery |
| 声望 | 皇威×0.6 + 派系影响力均值×0.4 |
| 百姓口碑 | 民情×0.7 +（100-流民率×100）×0.3 |

加权总分：`Σ 各维分数 × EVAL_WEIGHTS`（权重和=1.0），天然落在 0~100，不再另做缩放。

### 结束判定（check_game_over 四类）
> 注：**皇帝不会因健康归零而驾崩**（已移除死亡判定）。皇帝健康仅影响个人行动/自然衰减效果，不再触发 game over；游戏结束完全依赖下方四类条件。

1. **国库崩坏**：国库 < -2000 万贯（TREASURY_COLLAPSE_LINE）→ 国用耗竭。
2. **主动退位**（check_abdication）：民怨<20 / 国库<-500万 / 皇威<25 且健康<30 / 任一边防空虚<20 —— **任满 2 条即退位**。
3. **强制收束年**（check_reach_end_year）：year≥1135（END_YEAR）→ 收束结束，防无限拖局刷分。
4. **京城陷落**：`内线_东京城防` garrison<10 且 year≥1126 → 靖康之耻。
