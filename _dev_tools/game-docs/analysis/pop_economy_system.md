# 《宋祚》人口·经济·金融体系整理（POP 化后）

> 整理日期：2026-08（更新） · 依据当前工作区源码实勘
> 核心思想：维多利亚式 POP 人口分层 + 钱粮商品三账记账（来源=去向，非总量守恒）+ 田亩归属 + **AI 推演经济动态（AI 只给方向档，程序换算封顶）** + 经济金融 AI 介入 + 大臣家产/建筑/投资融入循环
> 消费端校准 + 生产过剩加消耗已落地；**全游戏强制 AI**（AI 缺失 → 经济推演不执行 + 明确报错，不伪造）

---

## 一、POP 人口群体（每路 6 类，每类 {人数, 钱, 粮, 商品}）

| POP | 人数（全国） | 角色 | 收入来源 | 主要支出 |
|---|---|---|---|---|
| 农 | ~7200 万（90%） | 种地产粮 | 卖粮 | 吃粮、交税、交租（佃户）、买布 |
| 士绅（地主） | ~124 万（1.5%） | 收租、囤粮、隐田 | 地租、隐田产、卖粮 | 买绸（奢侈）、囤粮、交地主田赋 |
| 工匠 | ~400 万（5%） | 产商品（绸布等） | 卖商品 | 吃粮、买原料、交工商税 |
| 商人 | ~240 万（3%） | 贩运、市舶 | 贩运差价 | 吃粮、交工商税/盐课/市舶税 |
| 官僚 | ~24 万（官2.7+吏21.6） | 食禄 | 俸禄 | 吃粮、买绸布 |
| 兵 | ~75 万 | 食饷 | 军饷 | 吃粮、买布 |

- 总人口 = 在籍 8000 万 + 兵 75 万 = 8075 万；隐户 2000 万（不在籍，吃粮计入需求）
- 三账守恒：钱（贯）、粮（石）、商品（分种类 dict，如绸/布）——每笔流转此消彼长

## 二、田亩归属（粮是田产的，不是人产的）

| 田类 | 占比 | 产粮归谁 | 租/税 |
|---|---|---|---|
| 自耕农田 | 40% | 自耕农（农 POP） | 交自耕田赋 |
| 地主田 | 50% | 佃户自留一半 + 士绅收租一半 | 士绅交地主田赋 |
| 官田 | 8% | 佃户自留一半 + 官租入太仓 | 免田赋（官租即财政） |
| 皇庄 | 2% | 佃户自留一半 + 皇租入内帑粮仓 | 免田赋（皇租即内帑） |
| 隐田 | 25%（额外） | 全归士绅（隐瞒） | 逃税 |

**土地演化（开局初值可变化）**：
- 自然兼并（每月 0.1%）：自耕田 → 地主田（自耕农破产）
- 诡名寄产（每月，随东南士人势力）：地主田 → 隐田（士绅逃税）
- 方田均税（政策，AI 推演力度）：隐田转正 + 地主田退给自耕农 + 士绅吐粮

## 三、产粮与分配

- 粮产 = 田亩 × 亩产（北 1.0 / 南 2.5 石/亩）× 粮田率（扣经济作物田，北 10% / 南 20%）
- 全国在册产 7.2 亿石/年（加权亩产 1.83 石/亩）
- 三运期（3/6/9 月）集中产粮，每期 1/3 年产
- 分配：自耕田→自耕农、地主田→佃户半+士绅半、官田→佃户半+太仓、皇庄→佃户半+内帑粮、隐田→士绅

---

## 四、消费与市场交易

**粮市**：各 POP 吃粮（人均 0.3 石/月，含综合消耗）；非农 POP 用钱买农余粮（钱→农、粮→非农）

**商品市**：工匠产多商品（绸/布等，后期 AI 开发新商品经 `register_finished_good` 扩展）；各 POP 按阶级买（士绅买绸贵、官僚买绸布、农兵买布日用）

**消费景气**：AI 推演（景气档位 微/小/中/大 → 消费额 0.5~1.3 倍）

## 五、税赋（税基 POP 化，不从凭空常量征）

| 税种 | 税基 | 纳税人 | 去向 |
|---|---|---|---|
| 田赋本色 | 在册田产 × 税率 | 自耕农(自耕田) + 士绅(地主田) | 太仓 |
| 田赋折色 | 税粮 × 折色率 40% × 粮价 | 同上 | 国库 |
| 役钱 | 农 POP × 丁口率 | 仅农（乡村民户） | 国库 |
| 工商税 | (工匠+商人)size × 人均产值 × 5% | 工匠/商人 | 国库 |
| 盐课 | 盐产量 1.85 亿斤 × 榷利 0.045 | 商人（专卖） | 国库 |
| 酒课 | wine_tax（随酒坊累积） | 作坊/商人 | 内帑 |
| 市舶税 | 海外贸易额 × 关税 | 商人 | 国库 |

**避税/免役**：隐田逃税、官户（士绅/官僚）免役、坊郭户（工匠/商人）不服乡村差役（科配并入工商税）、兵免。

## 六、财政账户

| 账户 | 单位 | 收 | 支 |
|---|---|---|---|
| 国库 treasury | 贯 | 工商/役钱/折色/盐/市舶税 | 俸禄、军饷、常费、工程 |
| 太仓 granary | 石 | 田赋本色、官租、漕运 | 军粮、官禄、赈济 |
| 内帑 imperial_treasury | 贯 | 酒课、结余抽成 | 宫廷用度、赏赐 |
| 内帑粮 imperial_granary | 石 | 皇庄皇租 | 宫廷用粮 |

收支平衡：月入 ~207 万贯 ≈ 月出（俸禄 + 常费），国库稳定 ~800 万贯。

## 七、金融与物价

- **货币总量 = ΣPOP 财富 + 国库 + 内帑 + 交子 + 白银**（自然派生，无凭空常量）
  - 士绅财富 × 0.5（窖藏藏富，一半退出流通——北宋钱荒根源）
- **物价水平 = 货币有效供给 × 周转 1.8 / 实物经济总量**（clamp 0.5~3.0）
- **粮价 = 物价 × 季节（青黄不接×1.15/秋收×0.9）× 灾害（按灾级 ×1.5~3.5）× 区域供需比（0.5~2.0）**
- **交子**：官府发钞，issued × 信任度入货币；超发→贬值（后续接）
- **钱荒**：货币 < 交易需求 → 纳税系数降、物价跌
- **市舶**：商人外贸，白银流入 → 货币增

## 八、士绅经济（囤积居奇 + 逃税 + 藏富）

- 收入：地主田租（25% 产）+ 隐田产（25% 产）
- 支出：交地主田赋（5% 产）+ 买绸（奢侈）+ 囤粮
- **囤粮**：AI 推演（囤/抛 + 力度档位，档位词 7 档 无/微/小/中/大/巨/极），上限 = 士绅田产年产（囤不了无限多），超上限强制卖
- **卖粮**：AI 推演档位换算，粮→钱（买方化：买方扣款 == 士绅增款，无凭空造币）
- **挤压**：士绅囤粮退出市场流通 → 粮价涨（囤积居奇）
- **窖藏**：50% 铜钱入窖银（藏富·死钱，抽水减半）、50% 入流通；no-AI 被动缓释 0.5%/月（有 AI 由档位决定）；只藏铜钱不藏交子
- **消费**：士绅奢侈消费 = 家产/wealth × 0.01 × BOOM_MULT（1%，A1 修复后）

## 九、AI 推演（行为层，程序只做框架+记账+换算封顶；全游戏强制 AI）

| 推演 | 输入 | 输出 |
|---|---|---|
| 经济动态 economy_decide（推演官）| 粮价/物价/民心/财力/记忆图谱 | 景气、士绅囤抛、生产、窖银、城市化/回乡/科举 + **5 金融字段**（交子信任/钱荒/市舶/银行/物价趋势）|
| 方田均税效果 survey_settle（按察使）| 隐田规模/士绅势力/皇威 | 清隐田/退田力度档位 |
| 军事 military_decide（枢密）| 盘面 | 训练/兵额/征发档位 |
| 外交 diplomacy_decide（使节）| 外部盘面 | 态度/岁币/盟约档位 |
| 灾荒 relief_decide（按察使）| 灾情 | 赈济/流民档位 |
| 自由动作 free_effect | 玩家拟诏 | 白名单效果 + CAP + 拒绝式 |
| 投资 invest_decide | 投资对象+金额 | 回报/风险档位 |
| 新作物/新矿 new_material | 玩家拟诏 | 注册新原料（register_raw_material）|

**强制 AI**：AI 缺失/失败 → 经济推演不执行 + 明确报错（AI_NOT_CONFIGURED 等 6 码），绝不伪造档位（移除旧「无 AI 写死兜底」）。

**经济金融 AI 介入**：AI 只给方向档（交子信任 增/稳/跌、钱荒 缓/平/加剧、市舶 兴/平/衰、银行 扩/稳/损、物价趋势 通胀/平/通缩），程序按 `FINANCE_DECIDE_BASE` 换算记账（交子 trust±5/issued+100万 受可发额度、钱荒 shortage±0.05 联动税负、市舶 tariff±0.02/silver_in±10、银行仅 established、价格系数±5% 月度重置）——AI 保混沌、程序保记账（不凭空造灭）。

**大臣家产**（minister_estate 钱+田）：1101 基线（蔡京 3万/800）→ 随 corruption 膨胀（靖康籍没锚点）；钱的循环（俸给→奢侈消费→工匠商人/窖藏→钱荒/抄没→国库）；田的循环（收租→卖粮/田赋/免役/兼并→清丈/抄没→官田）；融入经济循环。

**建筑**（政府 + POP，Lv1-5 ×1.5/级 封顶 ×2.0）：政府建筑（projects 工程系统：水利/常平/官营作坊/官署/军营/学校）+ POP 建筑（路级 buildings：农田/工坊/商铺/庄园）；效果=对既有公式乘数，数值走既有公式保守恒。

**投资**（invest_decide 复用 free_effect）：国库（会签）/内帑（乾纲独断）投入 → AI 推演回报/风险 → 程序记账（投入-回报-亏本-贪腐截留四账闭合）→ 投资→产出→税收→再投资闭环。

## 附：经济循环总图

```
田产粮（按田亩归属，含大臣家产田）
  → 自耕农/士绅/太仓/内帑粮/隐田(逃税)
  → 各 POP 吃粮 + 粮市交易（记账：来源=去向）
  → 加消耗：酿酒/饲料/种粮/霉耗/漕运损耗（吸收过剩）
  → 士绅囤粮（AI 推演）+ 窖藏 50%（钱退出流通，0.5% 回流）
  → 工匠产商品 + 各 POP 按阶级买（钱→工匠商人）
  → 税从 POP 征（田赋/役钱/工商/盐酒市舶）→ 国库/太仓/内帑
  → 国库发俸饷 → 官僚/兵（俸给划转入大臣家产）
  → 大臣家产：奢侈消费（→工匠商人）/窖藏（→钱荒）/抄没（→国库）
  → 建筑（政府 projects + POP 路级）：建造耗钱 → 雇佣 POP → 产出乘数 → 税收
  → 投资（invest_decide）：国库/内帑投入 → AI 推演回报/风险 → 产出/收益/亏本/贪腐截留
  → 经济金融 AI（交子/钱荒/市舶/银行/物价趋势）：AI 给方向档 → 程序换算记账
  → 货币 = ΣPOP 财富 + 国库 + 内帑 + 交子 + 白银 → 物价 → 粮价
```
