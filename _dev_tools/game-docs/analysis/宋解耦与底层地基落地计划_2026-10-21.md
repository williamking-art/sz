## 1. 总原则（违反即返工）

1. **宋-first**：本阶段不实现任何其他朝代/政体内容；只留 schema 兼容与 MOD 接口。
2. **零行为优先**：P0 全部"只读/契约/适配"，同种子新局与 6 月结算必须逐字段一致。
3. **契约先行**：每个域先写"输入/输出/不变量/缺失语义"，再改代码；没有契约不改行为。
4. **单一真账**：人/钱/粮/货只落既有 POP/国库/内帑/库房；派生视图只读；禁止平行账本。
5. **缺失 ≠ 0 ≠ 1.0**：一律 `None/Unknown + reason`；禁止 `or 0`、`or 1.0` 冒充。
6. **确定性可回放**：同 seed + 同决策 = 同结果；关键路径记录决策日志。
7. **AI 只提议，Jev 只判断，程序只执行**：AI/Jev 都不写 state、不出数值。
8. **先适配后替换**：旧字段保留、adapter 映射、守卫棘轮；不做全库重命名/大爆炸。
9. **每步可回滚**：小提交、独立验收、先只读后可写、先影子后切正式。
10. **文档与裁定留痕**：Jev 结论进 `decisions/*.json`；每轮更新 README/索引/基线/handover。

## 4. 架构分层与跨域机制

```text
表现层（UI/奏报/地图/读数）
  ↑
推演层（月循环、事件、AI 叙事、重放）
  ↑
决策层（TianDao/Jev：只判档位/概率；决策日志）
  ↑
机制层（经济/政治/军事/社会；只认实体/契约/约束）
  ↑
约束层（守恒/容量/预算/权限/信息可见性；Unknown/Range）
  ↑
状态层（唯一真账：人/钱/粮/货/地/官/军/时间）
  ↑
内容层（宋 pack：数据/参数/文案/AI 风格；MOD 只能声明式追加/覆盖）
```

**跨域机制（必须先于各域实现）**：
1. **ID/本体**：中性实体 ID；旧字段 adapter；不重命名全库。
2. **约束/未知/来源**：`Constraint`、`Unknown`、`Range`、`Provenance`。
3. **时间**：`Calendar`（年/月/季/年号/周期）；start_year 来自 pack。
4. **空间**：四图 + 距离/邻接/路线/地形单点。
5. **权限**：`AuthorityGrant` + `AuthorityResolver`（七类派生）。
6. **决策**：`DecisionRequest/Result` + `decision_log` + objective registry。
7. **信息**：事实/感知/延迟/偏差/密级；奏报≠真账。
8. **AI**：提案/叙事，不写 state；schema+约束+审批。
9. **Pack/MOD**：manifest/schema/依赖/冲突/沙箱。
10. **存档/重放**：pack meta、seed、decision log、golden replay。

## 8. v2 的改善点（为什么这次更能落地）

1. **全图而非补丁**：16 域一次列清，不再"问一点补一点"。
2. **契约先行**：每域先定输入/输出/不变量/缺失语义，避免边写边改。
3. **golden replay**：任何重构先有同种子快照，行为变化可定位。
4. **adapter + 棘轮**：旧字段保留、守卫白名单只减不增，避免大爆炸。
5. **覆盖报告**：权限/数据/未知/决策都有覆盖率，能看到"哪里还模糊"。
6. **决策日志**：Jev/天道每次判断可回放、可解释，不黑箱。
7. **MOD 沙箱**：只开声明式数据，避免创意工坊把内核写崩。
8. **性能预算**：单回合/内存有门，避免"功能对了但跑不动"。
9. **历史校准**：Jev/经济参数用回测，不靠拍脑袋。
10. **明确不做**：其他朝代、任意 Python、全库重命名、接钱先行。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 范围过大 | 按工作流并行、里程碑退出；P0 只做零行为 |
| 过度抽象 | 只抽象共同点（实体/关系/不变量），名称/层级/参数进 pack |
| 隐藏行为变化 | golden replay + 同种子 6/12 月对比；每步独立提交 |
| 存档破坏 | pack 字段可选；旧档默认宋；未知 pack 拒绝；原子写 |
| MOD 越权 | v1 只声明式；Python 插件后置+沙箱+审批 |
| AI 写崩经济 | AI 只提案/叙事；Jev 只判断；程序唯一执行 |
| 数据假精度 | provenance/unknown/range；缺数据不填 0 |
| 性能退化 | 单回合预算；定期 profiling；批量/缓存 |
| 文档漂移 | 契约/README/索引/基线/handover 每轮回写 |
