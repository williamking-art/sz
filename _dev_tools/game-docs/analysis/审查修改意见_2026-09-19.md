# 宋祚游戏全面审查修改意见

## 结论

Python 定向测试 `628 passed`，前端 TypeScript 检查通过；但当前版本不建议发布。发现凭据泄露、SSRF、并发串用、局势结算不守恒、前端会话串台及存档可靠性问题。本文不记录真实 API Key；工作区密钥必须按已泄露处理。

## P0：立即处理

### 1. 吊销并轮换明文 API Key

位置：`game/ai_config.json`、`game/ai/client.py:413-442`。

工作区存在主、备用供应商明文 Key，即使未被 Git 跟踪也可能经由打包、备份、同步、日志泄露。立即吊销轮换，检查 Git 历史、产物和日志；改用 OS keyring 或环境变量，配置文件只保存非敏感字段，加入 `.gitignore` 和泄密扫描。API、日志、异常不得输出 Key 或稳定片段。

## P1：安全与并发

### 2. 修复 AI 配置 SSRF

位置：`game/backend/server.py:109-125,932-1004`、`game/ai/client.py:355-358`。

`base_url` 校验必须拒绝 localhost、loopback、RFC1918、link-local、metadata、multicast、unspecified、URL userinfo、解析后内网地址及越界重定向。优先 provider allowlist；每次连接前重新解析校验，探测接口不得把生产 Key 发往任意地址。

### 3. 配置更新必须事务化

位置：`game/backend/server.py:979-1013`。

先构造候选 client、校验并 probe，成功后临时文件+fsync+原子 replace，再锁内替换全局 client；任一步失败均保留旧配置。补充失败、崩溃、并发更新测试。

### 4. 消除 AI provider 串用

位置：`game/ai/client.py:282-302,335-351`、`game/backend/server.py:145-149`。

请求开始时固定不可变 provider snapshot，禁止在共享 client 上原地改字段；切换时创建新 client 并原子替换。并发请求的 URL、模型、Authorization 必须始终属于自身快照。

## P1：局势结算

### 5. 终态效果原子提交

位置：`game/core/situation_settle.py:272-285`。

先在临时状态/事务中应用效果，成功后才写 `resolved/failed`；失败时保留 active 或进入可重试的 `effect_pending`，不得出现终态已完成但钱粮、威望、民心未落地。

### 6. 实现 `progress_cost`

位置：`game/core/situations.py:856-858`、`game/core/situation_settle.py:196-242`。

区分 `ongoing_cost` 与推进费用；只有扣费成功才能推进 bar，资源不足不得推进。所有资源变化配守恒断言和测试。

### 7. 实现 `deadline`

位置：`game/core/situations.py:867`、`game/core/situation_settle.py:178-292`。

明确 `turn == deadline` 语义；逾期进入失败流程并应用失败效果；同时命中 deadline 与 resolve/fail 时固定并测试优先级。

## P1：前端会话隔离

### 8. 修复大臣切换竞态

位置：`game/frontend/src/renderer/panels/AudienceView.tsx:187-224,376-413`。

使用 AbortController 和 request sequence；响应写状态前校验 sequence、minister ID、session ID。会话/记忆按 minister ID 分区，切换时清空旧私有数据并区分 loading/error/empty。

### 9. 修复调拨响应串会话

位置：`AudienceView.tsx:258-288`。

请求记录 minister、session、sequence；返回时对象已改变则丢弃或写回原会话，不得追加到当前错误会话。

## P2：存档与记忆

### 10. 存档 schema 安全解析

位置：`game/core/save_load.py:287`。非法字符串、对象、列表、空值不得抛出未处理异常；返回结构化错误或 `None`。

### 11. 识字率以 POP 派生值为权威

位置：`game/core/save_load.py:53-54,512-521`。全国识字率载入后始终由逐路 POP 加权重算；顶层字段仅作迁移诊断，不得覆盖派生值。

### 12. SQLite 线程与并发

位置：`game/memory/dialogue_memory.py:34-39,69-78,306-343`。优先短连接+事务或连接池/DB worker；若关闭线程检查必须配对象锁和事务边界。

### 13. 损坏记忆库不得静默变空

位置：`dialogue_memory.py:306-326`、`memory_graph.py:726-757`。quarantine 原文件并保留备份，返回可诊断错误，禁止伪装成正常空库。

## P2：配置契约与 AI 安全

### 14. 保留 fallback/settlement

位置：`game/backend/server.py:128-140,909-1013`、`game/ai/client.py:153-171,416-442,706-724`。统一 schema，HTTP 更新采用 PATCH/merge，未提交字段不得被删除；补 round-trip 测试。

### 15. 不返回 Key 片段

位置：`game/backend/server.py:919-923`。只返回 `configured` 和服务端生成的 `key_id`，不返回前后片段。

### 16. 防提示词注入

位置：`game/ai/client_utils.py:86-96,159-198`、`game/ai/client.py:883-897`。玩家/历史文本使用不可信边界；工具调用必须经服务端白名单、权限、对象和数值校验，模型不得直接变更真实状态。

### 17. 词库加载失败不得完全 fail-open

缺失或损坏时标记过滤器不可用；高风险输出暂停或降级，并显示明确状态。

## P3：Rust

### 18. 处理 Mutex poison

位置：`songzuo_server/src/server.rs:202-224` 等。将 `lock().unwrap()` 改为可控错误处理，缩短锁范围；重新运行 `cargo test` 并保存完整 stdout/stderr，未通过前不得宣称 Rust 通过。

## 必须补充的回归测试

1. 终态效果失败可重试且不假完成；2. `progress_cost` 扣费成功才推进；3. deadline 及边界优先级；4. 非法 schema 不导致 500；5. POP 识字率加权守恒；6. AI probe 失败保留旧配置；7. provider 并发不串 Key；8. fallback/settlement round-trip；9. SSRF、DNS、重定向拒绝；10. SQLite 并发与损坏 quarantine；11. 前端快速切换和调拨不串会话；12. Rust 测试失败必须让 CI 失败。
