# 《宋祚》POP 体系改良设计（对照 P 社 Victoria 3）

> 取证等级标注：**【wiki 实证】**= 取自 Victoria 3 官方 wiki `Profession` 页（2026-09-27 抓取）；
> **【通用理解】**= 我的模型知识，未逐页核实（实现前建议复核）；
> **【本作实证】**= 本仓库代码/文档，附 `文件:行`。
>
> 本文回答一个问题：**"P 社 V3 的 POP 体系是什么样，宋祚该照搬什么、改造什么、拒绝什么。"**

---

## 0. 结论摘要

**V3 的 POP 体系是一条"市场链"**：职位（profession）→ 建筑岗位（employment）→ 工资/分红 →
生活水平（SoL）→ 需求消费 → 政治倾向 → 流动/移民。

**宋祚的 POP 体系是一条"汲取链"**：身份（四民+兵）→ 土地关系 → 分成/自给/俸禄 →
**税租役汲取** → 生存压力 → 逃籍/流动 → 派系对抗。

两者**不是同构**，但可以互补。**本次设计的核心决策：引入 V3 的"生活水平"作为中介变量
（宋代对应物 = 生计水平），把税负分层、消费分层、流动、政治倾向四件事统一到一条因果链上。**

```
V3 ：  职位 → 岗位 → 工资/分红 → SoL → 需求消费 → 政治 → 流动
宋祚：  身份 → 土地/岗位 → 分成/自给/俸禄 → 【生计水平】 → 消费分层 → 派系倾向 → 逃籍/流动
                                            ↑ 本次要补的中介变量
```

**八条关键决策**（详见 §3.3）：

| # | 决策 | 取舍 |
|---|---|---|
| 1 | 分类键＝**职位**；六类＝四民+兵（V3 的 15 职粗粒度整合） | 采纳（用户已定） |
| 2 | 建筑＝**多职位岗位槽**（自耕农庄/地主农庄/衙门/工坊/矿场/商铺/军营） | 采纳 V3 |
| 3 | **不全盘采纳**农业工资化（农不领工资，自给+分成） | 拒绝（半 V3，既有边界） |
| 4 | **引入"生计水平"**（子池级读数）= 收入 − 必需支出（口粮/租/税/役） | **改造 SoL**（本设计的核心增量） |
| 5 | 消费按生计水平**分层**（V3：Peasants 消费 ×0.05 给了标定） | 采纳并改造 |
| 6 | 流动由**岗位容量 + 生计水平 + 资质（识字）**驱动，而非固定 2%/月 | 采纳 V3 的 hiring 语义 |
| 7 | **保留本作特有**：隐户信息不对称（约值+清丈）、中央-地方对抗、科举/恩荫/致仕、官/吏身份子池 | 本作特有，V3 无 |
| 8 | **拒绝**：文化/宗教 POP 维度、奴隶、跨国移民、V3 的 ownership 建筑分红账本 | 明确不做（见 §3.3） |

## 1. V3 的 POP 体系（事实层）

### 1.1 职位与阶层【wiki 实证】

15 种职业 + 失业，分三层 strata；农业相关的四个是设计对照的关键：

| 职业 | Stratum | SoL | 工资系数 | 关键特性（wiki 原文要点） |
|---|---|---|---|---|
| **Peasants** | Lower | 5 | **0.2** | **不能被解雇**（失业即转 Laborers）、**无视就业比例**、**消费 ×0.05**、依赖收入 0.25 |
| **Laborers** | Lower | 5 | 1.0 | 默认职业、无资格门槛、可被雇/被裁 |
| **Farmers** | Middle | 10 | 2.0 | 10% investment pool（经营农/农场主） |
| **Aristocrats** | Upper | 20 | 5.0 | **不领工资（只拿分红）**、20% workforce ratio、20% investment pool（地主） |
| 其他 | — | — | — | Clerks/Machinists/Servicemen/Slaves（Lower）；Academics/Bureaucrats/Clergymen/Engineers/Officers/Shopkeepers（Middle）；Capitalists（Upper） |

> 关键洞察一：**V3 的 Peasants 就是"自给农"**——不占岗、不领工资、几乎不消费（×0.05）。
> 本作"农不领工资 + 粮维豁免岗位制"其实**已经**是 V3 的 Peasants 轨，只是没分层。
>
> 关键洞察二：**V3 的"自耕农/佃农"分野 = Peasants vs Laborers（两个职位）**；
> 本作把它们压进一个"农"职位 → 只能用子池表达（用户 2026-09-27 口径）。

### 1.2 POP 的构成与属性【通用理解】

- POP = **profession × culture × religion** 三元组（本作**不采纳**文化/宗教维度）；
- 每个 POP 有 size、**workforce / dependents** 拆分、SoL、literacy、qualifications、
  political strength、radicals/loyalists 比例、migration 意愿。

### 1.3 就业与工资【wiki 实证 + 通用理解】

- **建筑提供岗位槽**：每个建筑按 profession 分槽（一个农场里 laborers/farmers/aristocrats 并存）；
- **招聘**：按 qualifications（识字/资质）＋ 工资竞争；跳槽需工资高 10%；受**就业比例**限制
  （Peasants/Officers/Servicemen 与 ownership 建筑豁免）；
- **工资** = 建筑 base wage × 职位工资系数；建筑靠涨薪抢人，亏损则降薪/裁员/破产；
- **利润 → ownership 分红**：aristocrats/capitalists 通过 ownership 建筑（manor house /
  financial district）拿分红，**不领工资**。

### 1.4 需求与生活水平【通用理解】

- **SoL 由 needs 满足度分级**（staple 必需品 → 日用品 → 奢侈品）；买不起 → SoL 降 →
  死亡率↑/激进↑/移民↑；
- 消费按 needs tier 分层，Peasants ×0.05 意味着自给农几乎不参与市场消费。

### 1.5 流动【通用理解】

- **promotion/demotion**（职业升降）、**migration**（城乡、国内、跨国）、
  **subsistence → laborers**（农业建筑化把自给农变成雇工）；
- 流动动力 = 生活水平差 + 岗位空缺 + 资质。

### 1.6 政治【通用理解】

- POP 按利益集团（Interest Group）支持度汇聚 → IG 政治力量；识字率/财富提高政治参与。

## 2. 对照表：V3 十个维度 × 本作现状 × 差距

| # | V3 维度 | 本作现状【本作实证】 | 差距 |
|---|---|---|---|
| 1 | 身份键 = profession×文化×宗教 | 六类=四民+兵（`GRAIN_CONSUME_PER_CAPITA` 权威）；子池=身份/经营结构 | ✅ 口径已对齐（用户定）；文化/宗教不做 |
| 2 | POP 规模 = size + workforce/dependents | `size` 单值，无 workforce/附属人口拆分 | 🟡 缺"在业/抚养"细分（本作轻量化可接受） |
| 3 | 建筑多职位岗位槽 | `BUILDING_WORKER = {建筑: 单一 worker 类型}`（`building_jobs.py`） | 🔴 **必须升级为多职位槽**（B0） |
| 4 | 工资 = 建筑 wage × 职位系数 | 农分成/自给、士绅租、官俸、军饷；**无农业工资** | ✅ 有意不同（半 V3）；但"同建筑内多职位收入差"缺载体 |
| 5 | ownership 分红（地主/资本家） | 佃租半分给士绅（`_settle_economy` 地主田分配）；无 ownership 结构 | 🟡 结构隐式；"地主=owner 岗"要显式化 |
| 6 | SoL（需求满足度分级） | **无 SoL/生计水平概念**；只有 `population_satisfaction`(0-100) 与路级 mood/民怨 | 🔴 **本设计的核心增量**（§3.1 L4） |
| 7 | 消费按 SoL/needs 分层 | 口粮按职业常量（`GRAIN_CONSUME_PER_CAPITA`）、商品按 `GOODS_CONSUME_RATE`，**均质不分子池** | 🔴 需按子池/生计水平分层 |
| 8 | literacy + qualifications 决定可任职位 | 有 `literacy`（逐路 POP 派生，`core/literacy.py`）；科举有资格线 | 🟡 未作为流动门槛接入 |
| 9 | 流动 = promotion/demotion + migration（由 SoL/岗位/资质驱动） | 固定通道：科举/城市化/致仕/入伍/隐户双通道；就业流动刚接线但**固定 2%** | 🔴 驱动力要改（B3） |
| 10 | 政治 = POP→利益集团力量 | 派系 5 集团 + 基本盘子集读数（`faction_basis`）+ 满意度 | 🟡 基本盘未按子池加权 |

## 3. 改良设计（本作版 POP 体系）

### 3.1 五层架构

```
L1 人口账     六类职位（四民+兵）＋ 子池（身份/经营/户籍）      Σ子池 == size（隐户单列加法子池）
L2 建筑-岗位   建筑 → {职位: 每级岗位数}                       一个建筑横跨多个 POP 类
L3 收入       分成 / 自给 / 地租 / 俸禄 / 军饷 / 工钱          按"职位+子池"定价，钱粮各挂其主
L4 生计水平   生计 = 收入 − 必需支出（口粮+租+税+役）           ★新增中介变量（SoL 的宋代对应物）
L5 流动       换职位=跨类；换身份=子池；驱动=岗位缺口+生计差+资质
```

### 3.2 各层落点与验收

| 层 | 落点 | 关键字段/参数 | 守恒与验收 |
|---|---|---|---|
| **L1** | `_build_pops`、`data_constants`、`save_load` 迁移 | `农`: 自耕农/佃农/富农/贫农（＋`hidden`）；`士绅`: `clan`/`estate`；`官僚`: `officials/clerks/on_post/waiting/sinecure` | 逐路 `Σ子池 == size`；Σ六类 size 守恒；**六类清单单源守卫**不破 |
| **L2** | `building_jobs`：`JOBS_PER_LEVEL`→`{建筑:{职位:岗位数}}`、`BUILDING_WORKER`→多职位映射 | 自耕农庄/地主农庄/衙门/工坊/矿场/商铺/军营 | 岗位表读数正确；**新局零迁移**；外邦长局基线不漂移 |
| **L3** | `settlement_econ`（分成/自给）、`settlement_finance`（税）、`settlement_officialdom`（俸）、`settlement_military`（饷） | 各职位单价/分成率/租率 | 各账 ΣΔ==0；**税基按子池**（自耕农/富农纳役钱，佃农/隐户不纳） |
| **L4** | 新增 `core/livelihood.py`（或 `situation_metrics` 内） | `pop_livelihood(路, 职位, 子池)`：收入−（口粮折价+租+税+役）；分档（如 赤贫/困顿/温饱/小康/富足） | 只读派生、可复算；**不落存量**（避免平行账本） |
| **L5** | `building_jobs.apply_employment_flow`、`officialdom`（科举/致仕）、`settlement_imperial`（隐户） | 迁移量 = f(岗位缺口, 生计差, 识字门槛)，月率封顶 | 迁移 ≤ 缺口；ΣPOP 守恒；长局非农不塌陷 |

### 3.3 V3 采纳 / 改造 / 不采纳清单

| V3 机制 | 本作处置 | 理由 |
|---|---|---|
| 职位＝分类键 | ✅ **采纳** | 用户已定；本作即四民+兵 |
| 建筑多职位岗位槽 | ✅ **采纳** | 用户已定；一建筑横跨多 POP 类 |
| Peasants 消费 ×0.05、不能失业、无视比例 | ✅ **采纳并改造** | 直接用于"隐户/贫农"的消费标定与生计兜底语义 |
| 工资系数分层（0.2/1.0/2.0/5.0） | 🟡 **改造**：不做农业工资，但用**同建筑内收入级差**表达（自耕农>佃农>贫农） | 保住"半 V3"边界，同时保留分层张力 |
| **SoL / needs 满足度** | ✅ **改造为"生计水平"**（子池级派生读数） | ★核心增量：统一税负/消费/流动/政治 |
| qualifications 门槛 | ✅ **采纳并改造**：用既有 `literacy` + 科举资格 | 复用既有数据，避免无摩擦流动 |
| ownership 建筑分红 | 🟡 **改造**：地主/田主作为**地主农庄的 owner 岗**收租（不建分红账本） | 避免新增平行账本（挂载律条 4） |
| 文化/宗教 POP 维度 | ❌ **不采纳** | 与史实框架无关，且会把 6 类炸成矩阵 |
| 跨国移民 | ❌ **不采纳** | 本作是单一国家视角；只有流民/逃籍 |
| 奴隶 | ❌ **不采纳** | 边界（文档 §十六） |
| 农业工资化（全 V3） | ❌ **不采纳** | 既有边界："农不领工资"（半 V3） |

### 3.4 本作特有（V3 没有、必须自己设计）

1. **隐户信息不对称**：人口账在 POP 内、**朝廷端只给约值**（档位词），真实值靠**清丈/统计**揭示；
   → 衍生**中央 vs 地方**对抗（地方低报、士绅庇户、吏胥把持、清丈反弹）。
2. **土贡式财政汲取**：税/租/役三腿并行，**税痛感因身份而异**（自耕农最直接、佃农隐于租、
   隐户无税痛）——这是本作**最独特的玩法张力**，也是 L4 生计水平的主要输入。
3. **科举/恩荫/致仕**：士绅↔官僚的职位互换（V3 无对应；本作的政治再生产主线）。
4. **官/吏身份子池**：同一衙门建筑内的两个岗位（用户 2026-09-27 口径）。

## 5. 风险与护栏

1. **六类不可擅自扩**：`GRAIN_CONSUME_PER_CAPITA` 是权威单源，守卫测试 `test_pop_class_single_source.py` 在位；
   新增职位一律走**子池**（吏已按用户口径定为衙门岗位，不升格）。
2. **不做平行账本**（挂载律条 4）：生计水平只读派生；所有权不建分红账本。
3. **守恒**：`Σ子池==size`、`Σ六类 size` 守恒、各钱粮账 ΣΔ==0、`M_ALL` 残差 0 不破。
4. **不动外邦基线**：B0 的岗位表升级必须兼容外邦既有 `{"lv": n}` 建筑与长局断言。
5. **不破既有 1110 基线**：每批结束跑全量 + 专项守恒。
6. **信息不对称与档位化**：隐户真值、生计水平细值一律不下发前端/AI，只给档位词（同 `loyalty` 先例）。
