# 利益集团历史命名与子集关系方案

详见当前 data.py 的六个集团，建议显示名：新法系、元祐旧臣与保守士绅、内侍与内廷势力、陕西边将与西军、东南形势户与市舶商人、台谏清议。

## 子集关系

- 新法系：官僚 officials 核心，士绅为政策暴露扩展层。
- 元祐旧臣与保守士绅：全国士绅政治子集，可与台谏清议重叠。
- 内侍与内廷势力：京畿官僚 officials 子集，不等于全部京畿官僚。
- 陕西边将与西军：陕西、河东、河北兵 POP 路域子集，兵力仍来自兵 POP/军队单位。
- 东南形势户与市舶商人：东南士绅+商人路线子集，应拆士绅、商人两个诉求通道。
- 台谏清议：官僚 officials 子集，按台谏职位和清议暴露识别。

## 重叠规则

新法系与台谏清议是政策网络与制度网络的交叉；元祐旧臣与台谏清议同样可重叠；新法系与内廷势力可合作但不从属。所有重叠只影响政治读数，不重复扣 POP 人口、财富和粮食。
