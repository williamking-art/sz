## 纪律
- 结论必须带**证据**（文件:行、命令、实测数值），"需人工确认"要显式标注；
- 报告只增不删（改写留痕），历史结论被推翻时**注明更正**而非悄悄改掉。
- 分析稿不是当前机制的权威源；仍有效的结论需回写 `../docs/` 或对应 `../specs/*/tasks.md`。
- 旧报告中的测试数、文件行号、待办和“已落地”标签按报告时点理解；引用前先查当前代码与最新任务状态。
