# 舆图/空间地基审计（P0 · 2026-10-21）

> 只读审计，不改渲染/数据/生成器。依据：`game/assets/map/README.md`、
> `game/AGENTS.md` §4/§5、`_dev_tools/game-dev/tests/test_map_prefecture_geometry.py`。

## 1. 分层现状

| 层 | 位置 | 状态 |
|---|---|---|
| 源料 | `game/assets/map/raw/` | 已跟踪行政边界/自然地理输入 |
| 生成数据 | `game/assets/map/web/*.geojson`、`view.json`、治所台账 | 部分生成物未跟踪；本地可重建 |
| 前端运行副本 | `game/frontend/public/map/*.topojson` | 由 `build-topo.ts` 生成，**不在版本库** |
| 模拟空间 | `geo_admin`、`region_registry`、`county_registry`、`prefecture_entity`、`transport.py` | 区划/治所/路线分散，未统一空间服务 |
| 表现 | `frontend/src/renderer/map/` | MapLibre/WebGL；无头截图不保证 |

## 2. 生成链（需可复现）

```powershell
cd game
python build_map_basemap.py
python content\build_map_geo.py
cd frontend
node .\node_modules\tsx\dist\cli.mjs scripts/build-topo.ts
node .\node_modules\electron-vite\bin\electron-vite.js build
```

- 干净 clone 未重建 ⇒ `frontend/public/map` 为空、舆图空白；
- 山坡影瓦片需联网 `fetch_hillshade.py`，未生成时 `HILL_TILES_ENABLED` 关闭；
- 生成物不手改；改源料/生成器后必须按序重建。

## 3. 一致性缺口（待 W1/W2 接口解决）

1. **四图未分离**：地点（几何）/行政层级/政治控制/职能管辖仍混在 `prefectures`/`regions` 读口中；
2. **空间服务缺失**：距离/邻接/路线/地形没有单一入口，运输/军事/市场各算各的；
3. **治所↔区划↔地图**：`region_registry` 只读骨架已建，但地图 `circuit_seat_ledger`/`view.json` 与 `seats` 的坐标/名称未做统一校验；
4. **无头验收限制**：WebGL 像素级仍需真机；数据级回归只有 `test_map_prefecture_geometry.py`；
5. **MOD 边界**：没有"地图 geometry 只读、内容 mod 不改算法"的声明。

## 4. P0 结论与下一步

- **结论**：源料/生成/运行副本三层边界基本清楚，但**干净 clone 不可直接看到舆图**，空间服务未统一；
- **P0-11 完成项**：本审计 + 重建清单 + 缺口登记；
- **W2-03**：空间服务（地点/邻接/距离/地形/路线），运输/军事/市场共用；
- **W2-05**：舆图 pack/构建/前端契约 + 一致性用例（治所↔区划↔地图）。
