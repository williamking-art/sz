# 经济、金融、工程与科技机制整改意见

## 总原则
POP size/wealth/grain、国库、内帑是人口与钱粮唯一写入权威；任何经济、金融、工程、科技变化必须有来源、去向和守恒断言。core/money.py 只作对账视图。AI 只能提出结构化意图，程序负责白名单、扣费、回滚。

## 一、经济
1. 固定回合顺序：生产→工程投入→POP收入消费→粮食商品市场→税收转移→货币信用→物价→集团读数→提交。失败整月回滚。
2. 生产和工程项目必须声明原料、钱粮、工匠工时、产出、施工期、维护、折旧、路线和POP受益者。完成提高产能，运行持续维护，材料不足逐步降效。
3. 路线物价由供给、需求、库存、运输、货币有效供给派生；全国PRICE_LEVEL只是加权读数。粮价优先受产量、粮仓、漕运影响，价格有月度上限。
4. 税、工资、价格先改变POP财富/粮食，再派生消费、满意度和集团态度，禁止直接给集团发钱。

## 二、金融
1. 统一有效货币供给口径：流通铜钱+有效交子余额+实际流通白银折钱。窖藏、准备金、仓粮不得重复计入。每月对账铸币、发行、换界销毁、熔化、外流、税收回笼和支出。
2. JIAOZI_INFO 必须区分发行额、流通额、准备金、兑付率和界期。发行受准备金/税收接受度/信用上限约束；换界真实减少流通额；信用下降产生折价和挤兑，损失落到持有者。
3. BANK_INFO 增加存款、贷款、准备金率、逾期率、挤兑压力、网点和对象。贷款同时形成债权与借款方资产，利息、坏账有明确去向，不能当财政收入。
4. 信用由兑付、准备金、物价、税收兑现和违约派生；下降依次传导利率、折价、信贷收缩、囤货、工程延期。
5. STANDARD_INFO 分离记账汇率与市场汇率；兑换记录手续费、铸币损耗和双方资产变化。

## 三、工程
1. 项目状态机：proposed→funded→building→operating→degraded/abandoned。资金、材料、灾害或治安不足应延期/降效，不能静默完成。
2. 工程所在地消耗工匠POP可用工时，工资进入工匠POP wealth；工役产生农/工匠POP时间损失，不新增工程人口。
3. 水利提高有效耕地/抗灾，常平仓改善粮价，市舶司提高贸易吞吐，作坊提高产能，学校提高识字/人才；收益有容量、维护和折旧。

## 四、科技
1. TECH_INFO.level 只作综合读数；真正可用能力拆为火药、冶金、水利、历法、航海、财政、医学农学节点。节点声明前置、研究成本、工匠/学者投入、建筑、效果和维护。
2. researching 必须消耗预算和人才时间，受学校、识字率、材料影响；中断可保留进度但有机会成本。
3. 解锁不等于全国生效，必须经建筑、作坊或军队部署，以adoption覆盖率产生效果。
4. era是时代约束/叙事标签；west必须有贸易、使团、书籍、工匠或战争来源，不作万能加速器。

## 五、联动
经济繁荣提高POP财富、税基和研究资金，同时提高价格和集团议价；金融稳定降低交易成本并支持工程科技；过度发行提高物价和工程成本；工程提高产能但需维护；科技须部署才转化产出；最终利益集团只读取POP实际变化。

## 六、数据接口整改
统一schema version和金额/粮食/材料单位，禁止贯与万贯混用；所有存量进入存档迁移和守恒校验；API返回来源、去向、状态、错误；AI不得直接写JIAOZI_INFO、BANK_INFO、TECH_INFO或POP；失败不得静默成功。

## 七、测试与完成标准
补充生产/消费/税收守恒、物价供需、交子发行与销毁、银行贷款利息坏账、汇率、工程延期降级、工匠工资、科技研究和adoption、整月回滚、存档重算、AI非法操作拒绝测试。四系统必须有单一权威源、投入—产出—维护—折旧闭环、可回滚事务和压力测试，之后才能发布。
