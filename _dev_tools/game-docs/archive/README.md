# `archive/` · 历史材料

本目录只保存已被新规范取代的设计稿、旧审查和当时的运行记录。正文中的测试结果、路径、待办及缺陷状态均绑定原报告时点，不能作为当前事实。

## 维护规则

- **不改写历史结论**以追求与当前代码一致；如需纠错，在现行 `docs/`、`specs/` 或审校台账里写明原结论、复核证据和替代口径。
- 新增归档文件时更新 [`../README.md`](../README.md) 的目录说明；不需要在本索引逐条复制全部历史文件清单。
- 要复用旧报告，先确认其引用的实现、测试、路径和环境仍存在，再迁移仍有效的内容到现行文档。
