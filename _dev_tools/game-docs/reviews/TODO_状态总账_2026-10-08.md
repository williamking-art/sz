## 环境噪声与计数纪律（排障用）

### 1. 性能门对整机占用敏感

`test_situations.py::test_readout_performance_gate` 在**并行作业占满 CPU** 时报
`P95=134ms > 50ms`。**与代码无关** —— 同进程 A/B 实测（唯一变量 = `clan`）：
含 `clan` **26.2** / 去 `clan` **27.5** / 含 `clan` 复测 **28.7** ms，均在噪声内；干净串行重跑通过。

⇒ **跑全量时不要并行其他负载**。

### 2. 本机 dot 计数不可靠（曾据此误报）

PowerShell 重定向会**吞字符**，`-q` 的进度点行宽度也随环境变化（79 → 72），
按点计数得出过 `2373 / 2374 / 2444 / 2445` 等**互相矛盾**的结果，并使我误报过 skipped 数。

**纪律：一律用 `--junitxml` 或 `--collect-only` 取数，不数点。**

```powershell
# 权威计数（推荐）
python -m pytest _dev_tools/game-dev/tests -p no:cacheprovider -p no:warnings -q --junitxml=out.xml
# 或用 Python 读 testsuite 的 tests/failures/errors/skipped 属性
```
