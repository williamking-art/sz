## 八 · 产业链之间的联动（2026-10-03 用户追问后补）

> 上文 §二 是**并列清单**，但真实手工业是**网络**：有上下串联、有同源争抢、有联产副产物、有工序缺失。
> **联动没设计，扩充就是假的** —— 一条链扩了 16 个坊，原料不够、产能互抢、缺料即全停。

### 8.1 三个必须解决的联动问题（实测 `settlement_econ._settle_workshops`）

| 问题 | 现状 | 后果 |
|---|---|---|
| **① 同源争抢** | 绢坊/绫罗坊/紬坊**都读** `state.resources["丝"]["stock"]`，无仲裁 | 谁先结算谁拿；后跑的缺料停产，**产出结构随机漂移** |
| **② 无串联** | `recipe` 是 `原料 → 成品` 单级一步到位 | 无法表达「缫丝→纺→织→染」，织造工艺被压扁 |
| **③ 产出不分州府** | `_POOL_DIMS` 汇成**全局**工匠池 | 工坊产出**没有产地属性**，与 G-2 州府桶脱节 |

### 8.2 联动一 · 多级串联（工序链）

真实丝织是**四道**：桑→茧→生丝→织→染→成品。建模为**级联配方**：

```
桑叶 ──蚕坊(畜栏)──> 茧 ──缫丝坊──> 生丝
生丝 ─┬─绢坊(平纹织)──> 白绢 ─┐
      ├─绫罗坊(提花)──> 白绫罗 ─┤
      └─紬坊(厚织)  ──> 紬    ─┴─染色(染坊)──> 成品绢/绫/紬
```

**同一批生丝可按比例分流到三条织造线**，再经染坊统一上色。
实现口径：`recipe` 允许 `input_dim` 指向**另一工坊的 `output_dim`**（半成品），
结算顺序按**拓扑序**（上游先结），而非 `state.workshops` 的字典序（现状即字典序，见 `for wid, ws in list(state.workshops.items())`）。

### 8.3 联动二 · 同源争抢的仲裁

绢坊/绫罗坊/紬坊共用生丝时，按**配给制**而非先到先得：

- 每个工坊登记**原料需求权重**（如 绢坊 0.5 / 绫罗坊 0.3 / 紬坊 0.2）；
- 共享原料池按权重**同时**分配（`Σ分配 == 池存量` 精确守恒，尾差归权重最大者）；
- 分配不足时按权重**同比例欠产**（而非先到先得的随机全停）—— 保证产出结构稳定、玩家可预期。

⚠️ **守恒硬约束**：任一原料维的**月分配总量 == 池存量**，且 `Σ各坊实际消耗 <= 池存量`，
差额只能是「未被领用」的余量，**不得凭空造料**（对齐 §3 的 A-4 教训：曾因产出无买方而凭空造币）。

### 8.4 联动三 · 联产与副产物

宋代工坊多有**一物带两产**：`WORKSHOP_RECIPES` 现只支持**单 output**，须扩为 `outputs{}`：

| 工坊 | 主产 | 副产 | 说明 |
|---|---|---|---|
| 蚕坊 | 茧 | 蚕沙(→肥料) | 养蚕必产蚕沙 |
| 糖坊 | 糖霜 | 蔗渣(→燃料) | 榨蔗剩渣是主要燃料 |
| 畜栏 | 肉 | 皮(→鞣制原料) / 骨 / 粪(→桑田肥料) | 现有 `meat` 单产 |
| 麻坊 | 布 | 麻秆(→燃料/纸料) | |
| 竹器坊 | 席/簟 | 竹屑 | |

副产物让链条**闭合**：皮 → 毡坊/鞣坊 → 毡，与 §二 的皮毛组对接。

### 8.5 联动四 · 缺失工序补全

现有链**跳过了**几个必经工序，补上才自洽：

- **缫丝坊**（茧→生丝）：否则「丝」既当原料又当半成品，桑→丝凭空。
- **纺纱**（生丝→纱）：绢/绫/紬的真实前置。
- **染坊**（白绢/白绫/白紬 → 成品）：**全线共用**，且需染料原料（蓼蓝/红花/栀子），
  这解释了贡物里**红花、胭脂、胡红花**为何是原料而非成品。
- **抄纸坊**（楮/麻/藤 → 纸）：造纸需多道（浸沤→抄造→晾焙），非一步。
- **煎药坊**（诸药材 → 炮制药）：贡物里的人参/甘草/茯苓是**生药**，炮制后才是商品。

### 8.6 联动五 · 产出落地州府（与 G-2 汇流）

工坊产出**必须落州府桶**而非全局池：`goods[治所][成品维]`（工坊所在治所）。
这让「川峡产蜀锦、江南产罗绫」成为可读的事实，并使 G-2 的治所级差异化有消费出口。
🔴 现状 `_POOL_DIMS` 全局汇总是**必须拆除**的一环 —— 否则州府桶永远只有原料没有成品。

### 8.7 联动的实现分期

| 期 | 内容 | 前置 |
|---|---|---|
| L1' | **配给仲裁**（同源争抢）：recipe 加工料需求权重，同比例分配 | G-6-L1 |
| L2' | **多级串联**：recipe 支持指向另一 output_dim，按拓扑序结算 | L1' |
| L3' | **联产副产物**：`outputs{}` 支持一主多副 | L2' |
| L4' | **补全工序**：缫丝/纺/染/抄纸/煎药 | L3' + 原料维扩充 |
| L5' | **产出落州府桶**，拆全局 `_POOL_DIMS` | L4' + **G-4** |

⚠️ **L5' 依赖 G-4**：工坊走市场采买原料后，产出才可能同时落州府；
若在 G-4 之前做，仍是暗管道，联动的意义被架空。

**守恒验收（三条，须进回归）**：
1. 任一原料维：Σ各坊月消耗 <= 池存量，差额 == 未领余量；
2. 串联链：上游产出量 >= 下游消耗量（缺料时下游停产**不产生**凭空半成品）；
3. 全链 Σ(投入) == Σ(产出) 按配方系数守恒，无凭空造料/造币。

**一句话**：扩链只是加法，**联动才是乘法** —— 没有仲裁会乱序，没有串联会压扁工艺，
没有副产物链不闭合，没有州府落地则前面全部白做。
