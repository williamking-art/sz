# POP 改良方案：阶层、经济归属与政治派系（2026-10-05）

> **目的**：独立收敛 POP 的分类、人口子池、产业经营关系、货物货权、政治派系和家计税务之间的边界，形成可供后续实现的分批方案。
> **状态**：设计方案，未实施。它补充并校正 [`POP家计与赋税体系设计_2026-10-04.md`](POP家计与赋税体系设计_2026-10-04.md) 中将经济经营类型称为 `faction` 的表述；家计、三税三基、科举正交等已裁定规则仍以原专题文档为准。
> **当前代码事实**：游戏已有六类 POP、农户职位/丁口/隐户、士绅家产、官吏身份子池，以及一套独立的政治派系影响力模型。新经济归属层尚未实现。文中不提供缺乏史料依据的份额或税率。

## 1. 先把五个概念拆开

“农民属于什么派系？”容易把人口身份、经营方式和政治立场混成一个字段。建议每个概念只回答一个问题：

| 层 | 回答的问题 | 建议字段/载体 | 是否计入人口 | 是否决定货权 |
|---|---|---|---:|---:|
| **阶层/职位** | 这个人主要以什么身份谋生？ | `cls`：农、士绅、商人、官僚、兵、工匠；农的职位细分沿用现有切片 | 是，六类总人口的分区 | 否，不能单凭职业推货主 |
| **家计等第** | 这个家庭/人口切片的财力状况如何？ | 从家计计算派生的五等读数 | 否，是读数不是第二份人口 | 否 |
| **经济归属/经营关系** | 该人口切片处于哪种生产、租佃或经营关系？ | POP 下的互斥经济切片 `economic_affiliation`；没有依据时为 `unclassified` | 是；子切片人数之和必须等于父 POP | 仅当合同或制度明确指定时，提供货主解析线索 |
| **政治派系** | 此群体支持哪种政治网络、其影响力和满意度如何？ | 现有 `state.factions` 与 `FACTION_POP_BASIS` / `FACTION_SPLIT_INIT` | 不另增人口；按 POP 基数派生，可有交叠 | 否 |
| **账户/货权** | 钱、粮、商品最终记在哪个主体名下？ | POP 切片账户、州库、内帑或明确的经营主体账户 | 否 | 是，唯一裁定货权的账本层 |

核心裁定：代码中的 `faction` 已指政治派系（新党、旧党、皇党集团、军功集团、中立派）。经济经营类型不得再占用此名。推荐使用 `economic_affiliation` 表示 POP 内互斥经济切片；生产批次使用 `operating_regime`；库存账户保留明确的 `owner_id`/`holder_kind`。政治派系不参与 `resolve_holder`。

## 2. 推荐的 POP 结构

```text
POP[州府][cls]
  ├─ 基础人口与资产：size / ding / kou / wealth / grain / goods
  ├─ 既有人口切片：农的职位、官僚身份、士绅宗族等（遵守各自口径）
  └─ economic_affiliation[关系键]
       ├─ size、wealth、grain、goods 等可归属的同类账项
       └─ source / confidence / effective_date（来源与适用范围）

政治视图：state.factions ← 根据政治基数与分配规则聚合 POP，不反写人口和货物账户
产业视图：生产者/合同/批次 → operating_regime + owner_id → 唯一收入及库存账户
```

### 2.1 经济切片的挂载规则

1. 经济切片是其父 `POP[州府][cls]` 的**分区**，不是新增人口账本；每个成员在同一口径下只能落入一个经济关系切片。
2. `Σ child.size == parent.size`；适用的 `wealth`、`grain`、`goods` 等可拆资产也须满足子项合计等于父项。只有标明为派生镜像的字段可只读聚合。
3. 现有 `hidden` 是加法型、非在籍人口，`estate*` 是货币/家产字段，官吏职位等也有自己的恒等式；不得因引入经济切片而把这些不同语义塞进通用人口池白名单。
4. “庄园”“官营”“民营”“租佃”“自营”等是经营或产权关系候选值，不预先假设每一类都适用于六个阶层。某类不适用时不造空池。
5. 份额来源缺失时保留 `unclassified` 或 `None` 并标出数据缺口；禁止均摊、默认为民营、或从政治派系反推。人口总量可以已知而归属比例未知，两者要分别表达。
6. 人口和资产转移须走统一的迁移接口，迁移人数时按同一来源切片搬运对应资产；不能只改 `size` 后再由兜底比例重造财富。

### 2.2 经济归属值建议

值表应从“可执行关系”出发，不按想象中的社会身份无限扩张：

| 键 | 含义 | 适用例 | 默认货权 |
|---|---|---|---|
| `household_self` | 家庭自营/家庭副业 | 自耕农户、农户蚕桑麻纺 | 家庭 POP 切片，须核具体制度/产物 |
| `tenant_household` | 租佃家庭 | 佃农经营田亩、交租后保留份额 | 按租佃合同拆分；不能把全产出给佃户或地主 |
| `estate_operator` | 庄园/地主经营 | 庄园雇工、庄园自营或委托生产 | 依土地权和雇佣/分成规则指定账户 |
| `state_operator` | 州县/官府经营 | 官田、官营工场等 | 州库或明确的官营经营账户 |
| `imperial_operator` | 皇室经营 | 皇庄、御苑、内诸司掌管的山泽珍异 | 内帑/内库账户 |
| `unclassified` | 目前材料不能确定 | 迁移旧档或史料未覆盖的生产关系 | 不允许自动售卖；待归属明确后才能结算 |

这些值描述的是 POP 所处的稳定关系；具体生产批次仍要注明使用哪项制度、哪块田产/工坊及适用规则。不能仅凭“农 + 庄园”推导某州府全部果木都属于士绅。

## 3. 阶层、政治派系和经济归属怎样互相作用

### 3.1 阶层是经济与社会统计的主分区

保留现有六类权威集合。阶层迁移表示职位/身份变化，例如科举入仕、入伍、致仕、就业转岗。类内的自耕、佃作、雇工等差异放在职位或经济归属子层，不增设第七类 POP。贫富变化通过家计及等第读数体现，不把“富农/贫农”等财力层级误建成与阶层平行的总人口。

### 3.2 政治派系是对人口的政治读数

沿用现有政治模型：派系有影响力、满意度、凝聚力、领袖等政治状态；其人口基数由 `FACTION_POP_BASIS` 和分配比例从相关 POP 派生。政治派系可以跨阶层，且彼此可能重叠，因此不是互斥 POP 子池，也不能把各派系人数相加后写回总人口。

政治派系影响政策支持、朝局和政治事件；它不决定谁拥有丝、粮、工坊或现金。例：旧党可从官僚与士绅基数形成政治影响，但“旧党”不能因此成为库存账户或收取商税的主体。

### 3.3 经济归属是人口切片，政治归属是派生政治关系

一个官营佃户仍是农阶层，经济切片可为 `tenant_household`；他对政治派系的归属仍按现有政治基数规则计算。政治派系变动不会移动其人口、财富、商品或田亩。经济关系变化（如自耕转佃）则必须在 POP 子切片间迁移人数及相应资产；除非规则明文规定，不自动改其政治支持。

## 4. 商品链、产地与 POP 账户的连接

商品目录负责说明“哪里可产什么、加工成什么”；POP 方案负责说明“谁生产/经营、产出归哪个账户”。中间必须有生产批次或明确的供给记录，不从州府特产清单直接推导某个阶层的持有量。

| 产业情形 | POP 身份 | 经营关系/生产主体 | 货权与结算建议 |
|---|---|---|---|
| 家户丝、麻及家庭加工 | 农，按现有农职位切片 | `household_self` | 经证据确认后记家庭 POP 切片；投入、产出、损耗逐项守恒 |
| 佃户耕种官田/地主田 | 农 | `tenant_household` + 田亩权利人/契约 | 按约定分成分别入户、州库或庄园账户；没有分成参数不得整笔结算 |
| 官营盐铁 | 相关生产人口按实际职业建模；当前商品生产可先不虚构工人 POP | `state_operator` | 盐铁库存属于官营/州库账户，购买款进入同一账户；商人只在后续转售时持有贸易库存 |
| 皇庄、御苑或内诸司山泽产出 | 工作者仍按真实职位归类 | `imperial_operator` | 进内帑/内库相关账户，不能并入州库或普通士绅资产 |
| 商人跨区购入/转运 | 商人 | 实际贸易订单/商号 | 只有发生真实交易才暂持货物；商人不是产地资源的默认所有者 |

端到端唯一解析建议：

```python
resolve_holder(
    goods_id,
    producer_id,
    production_site,
    operating_regime,
    contract_id=None,
) -> HolderRef | Missing
```

`HolderRef` 必须只解析到一个账户：`pop_slice`、`state_treasury`、`imperial_treasury` 或有明确制度依据的经营账户。若一批产物依契约分成，应先拆成多个数量明确的批次，再逐批解析唯一货主；缺少货主或份额时返回缺失并阻止交易。产出、存货、销售收入和税基共用这套货权结果，禁止供给端、采购端各自猜收款人。

## 5. 与家计、税务、等第及科举的接口

1. **家计按真实 POP 切片聚合**：收入、消费、租、税、役归属到相应家庭/主体后，才可算家计；缺项是 `None`，不由政治派系或行业标签补值。
2. **等第从家计派生**：五等版籍为财力读数，不更改阶层或政治成员关系；士绅可贫、农户可富。
3. **赋役税**：沿用原设计的家计等第税基和身份豁免边界；政治派系不调整法定税额。若税制按丁征收，丁口按实际 POP/户籍关系统计。
4. **田赋税**：由占田亩数及田权/纳税义务人解析；经济归属帮助识别耕作者和契约，不替代田权。客户/佃户是否承担某项负担必须按规则显式指定。
5. **商税**：由真实交易额、货类和税率计算；商品的政治来源、货主阶层或家计等第不替代成交额税基。
6. **科举与职位流动**：保留离散身份跃迁与家计等第正交。流动接口迁移人数及归属资产；科举不自动把全家财产、产业货权或政治派系一并迁走。

## 6. 实施方案与决策顺序

### 批次 0：锁定字段语义与审计面（先行）

- 把旧设计中“派系=官营/民营/庄园”等表述标为过时术语，明确政治 `faction` 保留原义。
- 对现有 POP 字段登记语义：人口分区、加法人口、资产、镜像或派生政治视图。
- 盘点所有直接读写 `size`、`wealth`、`grain`、`goods`、田亩和 `state.factions` 的入口，列出需要挂接的迁移/结算路径。
- 输出旧档样本覆盖率；材料不支持的归属比例进入缺失清单，不填估计值。

### 批次 1：经济切片最小纵切片

- 只选一个材料充分、产物和货主规则清楚的商品链/州府做试点。
- 定义 `economic_affiliation` 子池结构和 `unclassified` 语义；确定该切片如何同步人口及可拆资产。
- 接入唯一 `resolve_holder`，验证同一批货从生产、库存、出售到收入入账的单一所有者路径。
- 确认州府 POP 汇总与路级镜像只读聚合；任何一层均不能产生重复人口/商品。

### 批次 2：迁移与通用生产合同

- 为全部改变 POP 人数的通道增加来源切片迁移；旧存档迁移幂等、有审计、无依据时保留未分类。
- 对租佃、官营和庄园等实际用到的关系逐个补制度规则、适用商品、货权及税费承担人。
- 对生产结果按商品维记录原料扣减、成品、损耗、副产品、账户转移；跨商品维不直接声称数量守恒，按配方单位/价值分别校核。

### 批次 3：家计与征税接线

- 把每种收入、家庭支出、租税役映射到 POP 切片或对应公库账户。
- 先用历史局面回放计算家计与五等分布；不在结构迁移批次同时调整经济参数。
- 田赋、赋役、商税分别从指定税基读取；政治派系状态仅影响政治机制。

### 批次 4：政治读数、界面和放行

- 验证 `FACTION_POP_BASIS` 仍由 POP 派生、可跨阶层、总人口不变；没有未经批准的个人政治标签持久化。
- 界面分别展示阶层/职位、经济关系、家计等第、政治支持和资产货主；缺失值明示“未知/未登记”。
- 做旧档迁移、月结守恒、交易货权、税基隔离、长局回放与差异解释；满足门槛后再扩大商品/地区覆盖。

### 需要保留的明确裁决点

| 裁决项 | 本方案建议 | 仍需证据或后续裁定 |
|---|---|---|
| 经济关系是否命名为 faction | 不用；政治 `faction` 是既有且稳定的概念 | 无 |
| 经济关系是否做成 POP 切片 | 只有稳定且互斥的人口关系才做切片；经营订单/产权变化放在生产关系对象 | 每个关系的社会范围和历史份额 |
| 商人是否默认持有产地商品 | 否；仅有真实采购/贸易后成为持货者 | 商贸链和库存时序 |
| 官营盐铁是否伪造“官阶层 POP” | 否；职业人口有数据时按实际阶层登记，货权直接在官营账户 | 是否需要独立官营经营主体 |
| 佃户/庄园产出怎样分成 | 依据田权、租佃/雇佣规则显式配置 | 具体地区、商品和时期；缺失时不结算而非猜份额 |
| 州府特产能否直接变成 POP 库存 | 不能；目录只给候选产地/商品，实际库存需生产规则和货权记录 | 每链实际产量和覆盖优先级 |

## 7. 验收条件

- 六类 POP 总量与现有权威总人口口径一致；新增经济切片不增人、不丢人。
- 同一层级经济切片人数和可拆资产合计等于父 POP；各个人口迁移通道切片前后守恒。
- 政治派系的人口基数从 POP 派生，允许重叠但不反写 POP 总量；派系改动不会改变货主、税额或商品库存。
- 任一库存及收入均能追溯至唯一货主和生产/交易来源；未知货主不能静默当国库、商人或零值。
- 三税分别读取法定税基；等第只进入赋役路径，政治派系不进入任何税基。
- 旧档迁移可重复运行而不重复拆分/入账；未分类数据保持可见并可逐步补全。
- 至少一个州府商品纵切片通过人口、货物、货币及月结账本核对后，再推广到商品目录的其他链条。
