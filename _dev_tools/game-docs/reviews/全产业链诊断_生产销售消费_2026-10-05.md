## 二、🔴 三个结论

### ① 原料端：农户堆积 3,200 万，商人只吸收 1.4%

```
农户四维合计 ≈ 32,281,660
商人四维合计 ≈    444,510   （1.4%）
```

⇒ 民间售料腿**受商人财富封顶**（商人单月仅能动用 wealth 的 30%，且被买空）。

### ② 🔴 **成品端断流** —— 这是真正的堵点

```
官仓 布 1,080,000 + 工匠 布 562,950  = 1,642,950
商人 布                                  =       882   ← 0.05%
```

**商人有货栈（他们买了原料 44 万），却几乎不持成品。**
⇒ **成品批发环节缺失**：工坊/官仓的布绸**没有渠道流向商人**，
商人也就**无法零售给民间**。

### ③ 消费端吞吐极小

商人成品从月 1 的 836 到月 6 的 882 —— **基本不动**。
而工坊月产布 **180,000**。
⇒ 消费量级约为产出的 **0.5%**。

## 三、链条全景（标注堵点）

```
生产(月产布18万)  ──→  官仓/工匠(堆积164万)  ──✗──→  商人成品(882)
                                                            ↓ ✗
                                                        民间消费(≈0)

农家原料(堆积3200万) ──→ 商人原料(44万，受资金封顶)
         └──✗──→ 官仓(和买，只买当月需求×1)
```

## 四、⚠️ 修正我先前的判断

我此前说「**产出过剩**是根因」—— **只对了一半**。
全链看：

| 环节 | 状态 |
|---|---|
| 生产 | 过剩（月产远大于下游）|
| **销售（批发）** | 🔴 **断流** —— 成品无渠道到商人 |
| **消费** | 🔴 **吞吐≈0** —— 民间几乎不买 |

⇒ **不是单点过剩，是「销售/消费」两环不工作，导致生产显得过剩。**
**若消费正常，过剩量级可能本可消化。**

## 五、建议下一步（**先查消费**，而非调生产）

| 序 | 动作 | 理由 |
|---|---|---|
| 1 | **查民间消费链路**：民间 POP 是否购买布/绸？走哪条路径？ | 若消费≈0，调生产毫无意义 |
| 2 | 查**成品批发**：工坊成品是否有「售予商人」的腿 | 商人成品 882 说明断流 |
| 3 | 再评估「戊」（降产出）| **最后才做** —— 前两环通了，过剩可能消失 |

🔴 **修正结论**：先前建议的「戊（降产出量级）」**应排到最后**。
先修**渠道**（批发/零售），再谈产能。

## 六、附带修掉的一个真 bug

本次探针发现 **丙 的预算被单一维度吃光**：

```
修前 月6 商人原料：丝 151,454 / 麻 138 / 蔗 0 / 果 2   ← 麻蔗果被饿死
修后 月6 商人原料：丝  44,079 / 麻 191,001 / 蔗 83,298 / 果 126,132   ✅
```

原因：`budget` 在 `FARM_PROCURE_DIMS` 循环中**递减**，排第一的「丝」吃完 ⇒ 后者为零。
改为**按有货维度均分**。
