## 二、排序逻辑（为何 G 并行于 A）

原文档把 P1–P6 串行排在 P0 第 5 门（A）之后，逻辑是「不改定价口径就没法做地方经济」。
但本轮新增要求 **G**（全商品走市场）**绕开**这个阻塞：

- G 一旦把工坊从「全局直扣」拔出来接市场，**B 顺带解决** ——「按人口占比分派」不再需要分派，因为那是**真实交易**；
- 旧粮价（A）属于**旧路线定价模型**；新商品走**州府级市场定价**。二者**可以并存**，逐步替换而非一次切换。

⇒ 因此 G 的**批次 1、2 不依赖任何裁定，可立即开工**；A 作为独立一条线待裁定。

## 六·补 · G-6 产业链扩充（2026-10-03 用户追加，原计划遗漏）

**为何必须补**：用户指出「米麦是原材料啊，可以精加工的」与「所有商品都参与经济流转」，
隐含要求是**加工链本身要扩充** —— 只把既有 3 维成品接进市场，产业链仍是单薄的。

**现状缺口（实测）**：

```
FINISHED_DIMS   = ['绸', '布', 'wine']              # 仅 3 维
WORKSHOP_RECIPES: 丝坊 丝→绸 / 麻坊 麻→布 / 酒坊 grain_feed→wine / 畜栏 grain_feed→meat
```

🔴 **既有错位**：`畜栏` 的 `output_dim='meat'` **不在 `FINISHED_DIMS`**，故 `meat` 从不进 `GOODS_DIMS`；
且 `wine` 走酒课进内帑、不入仓（`RESOURCE_DIMS` 排除 wine）—— 成品口径三者不一致。

**扩充的数据依据（真实，非臆造）**：从《宋史·地理志》抽出 **195 条州级贡物 / 210 种物产**，
高频项如：绢14、麝香13、银10、紬9、甘草8、蜜8、绵8、蜡7、葛7、席6、白紬5、石斛5、苎布5、
甲香5、人参4、鹦鹉羽4、金4、高良姜4、柴胡3、纸3、藤纸3、朱砂3……

**分级策略（避免一次性膨胀）**：

| 级 | 内容 | 依据 |
|---|---|---|
| L1 修补 | `meat` 并入 `FINISHED_DIMS`；统一 wine/meat 的入库口径 | 纯修错位，无新数据 |
| L2 主链 | 茶→茶饼/糖霜、盐→盐花、麻→苎布、丝→紬/罗/绫、药材→成药 | 贡物高频项，直接对��� |
| L3 特色 | 按路特色：建茶（福建）、糖霜/胡椒（广南）、麝香/金（川峡）、瓷器 | 贡物路别差异 |

⚠️ **不做的**：不为凑数造无史料依据的加工品；映射不上的贡物（解玉砂、白磁盏等非商品维）**跳过并记录**，
不塞进 `FINISHED_DIMS`。

**建议插入位置**：G-6 的 **L1（修补 meat 错位）**成本极低且解一个既存不一致，可与 G-2 同批做；
L2/L3 待 G-4（工坊走市场）之后再做 —— 否则新工坊仍从暗管道取料，等于把旧问题放大。
