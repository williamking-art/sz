# 未落地设计裁定与实施路线

> 状态：当前有效的设计治理与实施路线（2026-10-11）。
> 范围：收口 game-docs 全目录审校结果，明确哪些设计已经落地、哪些只是基础设施、哪些仍需实施或裁定。
> 本文回答三个问题：怎么做、做什么、做到什么程度。本文不替代 docs 机制口径或 specs 任务证据。

## 一、状态口径

任何设计分五层判断：

1. 规则已定：用户口径、边界、非目标明确。
2. 数据/接口已建：结构、API 或读数存在。
3. 生产已接线：真实月结、命令或前端入口调用。
4. 账本闭合：钱、粮、货、人口、地点、税基有唯一去向。
5. 质量放行：定向测试、长局回放和全量回归通过。

只有达到第 3 层才能说“已接入”，只有达到第 5 层才能说“已验证”。

🟡 **未闭合**：`calc_region_grain_price`（`game/core/game_state_econ.py:292`）中 `wine_share` 与中央太仓分摊 `_gran_share` 仍以**全国** `self.population` 作分母——即**A-粮价债务**（`total_pop/factor/wine_share/gran_share` 四处耦合）尚未消除。后果：单路受冲击会经全国分摊份额带动其他路粮价，违反 P0 第 5 门（只冲击一路不应全图同变）。阻塞于主线 B「地方府库下沉」（需州府级太仓真账作载体）。

## 三、必须实施的主线

### 主线 A：POP 守卫生产化

现状（2026-10-11 核实·✅ **已接线**）：守卫机制**已实现**（`pop_bridge.install_all_guards` / `pops_guard_violations` / `uninstall_pops_guard`），**测试已接线**（`test_route_pops_readonly_guard.py` 覆盖默认/single_whip/高城市化/组合场景、跑满 15 月零违规、镜像零失配），且**生产月结入口已接线**。

怎么做的（2026-10-11 落地）：接线点选 **`core/commands.settle_local`**（`settle_turn` → `settle_local` → `run_monthly_settlement` 的**唯一生产入口**，覆盖 sync `settle_turn` / `advance_and_settle` / async `_async_settle` / backend client 全部生产面）；**未选** `run_monthly_settlement` 本体——它有 AST 内省测试（`test_middle_calibration`）比对函数体内所有 `_` 前缀调用镜像，改动必触发。装/卸配对：结算前 `install_all_guards`，结算后读违规汇总写 log，`finally` 里 `uninstall_pops_guard` 把路级 `pops` 还原为普通 dict（不污染存档、不污染后续玩家操作）。开关用环境变量 **`SONGZUO_POPS_GUARD`**（缺省关闭，打开才装守卫），不改默认数值行为。失败快照 `_snapshot_state` 用 deepcopy 且取在装守卫**之前**，异常回滚时守卫子类随 `prefectures` 整体替换自然失效，不引入新失败模式。

做到什么程度：守卫**不硬中断**（与 §4 一致，记录型）；违规含字段、路、函数、文件、行号并汇总进月结 log；15 月及更长回放零违规、镜像零失配。验证：新增 `test_prod_pops_guard.py`（4 例，含 monkeypatch 注入直写证明守卫非空转、env 缺省关闭不改数值、装/卸配对还原）+ 回归 3 个直调 `settle_local` 的既有测试，共 **47 passed / 0 failed（364.6s）**。已知剩余写点已桥接化：`foundation/registries.py`（`_pay_equip_and_grain` 兵 POP 粮饷，原路级 `wealth` 直写）已改走 `pop_obj_add` 桥接（下沉局真账落 `seats`、再刷镜像，未下沉回落直写）。**读数面板**（把违规汇总接前端可见）属 §4 范畴，尚未接线——可作下一轮。

### 主线 B：州府级物理状态

顺序固定为：POP（已完成）→ 建筑下沉 → 交通下沉 → 地方府库下沉 → 仓储/商品存量 → 真实交易与州府价格。

🔴 **硬阻塞提示（2026-10-11 核实·已更新）**：其中「地方府库下沉」此前因 `specs/economy/地方府库下沉州府级_阻塞记录.md` 记载的「新局 20 路 `seats` 全空（0/20）」被判为硬阻塞。**但该记载已过时**——H 裁定甲后 POP/粮下沉已完成，生产主路径 `new_game()` 下的**新局 20 路全部有 `seats` 真账**（实跑 `settle_local` 全管线可装守卫 20 路、月结零违规，已由 `test_prod_pops_guard.py` 验证）。因此「地方府库下沉」的 `seats` 载体前置**已满足**，可推进；A-粮价债务（§2.2）仍需地方府库真账闭合才能解。建筑/交通下沉若其颗粒也需要 `seats` 载体，同样已具备前置。

不得先把州府交易挂在路级生产、建筑、交通或库存上，也不得按人口比例伪造地点、货主或资产。每批都要有唯一真账、路级聚合、旧档迁移、真实接线和守恒回归。

### 主线 C：生产率与经济作物

建立一作物一建筑（桑田、麻田、果园、蔗田、茶园），由在岗农户、建筑等级和已实现生产率因子共同决定产出。CASH_CROP_LAND 只作校验/平衡基准，不建第二份生产账。

做到什么程度：每月产出可分解为在岗人数、单位基数、等级系数和已生效因子；缺失因素显示未计入；产出、工资、税收和库存守恒。

### 主线 D：G-4 工坊经营资金

先做影子预算，不接正式结算。实际货主从已有账户划入营运资金，先冻结工资义务，再冻结采购预算；成交才扣款，到货后加工，有买方才记销售收入，工资不足记欠付。

做到什么程度：资金来源、地点、货主、工资、采购、到货、销售都可追踪；M_ALL 守恒；无 owner、余额、买方或地点时停工或显示未定义。

### 主线 E：家计、经济归属与税制

建立州府 × POP 类别 × 生产关系的 economic_affiliation，份额和必须等于父 POP；无史料部分保留 unclassified。家计等第先影子校准；田赋按占田，商税按真实交易，赋役才使用等第。

### 主线 F：市场与外贸

先做一个真实地点、货主、商品、路线、买方的最小州府市场切片，再扩展全商品、工坊投料、外贸和远方市场。必须完成产地—运输—成交—到货—加工链条的守恒和缺失诊断。

## 四、明确暂不实施

invest_decide 在没有真实产出/收益账户前不接线；不新增 TREASURY_HOARD 平行账户；复述门暂不接诏令主链；POP 守卫暂不硬失败；水泥/钢筋不实现；外邦复杂产业链暂不排期。

## 五、文档治理

当前机制以 docs 为准，专题实施以 specs/*/tasks.md 为准，跨专题裁定以 TODO_状态总账与裁决落地与分批计划为准。历史 archive 和 analysis 不作为当前状态。旧稿与现状冲突时不改历史正文，在现行状态表记录已过期并附代码/测试证据。
