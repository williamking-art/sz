# 未落地设计裁定与实施路线

> 状态：当前有效的设计治理与实施路线（2026-10-11）。
> 范围：收口 game-docs 全目录审校结果，明确哪些设计已经落地、哪些只是基础设施、哪些仍需实施或裁定。
> 本文回答三个问题：怎么做、做什么、做到什么程度。本文不替代 docs 机制口径或 specs 任务证据。

## 一、状态口径

任何设计分五层判断：

1. 规则已定：用户口径、边界、非目标明确。
2. 数据/接口已建：结构、API 或读数存在。
3. 生产已接线：真实月结、命令或前端入口调用。
4. 账本闭合：钱、粮、货、人口、地点、税基有唯一去向。
5. 质量放行：定向测试、长局回放和全量回归通过。

只有达到第 3 层才能说“已接入”，只有达到第 5 层才能说“已验证”。

## 二、已经落地的基础

### 2.1 POP 州府真账

已完成新局/读档 seats 真账、路级派生镜像，以及 wealth、grain、hidden、欠税、家产、身份子池、宗族、城市化、回乡和就业流动的主要桥接。默认、single_whip、高城市化和组合经济压力回归均已覆盖。

放行标准：州府真账唯一可写；路级聚合逐字段一致；POP 守卫、人口、财富、粮食守恒成立。

### 2.2 经济决策与路线粮价

AI 只输出经济档位，程序计算人口、财富、粮食和价格；路线粮价需求按本路在籍人口加本路农.hidden；全国酒耗和中央太仓按在籍人口份额分摊。相同初局只改变城市化档位的 12 月对照和 60 月实跑均产生可测 POP/粮价差异。

### 2.3 兼容缓存与界面

别名缓存已改为原地清空/更新；州路多页面抽屉、共享单军档案、单军月饷/月粮读数已接入。

## 三、必须实施的主线

### 主线 A：POP 守卫生产化

怎么做：补齐已知写点；在月结入口安装记录型守卫；每回合汇总来源；用默认、single_whip、高城市化和组合场景连续回放。

做到什么程度：守卫不硬中断；违规包含字段、路、函数、文件和行号；15 月及更长回放零违规、镜像零失配。

### 主线 B：州府级物理状态

顺序固定为：POP（已完成）→ 建筑下沉 → 交通下沉 → 地方府库下沉 → 仓储/商品存量 → 真实交易与州府价格。

不得先把州府交易挂在路级生产、建筑、交通或库存上，也不得按人口比例伪造地点、货主或资产。每批都要有唯一真账、路级聚合、旧档迁移、真实接线和守恒回归。

### 主线 C：生产率与经济作物

建立一作物一建筑（桑田、麻田、果园、蔗田、茶园），由在岗农户、建筑等级和已实现生产率因子共同决定产出。CASH_CROP_LAND 只作校验/平衡基准，不建第二份生产账。

做到什么程度：每月产出可分解为在岗人数、单位基数、等级系数和已生效因子；缺失因素显示未计入；产出、工资、税收和库存守恒。

### 主线 D：G-4 工坊经营资金

先做影子预算，不接正式结算。实际货主从已有账户划入营运资金，先冻结工资义务，再冻结采购预算；成交才扣款，到货后加工，有买方才记销售收入，工资不足记欠付。

做到什么程度：资金来源、地点、货主、工资、采购、到货、销售都可追踪；M_ALL 守恒；无 owner、余额、买方或地点时停工或显示未定义。

### 主线 E：家计、经济归属与税制

建立州府 × POP 类别 × 生产关系的 economic_affiliation，份额和必须等于父 POP；无史料部分保留 unclassified。家计等第先影子校准；田赋按占田，商税按真实交易，赋役才使用等第。

### 主线 F：市场与外贸

先做一个真实地点、货主、商品、路线、买方的最小州府市场切片，再扩展全商品、工坊投料、外贸和远方市场。必须完成产地—运输—成交—到货—加工链条的守恒和缺失诊断。

## 四、明确暂不实施

invest_decide 在没有真实产出/收益账户前不接线；不新增 TREASURY_HOARD 平行账户；复述门暂不接诏令主链；POP 守卫暂不硬失败；水泥/钢筋不实现；外邦复杂产业链暂不排期。

## 五、文档治理

当前机制以 docs 为准，专题实施以 specs/*/tasks.md 为准，跨专题裁定以 TODO_状态总账与裁决落地与分批计划为准。历史 archive 和 analysis 不作为当前状态。旧稿与现状冲突时不改历史正文，在现行状态表记录已过期并附代码/测试证据。

## 六、执行顺序

1. 文档状态收口。
2. POP 守卫生产化。
3. 建筑、交通、地方府库州府化。
4. G-4 影子预算。
5. 生产率与经济作物岗位化。
6. 家计等第与经济归属影子校准。
7. 最小州府市场切片。
8. 外贸与远方市场。
9. 封桩战略选项、复述门和事件危机链。

每阶段必须产出口径说明、代码调用链、守恒断言、定向测试、必要时的 60/240 月回放和前端可解释读数。
