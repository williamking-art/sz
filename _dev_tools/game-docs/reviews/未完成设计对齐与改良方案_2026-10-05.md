## 1. 统一判断规则

每项设计要分开回答五件事，不能用一个“完成”覆盖：

1. **规则已定**：产品口径和边界是否确定。
2. **数据/接口已建**：结构存在不代表生产路径调用。
3. **生产已接线**：有真实调用者且对权威账本生效。
4. **账本闭合**：钱、货、人口、地点和税基均有唯一来源与去向。
5. **质量放行**：定向回归、长局和平衡已通过。

`docs/`写确认口径与当前行为；`specs/*/tasks.md`记录逐项状态与证据；`reviews/`留对齐、取舍和历史复核；`analysis/`只保留探索。旧文件继续作为出处，但若与本页冲突，先按下表校正对应任务状态，再以代码和最新交接为准。

3. 按三个独立税基接入：赋役=等第/应役人口；田赋=占田；商税=交易额/商品税率。客户端田赋豁免不得被等第或商业税逻辑覆盖。
4. 科举身份与家计并行；升迁只通过人口移动入口，确保财富和物品随人移动或显式结算。
5. 每阶段增加迁移前后总量对账和长局校准；金额参数另批裁定。
