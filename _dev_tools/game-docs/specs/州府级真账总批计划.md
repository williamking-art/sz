## 三、字段分类（**哪些该下沉**）

### A 类：**应下沉治所**（有地理差异，路级聚合是失真）

| 字段 | 理由 |
|---|---|
| `pops` | **已裁定**（方案乙）；且影响 3417 条/月直写 |
| `buildings` | **已裁定**（交通是州府级）；且被 4 系统共用 |
| `land` / `self_farm_land` / `gentry_land` / `official_land` / `imperial_land` / `hidden_land` | **田亩是地理实物** |
| `grain` / `storage` / `changping_stock` | **仓储是地点性实物** |
| `grain_yield` / `grain_price` | **产出与价格有地区差** |
| `households` / `population` | 人口地理分布 |
| `city_defense` / `unrest` / `mood` / `public_support` / `refugees` | **治安有地区差** |
| **交通（canal_block / 水路 / 道路）** | **本次裁定** |

### B 类：**可保持路级**（行政属性，本无治所差异）

| 字段 | 理由 |
|---|---|
| `officials` / `clerks` | 编制按路设（但**岗位可在治所**，待议）|
| `fiscal` / `local_finance` / `local_treasury` | **路级财政**（行政层级）|
| `govern` / `pay_ratio` / `orgs` | 路级治理参数 |
| `monthly_tax` | 路级税额（可派生自治所）|
| `name` / `type` / `is_capital` / `controlled_by` / `route_mult` | **元数据** |
| `rename_log` / `gap` | 元数据 |

⚠️ **B 类不等于「不动」** —— 若其**计算依赖 A 类**（如 `monthly_tax` 来自田亩），
则需改为**从治所聚合**（成为派生）。

## 五、分批实施

| 项 | 内容 |

| 0.3 | **守卫上生产**：`install_all_guards` 目前**仅测试调用** ⇒ 接入结算入口 |

### 批次 1：**交通下沉**（最小、最独立）

## 六、每批的验收

| 批 | 验收断言 |
|---|---|
| 0 | 字段读写清单齐备；守卫能**当场炸掉**绕过桥接的直写 |
| 1 | 治所 `canal_block` 可独立变化；路级为**精确聚合**；粮价**逐路**响应 |
| 2 | `buildings` 落治所后，**四个消费者行为等价或显式变更**（有回归）|
| 3 | **新局 `seats` 非空**；结算**零未桥接直写**；**镜像 0 失配** |
| 4 | 同 2/3 |

🔴 **每批均须：改动清单 → 定向回归 → 放行门 + 全量（串行）**（承 §3-4）。
