## 二、🔴 阻塞：**`seats` 在新局全部为空**

```
routes with seats = 0 / 20
```

⇒ 治所级真账**无处可放**。若强行下沉：

| 后果 | 说明 |
|---|---|
| **地方库的钱无处可存** | 结算写入将失败或丢钱 ⇒ **守恒破裂** |
| 路级变派生后无源 | 路级 `local_treasury` 降为 Σ 治所，而治所**为空** ⇒ Σ=0 |

⇒ **这与《州府级真账》批次 3 是同一个前置**：
**新局即建 `seats`** —— 该项此前尝试过，功能成功（117 治所）但**全量 EXIT=1（15 失败）已回退**。

```
新局即建 seats（甲方案批次 3）
```
