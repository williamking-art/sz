## 二、🔴 关键洞察：士绅的「非经济回报」**是有实质政治意义的**

```
\u58eb\u7eb3 \u4fee \u5b66\u587e / \u4e49\u4ed3 / \u6865 / \u5b97\u7960
   \u21d2 gentry_resistance \u2193\uff08\u58eb\u7eb3\u6ee1\u610f\uff09
   \u21d2 public_support   \u2191\uff08\u6c11\u671b\uff09
   \u21d2 \u8be5\u8def\u66f4\u7a33\u5b9a\u3001\u7a0e\u57fa\u66f4\u7a33\u3001\u6297\u547d\u66f4\u5c11
```

⇒ **这不是「虛拟好感度」，而是「地方影响力的实质提升」** ——
**史实亦如此**：宋代士绅通过**义仓/学塾/修桥**积累乡里声望，进而影响地方治理。

⇒ ⚠️ **故 `gentry_resistance ↓` 本身就是士绅的真实收益**（政治收益），
**不需要另设一个抽象的「声望值」**。

## 三、三条通道 → 回报映射

| 通道 | 经济回报 | **非经济回报（落点）** |
|---|---|---|
| **民间·士绅** | 田产增产（若陂塘）| **`gentry_resistance ↓`** + **`public_support ↑`** |
| **民间·商人** | 商路收益·过路费 | **`public_support ↑`**（商誉）+ 本路 `mood ↑` |
| **民间·农户** | **直接增产**（多为经济工程）| （多数不需非经济回报）|
| **地方政府** | `local_treasury` 税基 ↑ | **本路 `public_support ↑`** + 上级考核 |
| **国家** | `treasury` | **`prestige ↑`**（皇威）+ 全局战略指标 |

### 3.1 效用函数（建议形式）

```python
def private_utility(channel, cls, project, state, route):
    econ = project.net_value(state, route)          # \u73b0\u6709\u6210\u672c/\u6536\u76ca\u53e3\u5f84
    if channel == "state":
        return econ * W_STATE_ECON + project.strategy_value(state) * W_STATE_STRATEGY
    if channel == "local_gov":
        return econ * W_LOCAL_ECON + project.public_good(state) * W_LOCAL_PUBLIC
    # \u6c11\u95f4
    pg = project.public_good(state)                 # \u516c\u5171\u54c1\u4ef7\u503c\uff08\u5916\u90e8\u6027\uff09
    return econ + pg * SOCIAL_WEIGHT.get(cls, 0.0)  # \u5404\u9636\u5c42\u504f\u597d\u6743\u91cd
```

⚠️ `SOCIAL_WEIGHT` **须逐阶层可解释**（如士绅高、商人中、农户低），
**不得用一个笼统系数**。

## 五、🔴 与「甲方案（治所级）」的衔接

⇒ 承甲方案 ⇒ **应下沉到治所级**：

