1. 上述两份 `docs/` 文档 —— 设计与需求的唯一权威。
2. 本目录 `tasks.md` —— **只**承载"怎么做、做到哪、怎么验收"；若与 `docs/` 冲突，以 `docs/` 为准并回改本文件。
3. 前序规格 [`../market-civilian-economy/tasks.md`](../market-civilian-economy/tasks.md) —— B0–B5 已完成批次及其未闭合项（本专题承接）。

- **开工门（§14.1）**：先按「定义存在 / 已接线 / 账本闭合 / 长局校准 / 玩家可观察」五态核实，
  **禁止把"有代码"当"已落地"**；不得因设计稿写了同一机制就重写一遍。
