### 🔴 为何不可用

| 问题 | 说明 |
|---|---|
| **两浙路仅 31km** | 而两浙是宋代**水网最密**之地（太湖/钱塘江/**江南运河**）|
| **荆湖南路 = 0** | 而**湘江**纵贯全路 |
| **淮南东路 = 0** | 而它在**淮河/运河**沿线 |
| **京畿路取到黄河** | 而它的漕运主干是**汴河**，非黄河 |

⇒ **Natural Earth 1:1000 万**收录的是**现代大河**，**不含宋代漕运水道**（汴河/江南运河/湘江/赣江/闽江）。
**⇒ 此路不通，不可据以填表。**
