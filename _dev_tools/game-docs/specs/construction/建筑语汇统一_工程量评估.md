## 一、两侧表实测（真实键，非推断）

### 宋侧（`core/building_jobs.py` 模块级表）

```
SONG_JOB_CLASSES     = ('农', '工匠', '商人')                    # JOIN 阶层 3 类
SONG_JOBS_PER_LEVEL  = ['农田','自耕农庄','地主农庄','工坊','商铺','庄园']   # 建筑 6
SONG_POSITION_CLASS  = ['自耕农','富农','贫农','佃农','地主','工匠','商人'] # 职位 7
SONG_BUILDING_WORKER                                   # 建筑→职位
造价：无 BUILDING_COST，走 BUILDING_STD[名].base_cost × 1.8^(lv-1)
```

### 外邦侧（`content/data_external.EXTERNAL_ECON`）

```
BUILDING_TYPES_EXT     = ['粮田','桑麻田','林果蔗田','牧场','矿场','工坊']  # 建筑 6
BUILDING_TYPES_EXT_LEGACY = ['农田','牧场','工坊','商铺']                  # 旧名 4
BUILDING_WORKER        = 5 项（**缺「粮田」**，粮维豁免岗位制）
BUILDING_POSITIONS     = ❌ **不存在**
POSITION_CLASS         = ❌ **不存在**
PER_WORKER_OUTPUT      = 按**政权类型**（游牧/党项/西南/default），非按建筑
BUILDING_COST          = 6 项；growth 1.35；UPGRADE_PROB 0.05
```

## 二、差异矩阵与难度

| 维度 | 宋侧 | 外邦侧 | 统一难度 |
|---|---|---|---|
| 机制链 | 建筑×lv→岗位→就业→产出→工资→破产 | **同一条链** | ✅ **机制已一致** |
| 建筑命名 | 农田/自耕农庄/地主农庄/工坊/商铺/庄园 | 粮田/桑麻田/林果蔗田/牧场/矿场/工坊 | 🟡 **仅「工坊」共有**，其余全不相交 |
| **职位→阶层** | `SONG_POSITION_CLASS`（7 职位） | 🔴 **无该概念** | 🔴 **最大缺口** |
| 产出率 | 按建筑配方 | 按政权类型 | 🟡 中 |
| 造价表 | `BUILDING_STD.base_cost`×1.8 | `BUILDING_COST`×1.35 | 🟡 低（数值差异**允许**）|

## 三、🔴 关键发现：**差异层接口已设计好，只是外邦侧没接**

`docs/主要国家与外邦设定分层.md:155-156`：

```
🔴 POSITION_CLASS（职业→POP 类）即「差异层」接口 ——
底层机制各国一致，职业映射到哪个阶层由各国自定。
```

⇒ **架构上「机制统一 + 差异层」这条路已经铺好**；
⇒ 统一工作 = **给外邦侧实现 `POSITION_CLASS` 差异层**，而不是重写机制。
⇒ 且 `:143` 已确认：「**已具备 V3 式要素**：建筑×等级 → 岗位 → 就业 → 产出 → 工资 → 破产」。
