## 一、🔴 前置事实：主要国家目前**没有**科技树

```
EXTERNAL_ECON 的 tech/blueprint 键 = ['REGIME_RES_SPOIL', 'REGIME_RES_SPOIL_METAL']  <-- 无科技
政权实体 辽 的字段: armies attitude grain grain_price growth_curve hidden_land internal_pressure
                  land monthly_tax name pop population power provinces rename_log
                  resources_regime storage treasury type unrest                          <-- 无 tech
state.tech 只存在于宋侧 GameState
```

⇒ 「科技树建筑是一样的」**当前无从谈起**，须先给主要国家建科技树。

## 三、可行性：主要国家具备承载条件

| 科技要素 | 主要国家是否有 | 证据 |
|---|---|---|
| 银/财 | ✅ | `treasury`（自有中央库藏）+ 各省 POP `wealth` |
| 人（士绅/工匠）| ✅ | `_ext_pop` 六类 POP（`game_state.py:302`）|
| 资源（铁等）| ✅ | `resources_regime` + `EXTERNAL_ECON` 的 `REGIME_RES_SPOIL*` |
| 时间推进 | ✅ | 月结算已在跑 `_settle_external_economy` |

⇒ **不需要新建机制**，只需**让政权实体持有自己的 `tech` 字典**，并接入同一套 `TECH_NODES` 推进。

## 四、最小方案（三步，建议分三批）

| 批 | 内容 | 风险 |
|---|---|---|
| **A** | 政权实体加 `tech` 字段（初始 level/各科技项），**只存储不推进** | 🟢 低 |
| **B** | 在 `_settle_external_economy` 里跑**科技推进**（按月扣银/时/月），效果接各自经济 | 🟡 中 |
| **C** | 解锁 `TECH_NODE_DEPLOY` 的 10 项建筑，**建筑表与宋侧统一** | 🟡 中 |

## 五、口径要点

- **差异层**：科技线**节点相同**，但**各国进度可不同**（这本身就是差异）；
- **数值可不同**（承「底层一致（数值不同）」），如研究速度；
- ⚠️ **不得**让主要国家科技**白嫖宋的 `state.tech`** —— 那是**两个平行账本**，
  违反挂载律，须各自持有。
