## 三、设计：**两个建造部门**

| 部门 | **劳力来源** | **付酬** | 适用工程 |
|---|---|---|---|
| **民间营造** | 雇工（`工匠` POP）+ 民间自建 | **付工钱** | 民产：陂塘 · 水碓 · 桥 · 渡 · 学塾 · 义仓 · 宗祠 |
| **官有营造** | **劳役（`应役丁`）** + 雇工 | **劳役不付工钱** + 雇工付钱 | 官产：漕渠 · 驿道 · 城池 · 堤防 · 官仓 · 边堡 |

### 3.1 🔴 核心：**役钱与劳役的关系（互补）**

```
\u5df2\u7eb3\u5f79\u94b1\u8005  \u21d2 **\u514d\u5f79**\uff08\u4e0d\u518d\u5f81\u53d1\u52b3\u5f79\uff09\u2014\u2014 \u94b1\u4ee3\u529b
\u672a\u7eb3\u5f79\u94b1\u8005 \u21d2 **\u53ef\u5f81\u53d1\u52b3\u5f79**\uff08\u51fa\u529b\u4ee3\u94b1\uff09
\u21d2 **\u4e8c\u8005\u4e92\u8865**\uff08\u94b1 \u6216 \u529b\uff09
```

⇒ **这正是「免役钱」的本意**（史实：纳钱免役）。

### 3.2 🔴 劳役的真实权衡

| 方式 | 成本 | 代价 |
|---|---|---|
| **雇工** | **付工钱**（贵）| 不扰民 |
| **劳役** | **不付工钱**（省）| **`mood` ↓**（`MUSTER_MOOD_W`，**扰民**）|

⇒ **省钱但伤民情** ⇒ **玩家/官府须权衡** —— 这是本设计的**核心玩法**。

### 3.3 劳役的规模约束

```
\u53ef\u5f81\u52b3\u5f79 \u2264 \u5e94\u5f79\u4e01 \u00d7 \u5f81\u53d1\u4e0a\u9650\u7387\uff08\u73a9\u6cd5\u8bbe\u5b9a\uff09
```

⚠️ **不得超征**（否则**误农时** ⇒ 应有额外惩罚）。
⇒ **上限率**与**误农时惩罚**待标定。
