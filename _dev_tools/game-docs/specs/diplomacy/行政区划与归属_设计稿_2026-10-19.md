# 行政区划与归属 · 分级数据设计稿（宋 + 外邦）

> 用户：「给各主要国家的州府级数据落地，其他的用省级或国家级，先出设计稿」→
> 「地域与政权分离，宋也是」→「先整理，因为设计上是有将州府级划到其他省，或新建省级单位的机制的」。
> **状态：设计稿，未实施**。实施阶段见 §11。

## 0. 一句话

行政区划是**三层可调结构**：`region`（地域单元，含等级/上级/owner/人口/土地）→ 省（T2）→ 州府（T1）；
**归属（owner）与层级（parent）分离**，两者都能变，但都只改**指针**、不动详账；
人口/土地/赋税随归属与层级走，**全程守恒**。

## 4. 数据形状（统一 `regions`）

```text
state.regions = {
  # 宋：路（T2）与州府（T1）；详账仍留 prefectures，这里只存指针
  song_jingji:           {level: "T2", name: "京畿路", owner: "宋", parent: "song",
                          prefecture_ref: {route: "京畿路"}},
  song_jingji_kaifeng:   {level: "T1", name: "开封府", kind: "府", owner: "宋",
                          parent: "song_jingji",
                          prefecture_ref: {route: "京畿路", seat: "京畿路|开封府"}},
  # 外邦：省（T2）与州府（T1）；人口/土地/建筑在本条目内
  liao_nanjing_dao:      {level: "T2", name: "南京道", owner: "辽", parent: "liao", ...},
  liao_nanjing:          {level: "T1", name: "析津府", kind: "府", owner: "辽",
                          parent: "liao_nanjing_dao", ...},
}
state.external_regimes["辽"]["territory"] = ["liao_nanjing_dao", "liao_nanjing", ...]
```

**每个 region 的字段**：

| 字段 | 含义 | 可变？ |
|---|---|---|
| `level` | `T1` / `T2` / `T3` | 可（改级，见 §6） |
| `name` / `kind` | 地名 / 府·州·京·道 | 可（改名/改治） |
| `owner` | **归属政权**（宋/辽/金…） | 可（占领/割让） |
| `parent` | **上级单元** id（T1→T2→`宋`/`辽`） | **可（改隶/分省/合省）** |
| `pop` | 6 类（size/wealth/grain） | 仅间接（人口流动） |
| `land` / `grain` / `buildings` / `center_lonlat` | 地域资产 | 仅建设/损耗 |
| `prefecture_ref` | 宋详账指针（外邦无此字段） | 不可变（详账不搬） |
| `changed_at` / `change_log` | 最近归属/层级变更 | 程序写 |

## 5. 归属（owner）与层级（parent）是两件事

| | owner（归属） | parent（行政层级） |
|---|---|---|
| 回答什么 | 这块地**属于哪个政权** | 这块地**归哪个省管** |
| 变更场景 | 占领、割让、和议归还 | 改隶、分省、合省、改治 |
| 谁发动 | 战争/外交结果（程序 + 事件） | **玩家诏令为主 + 天道给阻力评估**（Jev C 0.597） |
| 守恒 | 政权间转移：人口/土地随之（**地域不复制**） | 省内转移：**Σ省不变**（同一批州府换上级） |
| 失败后果 | 该地不入宋结算、计占领方收益 | 无（只是上级变了） |

> 🔴 **铁律**：`owner` 变更**不影响** `parent`；`parent` 变更**不影响** `owner`。两者只在**收复失地后重建行省**时同时变。

## 6. 行政区划调整机制（本轮新增）

### 6.1 四类操作

| 操作 | 说明 | 最小单位 | 常量约束 |
|---|---|---|---|
| **改隶** `transfer_seat` | 把州府从 A 省划到 B 省（`parent` 改） | T1 | A、B 须同 owner；A 省不得被划空（可配 `allow_empty`） |
| **分省** `split_province` | 从 A 省拆出新省（新建 T2 + 若干 T1 划入） | T2 | 新省至少 2 个州府；A 省保留至少 2 个 |
| **合省** `merge_provinces` | A 省并入 B 省（T2 合并，T1 改 parent） | T2 | 合计州府 ≤ 上限（默认 12）；不得跨 owner |
| **改治/改级/改名** `retype` | 省治迁移、州府升格/降格（T1↔T2）、改名 | 单元 | 层级深度 ≤ 3；改名须唯一 |

> 说明：宋的「路」与外邦的「道/省」都用 `level=T2`，**同一套操作**；术语差异只在显示层。

### 6.2 发动与阻力（Jev：C 0.597 / A 0.394 / B 0.009）

| 环节 | 谁做 | 内容 |
|---|---|---|
| 提议 | **玩家**（诏令/面板） | 选操作 + 目标单元 |
| 评估 | **天道（只出档位）** | `resistance`：无/微/小/中/大/巨；`posture`：准/缓/驳；一句叙事 |
| 执行 | **程序** | 校验 + 扣成本 + 改 parent/level + 记历史 + 设过渡期 |

⚠️ 天道**不决定**改不改、也**不给数**——只给「阻力档位/态度档位/叙事」，数值由 §6.3 程序算。
> 平手说明：C 0.597 与 A 0.394 差距不压倒；采纳 C 是因为它**贴合本作现有架构**（天道只出档位、玩家下诏），
> A（仅玩家诏令、天道不参与）会让区划调整缺少「地方阻力」这一层叙事。

### 6.3 成本与过渡期（Jev：A 0.841 / B 0.140 / C 0.019）

```text
成本 = 行政成本（府库银，按涉及州府数 × 距离档）
     + 吏治阻力（clerks 把持度 +Δ，按 operation 权重）
     + 民心（地方士绅不满 −Δ 满意度，按州府人口加权）
过渡期 = N 月（改隶 3、分省/合省 6、改级 3），期间：该单元税/产 × 0.6，且不再叠加
```

| 项 | 口径 | 设定值（可调） |
|---|---|---|
| 行政成本 | `州府数 × 2000 贯 × 距离档(邻省1.0/隔省1.5)` | 从**地方府库**扣，不足则拒 |
| 吏治阻力 | `clerks_grip += 0.01 × 州府数`（封顶 +0.1） | 走既有 `clerks` 通道 |
| 民心 | `满意度 −= 0.5 × (涉及人口/10万)`（封顶 −3） | 走既有满意度字段 |
| 过渡期折扣 | 税/产 × 0.6，持续 N 月 | 记 `regions[id].transition_until` |

### 6.4 守恒与不变量

| 不变量 | 断言 |
|---|---|
| 省内守恒 | 改隶：Σ(旧省) + Σ(新省) 的人口/土地/税基**逐字不变** |
| 分省守恒 | 新省 + 旧省 == 分省前 A 省（逐字段） |
| 合省守恒 | 合并后 B 省 == A + B（逐字段） |
| 无孤儿 | 每个 T1 必须恰有一个 `parent`；每个 T2 的 parent 是政权或 `None` |
| 无环 | parent 链不得成环；深度 ≤ 3（政权 → 省 → 州府） |
| 不跨 owner | 改隶/分省/合省**不得**跨政权（跨政权只能走 `transfer_regions`，§7） |
| 历史可回滚 | `region_changes` 每条可逆向重放（回收一次操作） |

### 6.5 API（新模块 `core/domains/diplomacy/region_admin.py`）

```text
can_redivide(state, op, params) -> {ok, reason, cost, resistance_hint}
redivide_regions(state, op, params) -> {ok, op, moved, cost, transition_until, change_id}
redivision_history(state) -> [{change_id, op, params, month, reversible}]
undo_redivision(state, change_id) -> {ok, reason}      # 仅未生效/过渡期内可回滚
verify_region_invariants(state) -> [违规清单]           # 守恒/孤儿/环/跨 owner
```

### 6.6 门（P7 阶段）

1. 改隶守恒（旧省 −新省 + 新省 = 0 差）；2. 分省/合省守恒；3. 无孤儿/无环/深度 ≤3；
4. 跨 owner 拒绝；5. 成本不足拒执且**不动账**；6. 过渡期折扣只作用一次（不叠加）；
7. `undo` 后逐字段复原；8. 未发动时 `verify_region_invariants` 返回空（现状自洽）。

## 7. 归属变更（占领/割让/更替）

```text
transfer_regions(state, from_regime, to_regime, region_ids)
   → 只改 regions[*].owner 与 territory；人口/土地/建筑【不动】
   → 政权字段（treasury/armies/tech/attitude）【不随地域走】
```

- **金登场**：事件建政权（不继承辽 treasury）→ 按战局分批 `transfer_regions(from=辽, to=金, …)` → 辽失地尽标 `extinct`；
- **金南下占宋地**：`transfer_regions(from=宋, to=金, ids)`；宋侧结算按 `owner == 宋` 过滤（未占领恒真 ⇒ 零变更）；
- **和议归还**：反向调用，详账未动 ⇒ 无需重建。

Jev：地域注册表 + 政权引用 **A 0.951**；宋地纳入统一归属 **A 0.979**。

## 8. 聚合与守恒

```text
政权级 = Σ 其 territory（政区内所有 region，含 T1/T2 不重复计）
省级   = Σ 其 T1 子单元
州府级 = 自身 pop/land/grain
```

| 规则 | 说明 |
|---|---|
| 缺失≠0 | 某单元缺 `pop` ⇒ 聚合该项 `None` + reason |
| 尾差归首府 | 整数分摊截断尾差并入该省首府（沿用既有惯例） |
| 只读镜像 | 政权/省汇总均为派生；写点只落 `regions` 单元或宋详账 |

## 11. 实施阶段（每阶带门）

| 阶段 | 内容 | 门 |
|---|---|---|
| **P1 regions 骨架** | 宋 117 治所 + 外邦六国省/州府登记（owner/parent/prefecture_ref） | 无孤儿/无环/深度≤3；宋 117 全登记；外邦六国 ÷省数与 `provinces` 一致 |
| **P2 聚合读口** | `aggregate_by_owner` / `aggregate_province` | Σ == 现有国级字段（逐字段容差 0）；缺失 ⇒ None |
| **P3 迁移** | `init_regions` + `migrate_regions` 幂等 | 新局/旧档各一次；重复调用幂等 |
| **P4 分解** | 省→州府人口/兵力分解（尾差归首府） | Σ州府 == 省（逐字段） |
| **P5 归属变更** | `transfer_regions`（占领/更替/归还） | 地域人口/土地逐字不变；政权字段不随地域走；未变更 A/B 逐字相同 |
| **P6 宋地占用** | 宋结算按 owner 过滤 | 未占领时判定恒真 ⇒ A/B 零变更；占领州府不计入宋税/产/兵 |
| **P7 区划调整** | 改隶/分省/合省/改级（§6） | §6.6 八条门 |

### 15.3 架构原则：**底图静态、归属运行期**

```text
构建期（离线，产物不入库）：
  疆域/省界/州府面/城市点/地形 —— 只依赖 geo 原始数据与静态表
运行期（每回合，前端 overlay）：
  state.regions → owner 着色 + parent 分组边界 + 占领/改隶高亮
```

🔴 **不得**用 `state` 重建 geojson/topojson（构建期产物，运行期无法重建；也会让存档/地图耦合）。

| 变化 | 底图 | overlay |
|---|---|---|
| 占领（owner 变） | 不变 | 该 T1 面改色（占领方颜色）+ 斜纹/描边 |
| 和议归还 | 不变 | 恢复原色 |
| 改隶（parent 变） | 不变 | 按新 parent 重算省界（对 T1 面做 union） |
| 分省/合省 | 不变 | 同上：省数/省界随 `parent` 重算 |
| 金登场 | 不变（`REGIME_GEO` 已有金疆域） | 金疆域激活 + 逐步接管的州府改色 |

### 15.5 阶段（与主稿 P 阶段并行，独立可验收）

| 阶段 | 内容 | 门 |
|---|---|---|
| **M1 名单对齐** | 以 `REGIME_PREFECTURES` 重建七国静态表（含吐蕃 4 块）；`regions` T1 与地图面一一对应 | 数量逐国相等；每块 face 有对应 region_id；无孤儿面/无孤儿 region |
| **M2 州府点补齐** | 七国州府点（`lonlat`）进 `regime_cities` | 点数 == T1 数；坐标在合理经纬框；点 id 唯一 |
| **M3 overlay 读数** | 后端 `map_overlay`（只读，`state.regions` 派生） | 未占领/未调整时 overlay 与底图 owner 逐字一致（A/B 零变更） |
| **M4 overlay 渲染** | 前端按 owner 着色 + parent 分组省界 + 过渡期斜纹 | 视觉验收（真机截图）；性能 ≤200 要素 |
| **M5 区划调整联动** | 改隶/分省/合省后省界重算 | 与 `verify_region_invariants` 一致；undo 后渲染复原 |

### 15.6 风险与纪律

| 风险 | 处理 |
|---|---|
| 地图与账两套州府 | M1 门锁死「面 ↔ region 一一对应」 |
| 构建产物不入库导致新克隆地图空 | 文档与 README 写明须按 §4 重建；overlay 无底图时降级为点 |
| 外邦面数据缺失（高丽/日本/安南） | 先点+色块，面待 geo 数据；**不臆造 polygon** |
| 运行期重算省界性能 | 只对可见视口 + 缓存 union 结果；上限 200 要素 |
| 金疆域在底图但账中无金 | 由「未登场政权」状态控制显示（底图 dim 处理），登场后激活 |
