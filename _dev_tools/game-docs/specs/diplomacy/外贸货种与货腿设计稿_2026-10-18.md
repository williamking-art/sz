# 外贸货种与货腿 · 设计稿（2026-10-18）

> 由用户提问触发：「外贸的钱，商品有实物吗」「要补的不止 9 个商品吧」「陆路榷场的商品呢」
> 「日本怎么是陆路」。**本件只出设计，不动代码。**

## 0. 一句话结论

现在的外贸是**纯货币注入**：关税、白银、商人利润都有，**货一件没动**；
而且**只有海路一条通道**（陆路榷场未实现）。要让它成立，需要：
**两条通道 + 一套货种体系 + 逐笔货腿 + 双守恒对账**。

### 3.3 为什么不逐品建维

逐品建 30+ 维要同时定单价、需求、仓储、消费篮、加工链 ⇒ 物价与市场全面漂移、标定成本高。
按类目建维：**类目承担价格与库存，成员承担史实与叙事**，与已落地的 COMMODITY_KINDS/GOODS_CLASSES 同构。

## 4. 一笔记账模型（货腿）

### 4.1 事件 schema（trade_journal 逐笔，append-only，无余额字段）

    {
      "month": 13210, "channel": "sea|land",
      "route": "两浙路", "seat": "两浙路|明州",
      "partner": "日本", "regime_dim": "香药",
      "direction": "import|export",
      "qty": 1200, "unit_price": 8.5, "goods_value": 10200,
      "freight": 51, "tax": 1020, "silver_settle": 9000,
      "escort": "无|镖|军", "blocked": null
    }

### 4.2 双守恒

| 量 | 约束 |
|---|---|
| **货** | 出口：Δgoods < 0（商人→外邦，离开本国）；进口：Δgoods > 0（外邦→商人）。每笔货腿必须能说出**从谁扣/入谁** |
| **钱** | 国内只发生：商人 wealth ↓（货款）→ 国库（关税）；白银按顺逆差增减 silver_stock。Σ国内钱变化 = 关税 ± 白银折算，**每笔可对账** |

### 4.3 货源不足 ⇒ 缩量（不凭空）

- 出口：按可出口量（商人 goods 优先，其次官仓）**缩量成交**；0 货 ⇒ 该笔不成交（记 blocked=no_stock）；
- 进口：按商人**库容/购买力**缩量；不足记 blocked=no_capacity / no_wealth；
- 缩量后的实际贸易额才计入关税与利润（**不得先按目标额收税再缩货**）。

## 5. 运费与税（口径单点，全部取自 trade_shadow）

| 通道 | 运费 | 税 |
|---|---|---|
| 海路 | sea_freight(qty, storm)（固定 + 货损） | 市舶抽解 tariff（入**国库**） |
| 陆路 | land_freight(qty, band, terrain)（按距离档） | 榷税：OVER_TAX_SHARE 过税（沿途路）/ STAY_TAX_SHARE 住税（交易地路）→ **地方府库**（待裁） |

🔴 不在结算里重写数字；band 必须用 LOGISTICS_FEE 的键（intra/d300/…），中文档位返回 None。

## 6. 禁榷与走私

| 品类 | 规则 |
|---|---|
| 铜钱、铁器、兵刃、部分书籍 | **禁止出境**（宋法）；若放行 ⇒ 走私：按批次概率查获，没收 + 罚，blocked="contraband" |
| 香药 | 朝廷**榷买**（专营）：进口香药优先卖给官府，余者方许民间 |
| 马 | 榷场官营（军用），民间不得私市 |

## 7. 白银与货币口径

- 出口 > 进口 ⇒ 白银**流入**（silver_stock ↑，对应 silver_in）；
- 进口 > 出口 ⇒ 白银**流出**（silver_stock ↓，宋钱外流问题）；
- 外贸属**体外注入/流出**：M_ALL 不守恒是正确语义；须在 货币口径规范_M0M1M2.md 补「外贸注入项」对账式（当前缺口）。

## 8. 验收断言（写死）

1. Σ货值(出口) + Σ货值(进口) ≡ 贸易额（逐月）；
2. 出口每笔 Δ商人goods ≤ 0 且 Σ扣货 ≡ qty；进口每笔 Δgoods ≡ qty；
3. 关税 ≡ 实际贸易额 × tariff（不得用目标额）；榷税 过税+住税 ≡ 税额；
4. 货源/库容/购买力不足 ⇒ blocked 非空且**贸易额缩量**（不得虚收）；
5. 禁榷品出境 ⇒ 必须出现 blocked="contraband" 或查获记录；
6. trade_journal 无余额字段（禁与 POP 平行的账本）；
7. 陆路/海路各自用对运费函数（不得混用）。
