# 长期旨「案卷化」设计稿（2026-10-20）

> 用户提供外部游戏「时局案卷」UI 作参考：案号 / 承办人六维 / 承办人授权（专款·余额·出库·赐专断之权·逐月自理）/
> 案卷底册（种类·局势·状态·来源引据·立项回合·最近推进·严重度·关联地区·派系·可撤性）/
> 当前阶段（见底→推进中→终前→达成）+ 进度 / 自然推进 vs 需推动 / 预计还需 /
> 当前影响（持续效果，如皇威−1）/ 案情摘要 / 推进日志（逐月：落账+叙事）/ 达成目标 / 失败代价。

## 1. 现状对照（代码实测）

| 参考 UI 区块 | 宋祚现有 | 缺口 |
|---|---|---|
| 案号、严重度、来源引据、立项回合、最近推进、关联地区/派系、可撤性 | `longterm_task` 仅有 id/topic/org/support | **缺**（本次补 `longterm_case`） |
| 承办人 + 六维 | `task["minister"]` + `content.ministers.data.MINISTERS` | 有数据、缺面板组装 |
| 承办人授权：专款/余额/出库、赐专断之权、逐月自理 | **无** | **缺**（本次补 `authorize_case` / `monthly_cost`） |
| 阶段 + 进度 | `longterm_task._stage`（立案待行/推行中/成效渐著/将成/告成） | 有；本次加 `phase_of` 对齐参考档位 |
| 自然推进 / 需推动 / 预计还需 | `build_readout().forecast` | 有；缺「自然 vs 需推动」标签与 ETA |
| 当前影响（持续效果） | **无** | **缺**（本次补 `monthly_effects` + 月度落账） |
| 推进日志（逐月落账+叙事） | `support_log`（圣旨支持记录） | 语义不同；本次加 `progress_log` |
| 达成目标 / 失败代价 | `_maybe_fail`（6 月无推进罢废） | 缺**效果**（`outcome_effects` / `fail_effects`） |

## 2. 本次落地（`core/domains/politics/longterm_case.py`）

```text
ensure_case_fields(state, task)     幂等补字段（缺失保持 None/空，不假装 0）
case_is_cased(task)                 是否已案卷化（旧事务零变更）
authorize_case(state, task, budget=, pool=, discretion=, monthly_cost=)
                                    从国库/内帑**真实扣款**；府库不足拒批且不动账；重复授权不重复扣
monthly_case_settle(state, task, log, narrative=, progress=)
                                    每月：扣月费 → 落持续效果（白名单键）→ 写推进日志 → 判达成
case_readout(state, task)           面板只读载荷（案卷底册/授权/进度/日志/目标/代价）
```

### 2.1 字段（新增，全部可选）

| 字段 | 含义 | 缺失时 |
|---|---|---|
| `case_no` | 案卷号 | None |
| `severity` | 严重度 0–100 | None |
| `source_ref` | 来源引据（事件 id/来源） | None |
| `opened_turn` / `last_advance_turn` | 立项/最近推进回合 | None |
| `linked_region` / `linked_factions` | 关联地区/派系 | None / [] |
| `cancellable` | 可撤性 | True |
| `budget` | `{total, remaining, pool}` | 0/0/treasury |
| `discretion` | 赐专断之权 | False |
| `monthly_cost` | 逐月自理的费用 | 0 |
| `monthly_effects` | 持续效果 `[{key, amount}]`（仅 prestige/treasury/population_satisfaction） | [] |
| `outcome_effects` / `fail_effects` | 达成/失控效果 | [] |
| `progress_log` | 推进日志（上限 12 条） | [] |

## 3. 纪律

1. **进展仍归 `longterm_task`**（本模块不另立账本，只做案卷层）；
2. **专款真实扣减**（国库/内帑），不足即拒批且不动账；
3. **持续效果白名单**，未知键忽略（防乱写）；
4. **专款耗尽 ⇒ 本月 blocked**：不落持续效果、日志记明（不假装仍在推进）；
5. 只处理 `case_is_cased` 的事务 ⇒ **旧档行为零变更**；
6. 缺失一律 `None`，面板显示「未定义」。

## 4. 接线
