## 3. 纪律（每批必守）

1. **天道只出档位**，数值由程序换算表算；换算表集中一处；
2. **缺档必须留痕**：source 字段写明天道/程序推导/兜底，缺失≠0；
3. **可复现**：随机入口支持注入（如 resolve_disaster(roll=...)），长局回放不能被破坏；
4. **不把事实交给天道**：是否成灾、是否开战由模型判定，天道只定程度/烈度；
5. 每批新增门：档位映射正确 + 缺档兜底标源 + provider 注入 + 非法档位不崩。
