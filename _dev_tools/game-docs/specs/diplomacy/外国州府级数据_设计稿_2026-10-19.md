# 外国行政区划分级数据 · 设计稿（2026-10-19）

> 用户：「给各主要国家的州府级数据落地，其他的用省级或国家级，先出设计稿」。
> **状态：设计稿，未实施**。实施计划见 §9。

## 0. 一句话

外邦分三级：**T1 州府级**（6 个主要国家，展开到州/府/京）→ **T2 省级**（现有 `provinces`）→ **T3 国家级**（其余 35 国只用国级汇总）。
聚合恒等式：**国 = Σ 省 = Σ 州府**（缺失一律 `None`，不回落 0）。

## 3. 数据形状

### 3.1 T1：省下挂州府

```text
external_regimes[国]["provinces"][i]["seats"] = [
  {
    "name": "析津府", "kind": "府",              # 府/州/京/道治
    "pops": {"农": {...6 类...}, ...},           # 与宋治所同构（size/wealth/grain）
    "land": 1200, "grain": 800000,
    "troops": 120000,
    "buildings": {"官署": 1, "仓廪": 1},          # 与宋 buildings 同构（等级形态）
    "center_lonlat": [116.4, 39.9],
    "note": "史实地名；人口/兵力=按权重分解（设定值）"
  }, ...
]
```

### 3.2 T2：省（沿用现有字段，补齐 `pops`）

现有 `provinces[i]` 字段**不改名、不改形**，只做两件事：①`pops=null` 的省按 §4 补分解；②新增可选 `seats`（T1 六国）。

### 3.3 T3：国家级

保持现有 21 字段；新增只读聚合入口，使调用方**不必知道某国是几级**。

## 4. 聚合与分解（守恒，口径单点）

```text
国级 = Σ 省 = Σ 州府（pops[6类].size / wealth / grain、land、grain、troops）
省级 = Σ 其州府（仅 T1 国家有州府；T2/T3 国家省即末级）
分解：省 → 州府 按「首都/要冲权重表」× 省 weight 分摊，**总额守恒**（尾差归首府）
```

| 规则 | 说明 |
|---|---|
| 缺失≠0 | 某省 `pops=null` ⇒ 聚合返回 `None` 并给 `reason`，**不当 0** |
| 尾差归首府 | 整数分摊的截断尾差并入该省首府（与既有 POP 分摊惯例一致） |
| 镜像只读 | 国/省汇总值均为**派生**；写点只落州府（T1）或省（T2）或国（T3） |
| 权重来源 | `provinces[i].weight` 已有；州府权重＝首都 1.5 / 要冲 1.2 / 普通 1.0（**设定值**） |

## 5. 数据来源与标注（不冒充史实）

| 项 | 来源 | 标注 |
|---|---|---|
| 州府**名称** | 史实（辽五京道府州、西夏州、高丽京、日本国、大理府、安南府） | 「史实·地名」 |
| 州府**人口/兵力/粮** | 按 §4 从省级/国级总量分解 | 「玩法设定·按权重分解（总量守恒）」 |
| 州府 **lonlat** | 现代城市坐标近似 | 「近似坐标」 |
| 省 `weight` | 现状已有（设定值） | 沿用 |

⚠️ **不得**把分解值写成史料数据；研究稿/面板如需显示，用「设定值」字样（沿用项目既有纪律）。

## 6. 读写单点（新模块）

```text
core/domains/diplomacy/regime_admin.py
  regime_tier(state, name) -> "T1"|"T2"|"T3"
  regime_seats(state, name) -> list|None            州府列表（T1 才有；其余 None）
  regime_provinces(state, name) -> list|None        省列表（T2/T1）
  regime_aggregate(state, name) -> dict             国级汇总（缺失项 None + reasons）
  regime_seat_add(state, name, province, seat) -> dict   写州府（T1）
  regime_set_pops(state, name, province, pops) -> dict   补省 pops（T2 缺口）
  verify_regime_conservation(state) -> list          Σ省==国、Σ州府==省 的违规清单
```

纪律：**调用方不直接读 `provinces`/`seats`**（口径单点）；未迁移国家/缺失字段一律 `None`。

## 7. 迁移与存档兼容

| 项 | 方案 |
|---|---|
| 新局 | `game_init` 末尾调用 `init_regime_seats(state)`（幂等；T1 六国写州府表 + 补省 pops） |
| 旧档 | 读档时同一幂等入口（`migrate_regime_seats`）；已有州府则跳过 |
| 版本标记 | `state.regime_admin_version = 1`；旧档无该字段 ⇒ 视为 0 并迁移 |
| 回滚 | 删除 `seats` 即可回到 T2；聚合自动回落省/国 |

## 8. 结算与显示影响

| 系统 | 影响 |
|---|---|
| 战争/占领 | T1 州府可被占领（省级→州府级战果），T2/T3 仍按省/国 |
| 外交 | 谈判单位**不变**（仍国级）；T1 提供细节读数（不必改谈判逻辑） |
| 岁币/外贸 | 仍用国级汇总 ⇒ **零行为变更**（读口兼容） |
| 榷场 | 陆路榷场 partner 可读到 T1 州府货值（P5/P6 已按 partner 汇总，天然兼容） |
| 地图 | T1 国显示州府点；T2/T3 显示省/国色块（前端按 tier 分支） |
| 性能 | T1 六国 ≤ 60 州府，`aggregate` 为纯算术；不影响月度结算热路径 |

## 9. 实施阶段（每阶带门）

| 阶段 | 内容 | 门 |
|---|---|---|
| **P1 数据表** | T1 六国州府表（名称/kind/权重/lonlat）+ 省 pops 补齐 | 名称唯一、kind 合法、Σ州府权重>0、lonlat 在合理经纬框 |
| **P2 读口** | `regime_admin` 读/聚合接口 | 未迁移 ⇒ None（不崩）；Σ省==国（在整数容差内） |
| **P3 迁移** | `init_regime_seats` + `migrate_regime_seats` 幂等 | 新局/旧档各一次；重复调用幂等 |
| **P4 分解** | 省→州府人口/兵力分解（尾差归首府） | **守恒**：Σ州府 == 省（逐字段） |
| **P5 接线** | 战争占领/地图/面板读数用 tier 分支 | A/B：未接线的系统读数**逐字不变** |

## 10. 风险

| 风险 | 处理 |
|---|---|
| 人口分解被误读为史实 | 面板与文档统一标注「设定值·按权重分解」 |
| 省 `pops=null` 被当 0 | 读口返回 None + reason；门锁死 |
| 与宋 117 治所口径混用 | 宋用 `prefectures`；外邦用 `external_regimes`，**两套不交叉**，只在贸易/外交边界做换算 |
| 存档体积 | T1 只 6 国（≤60 州府），可接受 |
