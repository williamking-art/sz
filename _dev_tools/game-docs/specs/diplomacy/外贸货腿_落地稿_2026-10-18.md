## 1. 口径真源（冲突时唯一依据）

### 1.1 时间（按载具，不按方式）

`days = ceil(km / (载具 km/日 × 30))`，**发运/在途/到货一律用它**。
`KM_PER_MONTH=2400` 只用于既有 `route_days` 的粗略可达性，**不参与发运**。

| 载具 | km/日 | 境内最远 2,356 km | 海路最长 4,230 km |
|---|---:|---:|---:|
| 驿马急递 | 250 | 1 回合 | 1 回合 |
| 海船 | 150 | 1 回合 | 1 回合 |
| 驴骡 | 40 | 2 回合 | — |
| 漕船 | 35 | 3 回合 | — |
| 马车 / 步行挑担 | 30 | 3 回合 | — |
| 牛车 | 20 | 4 回合 | — |

### 1.2 运量（月）

| 方式 | 单位 | 月运力 | 备注 |
|---|---|---|---|
| 陆运 | 石 | 500 / 路 | 车驮挑夫合计 |
| 水运 | 石 | 25,000 / 全国 | 漕船池，非每路 |
| 海运 | 石 | 40,000 / 全国 | 海船池 |
| 驿传货 | 石 | 50 | 轻货 |
| 信件 | 件 | 5,000 / 全国 | 独立池；**信件不算商品** |

钱运：**1 石 ≈ 15 贯**，按 `贯 ÷ 15` 扣运力。

### 1.3 所有权与调配

| | 官有 | 私有 |
|---|---|---|
| 来源 | 造船作坊产出、马政拨马 | 商人 `assets` 投资 |
| 用途 | 漕粮/军需/官物/驿传 | 商货/民用 |
| 征用 | — | 和雇 **运费×1.5**；差雇 **民心 −0.1~0.3** |

铁律：官物只走官运力（不足则和雇/差雇）；商货只走私运力；驿传只官有；禁海只限民船。

### 1.4 回合制

```text
回合开始：钱到账 → 货到账
回合内 ：生产/采购 → 发运（arrive_month ≥ now+1）→ 支出
回合末 ：结算失败整月回滚（含本月批次）
```

运力账 `transport_used[owner][mode]` 每回合清零；超出上限 ⇒ **排队（deferred_qty）**，不拒办。

## 3. 天道（只有档位；数值程序算）

| 机制 | 契约 | 档位 |
|---|---|---|
| 运具选择 / 官私调配 | **`transport_decide`（新增）** | `mode_pref` 水·陆·驿；`carrier_pref` 快·省·均衡；`requisition` 和雇·差雇·不征；`escort` 无·镖·军；`use_jiaozi` 是·否 |
| 商人投资倾向 | **`merchant_decide`（新增）** | `posture` 进取·稳健·保守；`focus` 运力·产能·品类·囤货 |
| 储粮损耗/发仓 | `granary_decide`（已接线） | 已有档位 |
| 奢侈消费 | `economy_decide`（已接线） | `luxury_appetite` 奢·中·俭 |
| 信件/军报时效 | `decree_execute_decide` / `military_decide` | 急递·常递；急·常 |

纪律（仅此三条）：档位白名单校验+非法回落中性；prompt 只喂区间快照；**先有消费者再登记 Agent**。

## 5. 阶段计划（唯一编号；旧 F/C/D/E/N/P/R 作废）

| 阶段 | 内容 | 行为变更 | 回滚 |
|---|---|---|---|
| **P1 数据** | §2 数据层全部表 | 无 | 删表 |
| **P2 读数** | `foreign_trade_readout` + 运输读数 | 无 | 删模块 |
| **P3 运力账** | 载具选择 + `transport_used` + 排队 | 有 | 开关关 |
| **P4 官私运力** | `carriage` 拆分 + 和雇/差雇 + 造船入账 | 有 | 恢复单一池 |
| **P5 海路货腿** | `trade_legs` 接海路 | **有** | `FOREIGN_TRADE_LEGS=0` |
| **P6 榷场** | 陆路通道 + 和战开关 + 榷税 | 有 | 清口岸表 |
| **P7 禁榷走私** | 禁榷查禁 | 有 | 清 `CONTRABAND_DIMS` |
| **P8 POP 投资** | `capital/assets/scope` + L1 + `merchant_decide` | 有 | 停用 L1 |

依赖：P1→P2→P3→P4→P5→P6→P7→P8；**P5 必须在 P3/P4 之后**（否则运费/运力无基数）。
验收：每阶段一条门（P1 覆盖/存在性、P2 对账、P3 守恒、P4 两本账、P5 双守恒、P6 开关、P7 禁榷、P8 资产守恒）。
