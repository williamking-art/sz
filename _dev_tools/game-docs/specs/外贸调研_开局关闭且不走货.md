### 2.1 实测默认值

```
maritime = {'open': False, 'tariff': 0.1, 'silver_in': 30}
calc_maritime_trade() = 0.0
```

⇒ 🔴 **开局 `open = False`** ⇒ **外贸默认完全不跑**。

### 2.2 🔴 即使开启，**也不走货**

该段代码**只做三件事**：

| # | 动作 | 是否涉及货物 |
|---|---|---|
| 1 | 商人毛利 → 商人 POP `wealth`（登记 `external`）| ❌ **纯钱** |
| 2 | 白银流入 → `silver_in` 存量 | ❌ **纯钱** |
| 3 | 关税（唯一入账通道在 `_settle_finance`）| ❌ **纯钱** |

**全段没有任何**：


**但「货出」在代码中没有任何实现**。

### 2.4 市舶税源的既有口径（`content/data.py:839`）

> 「市舶独立税源：海外贸易年总额（贯/年，基准）。市舶抽解是**关税**，
