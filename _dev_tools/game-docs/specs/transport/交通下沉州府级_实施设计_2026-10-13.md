### 7.1 🔴 本批抓到的两个问题（值得留档）

1. **我的 A/B 工装缺陷**：两次 run 在**同一进程**共用 RNG ⇒ 第二次拿到被第一次推进过的随机流，
   轨迹必然不同（M38b-2 比的是 dict 才没暴露）。**修**：每次 run 前 `random.seed(固定)`。
2. **真缺陷（桥引入的静默类型变更）**：`canal_set_national` 曾把 `state.canal_block` 从 `int`
   变成 `float`（12.0）——存档、前端 `pick<number>`、`_int()` 读点都会跟着变。
   **修**：桥**保持入参数值类型**（int 进 int 出）。**这条正是 A/B 对照的价值所在**。
