## 三、🔴 `盐` 的口径异常（重要）

### 3.1 事实

```
盐：全国年额 185,100,000（是丝的 7.2 倍）
    校准基数 4.2272（是丝的 26.6 倍）
    有值 16 路，其中 **京畿路 = −100,000（负值）**
```

**逐维负值核查结果**：

| 维 | 正值路 | 负值路 |
|---|---:|---:|
| 丝 / 麻 / 果 / 蔗 / 茶 / 木 / 石 / 铁 | 全部为正 | **0** |
| **盐** | 16 | **1（京畿路 −100,000）** |

### 3.2 结论

🔴 **`盐` 是唯一含负值的维** ⇒ 它**不是纯生产量，而混入了净流量**（调运/缺口）。

⇒ **不宜直接把 `盐` 建模为「盐场产出」** —— 否则负值无意义（负的产量？）。

### 3.3 处置建议

| 选项 | 含义 |
|---|---|
| **甲** | **保留 `production_chain` 专产盐**，不进建筑轨 |
| **乙** | 先把 `盐` 的 `yields` **拆成「产量」与「净调运」两个量**，再进建筑轨 |
| **丙** | 新增「盐场」建筑，但**负值路按缺盐处理**（不建盐场，靠调运补）|

⚠️ 这正对应《接入条件5_6事实核查》§七 的待裁项 **丙**。
