# `produce-space-price/` · 目录说明

本专题承载《物产新篇》商品模型中**宋祚尚缺的三层增补**：价格的空间维度（产地价 → 销地择优）、需求的地域维度（入市率 / 地域嗜好 / 年度流行）、物流的品类属性（腐坏率 / 运重）。
**状态：设计稿，零代码改动（尚未实施）。**

## 与既有专题的边界

| 问题 | 答案 |
|---|---|
| 与 `unified-civilian-market/`（P0–P6）什么关系？ | 本专题只补源模型独有的三层，**不重复**其月度八步、三重上限成交、四因未满足、沈括途耗、四仓位物权；P-A/P-C 可与其 M41/M42 并行，**但不得改 `trade_goods` 语义** |
| 与 `market-civilian-economy/`（B0–B5）什么关系？ | 需求侧的「阶层×财富余量×价格敏感」仍以它为准；本专题只加**地域维度与品目维度**（入市率/嗜好/流行），不改 B2 公式 |
| 为什么不直接写进 unified 的 tasks.md？ | Jev J2（0.759）判为新立专题；且本专题可独立验收/回滚（新表 + 纯函数 + 默认关接入），不扰动在跑的 P1 切片 |
| 源模型的 40 类能直接用吗？ | 不能。宋祚现有 `GOODS_CLASSES` 仅食品/粮两词条、`COMMODITY_KINDS` 仅 4 类，故先做 P-B0 品目层（D6） |
| 源模型的稀缺系数能直接抄吗？ | **不能**。实测宋祚治所图路对跳数 **1–11（中位 4、均值 4.62）**；源模型 `1.43^n` 是 23 大区 0–6 跳定标，直套最远 ≈55×。必须按本图重标定 + 扫描（D4），并设 `MAX_SPATIAL_RATIO` 放大上限 |
| 源模型的"税目按类征"能直接抄吗？ | **不能，前提不存在**。宋祚工商税＝`Σ(工匠+商人)人数 × 人均产出 × 税率`（`settlement_finance.py:1397-1402`），全库无 `TAX_BY*`；故 P-D 降级为**只读应税产值分解**，真分征另立 D8 |

## 阅读纪律（摘自既有文档，改本专题前先读）

- **开工门五态**：定义存在 / 已接线 / 账本闭合 / 长局校准 / 玩家可观察；**禁止把"有代码"当"已落地"**。
- **不伪造精度**：没有可靠初始数据的 POP/建筑/库存，不得按面积或人口比例伪拆成"真实州府值"。
- **缺失 ≠ 0 ≠ 1.0**：任何缺数据路径返回 `None` + `reason`。
- **禁平行账本**：本专题**不新增库存/钱载体**；产地属性与乘子一律只读。
- **不臆造**：无史料的系数（跳数/稀缺/入市率）必须显式标「设定值/推算」，不得冒充史料。
