## 一 · 系统定位（体验层）

- 玩家＝皇帝；唯一动作语言＝**圣旨**（拟旨/御笔/密旨/口谕/督行诏）。
- 财政世界＝**真账**（程序权威）＋**官方账目**（玩家/大臣所见）；两者受控落差＝"贪吏做账"。

## 二 · 真账模型（双层税基 · 归一三分）

### 2.1 公式链（唯一口径 · V1.2）

```
tax_base                                # 理论税基（田亩/人口派生；农业因子仍在此层）
  ↓ × collection_rate                   # 征收率（灾害/逃户/执行能力；决定 POP 实付）
actual_collection                       # 应征 = tax_base × collection_rate
  ↓ × 三率归一（transfer + keep + div ≡ 1）
central   = actual_collection × transfer_rate       → 上供 → state.treasury
local     = actual_collection × local_keep_rate     → 留州 → prefectures[路].local_treasury
embezzle  = actual_collection × diversion_rate      → 侵渔 → 官僚 POP wealth（吏→官僚回退）
```

**守恒**：`central + local + embezzle ≡ 实收`；`ΣM_ALL` 逐月不变（纯转移，不开新账户）。

### 2.2 实收基数（豁免/欠税层不可丢）

- 逐户扣缴仍走既有 `_tax_agents` 循环（`settlement_finance.py:596-633`）——保底豁免（`MIN_WEALTH_FLOOR_RATIO`）与欠税科目（`pops["欠税"]`）原样保留；
- **分流基数为"实收"**（应征经豁免/欠税后的实付累计，即该循环 `_paid`；欠税追缴回收额与当期实收同口径分流）；
- **缺省不臆造**：POP 付不满时按实付拆分，不得按应征强分（否则豁免额凭空分流）。

### 2.3 三落点与既有通道（全部复用，不新写）

| 落点 | 字段 | 既有写入通道 |
|---|---|---|
| central | `state.treasury` | 既有 `actual_tax` 管道（`settlement_finance.py:876-934` 恒等式维持；`actual_tax` 口径＝实收×transfer） |
| local | `prefectures[路]["local_treasury"]` | `transfer_money`（`game_state.py:1120`）／`state_applier` 的 `local:<路>`（`game_state.py:1147-1178`） |
| embezzle | 官僚 POP wealth | `transfer_money` 的 `pop:<路>:官僚`；吏→官僚回退范式（`hoard_settle.py:77`） |

### 2.4 与现状的根本差别

- 现状：`arrival` **一身两义**（征收＋解送合一），乘进税基（`game_state_econ.py:569`）——POP 少付、国库少收、两边同减，**截留无落点**；
- 终稿：拆为 `collection_rate`（决定 POP 实付）与 `transfer_rate`（决定中央份额），三率归一——**截留有落点、各有去处**。

## 三 · 四率与归一化（state 化 · 三改革轴一一对应）

### 3.1 `arrival` 拆解（两个新率）

| 旧 `arrival`（`game_state_econ.py:537`） | 拆为 | 来源（映射既有读数） |
|---|---|---|
| 征收侧（税基折扣语义） | **`collection_rate`** | 灾害（灾荒契约 `disaster_level`）／流民·逃户（`refugees`，`game_state.py:992`）／执行能力（民心·吏治） |
| 解送侧（到账语义） | **`transfer_rate`** | 中央权威（prestige `authority`）／转运体系（`ROUTE_WATERWAY`，`trade_shadow.py:35`）／监察能力（`audit_effort`） |

- 旧 `calc_arrival_rate`（含 `audit_effort`/`diversion` 两个吃默认值的死参数）**退役**；消费点（`game_state.py:1519-1520`、`game_state_econ.py:337/561/581`、`settlement_finance.py:553`）与读数族（`arrival_ratio_*` `:328-330`、`desensitize_arrival`）随 P1 同步改造；
- **不双计**：`tax_base` 层已含农业因子（`(1−hidden)`/丰歉/水利）；`collection_rate` 只吸收"灾/逃/治"社会侧，不再叠农业因子。

### 3.2 `local_keep_rate`（地方合法留成 · **A 平铺重标**）

- 语义＝**总额份额**（平铺），开局 **0.04**；
- 派生（govern）：`local_keep_rate = clamp(0.04 + (govern − 60) × k_g, 0.02, 0.08)`；`k_g` 待校准（C2，候选量级 0.001）；
- 字段＝`prefectures[路]["govern"]`（`game_state.py:940` 初始化，`settlement_econ.py:350` 月漂 ±1）；
- ⚠️ 与旧稿公式（0.6±，**余量口径**）不兼容——A 案下区间重标为总额口径 **0.02~0.08**，旧值**不得**平移（否则地方一口吃掉七成，中央崩塌）。

### 3.3 `diversion_rate`（非法侵渔 · 新语义）

- 语义＝**财政份额**（侵渔占总额比），开局 **0.02**；
- **旧 `diversion=0.35` 参数退役**（`game_state_econ.py:537`，原 `−diversion×0.25` 压低 arrival）——输入旋钮→输出份额，语义完全不同，不退役即双计；
- 与既有 `clerks._extort`（`clerks.py:235`）**反双计**：本机制＝**税内截留**（账面记损耗），extort＝**税外索取**（直接扣 wealth，民心付出 `EXACTION_MOOD_DIVISOR`）；并存、不抵扣、不双写。

### 3.4 归一化（单点函数 · 保护顺序）

```
normalize_finance_split(transfer, keep, div) → 调整到 t + k + d ≡ 1
调整自**最低保护等级**起：
  ① 先动 diversion_rate（残差吸收）
  ② 不足再动 local_keep_rate
  ③ 最后才动 transfer_rate（中央稳定是系统核心）
各率钳制：transfer ≤ 0.98、keep ∈ [0, 0.20]、div ≥ 0
落点：单点函数（建议 `game_state_econ` 收支域）；全库只此一处归一。
```

## 四 · 三角取舍（**甲案**）与财政校准门

V1.2 终裁：**甲案**——民负 +5~9%、中央持平、初始分流 5~8%。开局 **0.94 / 0.04 / 0.02**。

- **数学**：`应征 = 现状实付 / transfer_rate`；transfer=0.94 ⇒ 民负 **+6.4%**（落 +5~9% 区间）；`central = 应征×transfer ≡ 现状`（持平）；
- **为何民负微增**：现行 POP 实付≈0.59×B 且全数入国库；"民负持平＋中央持平＋侵渔>0"数学上不可能三全（三角不可能）。甲的让出量最小（对比"全额 G 案"的 +69%），且可叙事为"**既有侵渔显性化**"，非新增盘剥；
- **分流初始**：`0.94 / 0.04 / 0.02`（每 100 贯：中央 94、留州 4、侵渔 2）；
- **财政校准门（P1 硬验收，每批回归）**：同种子 ≥12 月对比 **国库余额 / 人口 / 民生指数 / 粮价 / 地方稳定** 五项——不得明显劣化；
- 双层税基标定（旧 C1 改写）：`tax_base × collection_rate ≈ 现状实付 × 1.06`（P1 内实测定，不预设）。

## 五 · 账面系统（官方账目 · 真账落差）

### 5.1 设计

- **真账**＝`money.ACCOUNTS`（国库/内帑/地方库/POP 钱池）；
- **官方账目**＝玩家与大臣所见：`tax_breakdown`／`statistics`／econ summary（`game_state_econ.py:497-532`）／月报；
- 落差＝embezzle 在账面写成"损耗"（账面自洽，开局口径："税收100 ＝ 中央94 ＋ 地方4 ＋ 损耗2"）。

### 5.2 火耗科目 `tax_loss_report`（新增键，非新账本）

```
state.statistics["tax_loss_report"] = {"运输损耗":…, "地方耗费":…, "火耗":…, "杂费":…, "total":…}
```

- **真实＝侵渔（`diversion_rate` 份额）；账面＝火耗类目**——做账的载体；
- 命名定稿 **`tax_loss_report`**（含运输/杂费，覆盖面优于旧拟 `tax_fire_loss`）；范式对标粮侧 `granary_stats["canal_loss"]`（漕运损耗已存在，`game_state.py:702`）；
- 实测核查：现金**火耗**科目**不存在**（`SPARROW_RAT` 只管粮耗）——全新键；
- 账面读取点：econ summary / 月报财政章（叙事钩子"火耗奇重"，月报挂点 `monthly_gazette.py`）。

### 5.3 信息差三级

| 观察者 | 所见 |
|---|---|
| 普通账面 | "耗损增加"（正常波动 vs 异常增长难辨） |
| 监察能力高 | "**耗损异常**"（告警） |
| 调查后 | "**侵渔金额**"（真相，档位/区间） |

## 九 · 改革三轴（一一对应四率 · V1.2）

| 轴 | 动率 | 效果 | 代价/风险 |
|---|---|---|---|
| **强中央** | `transfer_rate` ↑ | 中央份额↑、上供增 | 地方积极性/能力降 |

## 十二 · 守恒与验收断言（每批必带）

1. 单月 `_settle_finance` 前后 `m_all(state)` 不变（纯转移）。
2. 逐路逐月：`central + local + embezzle ≡ 实收`（实收＝应征经豁免/欠税后）。
3. `local_treasury` 增量 == Σ `实收 × local_keep_rate`。
4. 官僚 POP wealth 增量（本机制贡献）== Σ `实收 × diversion_rate`。
5. `treasury` 增量 == Σ `实收 × transfer_rate`（与保底豁免/欠税口径对齐）。
6. **归一化**：`transfer + keep + div ≡ 1`（容差 1e-9；保护顺序 §3.4）。
7. **账面分离**：`statistics.total_income` 不含截留额；`tax_loss_report` 与 `diversion_rate` 份额逐月对核。
8. **财政校准门**（P1 起每批回归）：同种子 ≥12 月，五项指标（国库/人口/民生/粮价/地方稳定）不显著劣化。
9. 路级 `pops` 只读守卫零违规（`SONGZUO_POPS_GUARD=1`）；长局（≥15 月）`m_all` 全程不变。
