## 3. 拆分与聚合规则

- `treasury` **不是**均值类（不适用 MEAN_FIELDS「原样复制 + 按 size 加权」那对设计）——
  它是**可加总量**：拆分侧按份额给出、聚合侧直接求和。
- 拆分份额取什么？**本设计不自行发明**：`seats` 已有的份额依据是 `pop_bridge.seat_pop_weights`
  （按 `size` 加权，AGENTS.md 提到其"权重非空"教训）。**第一版按该权重分摊**，
  并在口径里显式声明"分摊基于人口权数，属**推演**而非史料"（输出标签须可查）。
- 聚合：`aggregate_*` 求和；**逐字段与路级镜像差恒为 0**（与 POP 同型断言）。

## 4. 迁移与新局/读档接线

1. 新增 `migrations.sink_treasury_to_seats(state) -> int`：**无条件幂等**（已下沉跳过），
   把路级 `treasury` 按 `seat_pop_weights` 分摊到各治所，返回受影响路数。
2. `new_game`（`application/game_init`）与**读档**共用同一入口——与 `sink_pops_to_seats` 同型，
   避免两条路径分叉（POP 那条的教训：顺序/入口不一即分叉）。
3. ⚠️ **顺序**：必须在 POP 下沉**之后**调用（份额依赖 `seats[].pops` 的 `size`）。

## 5. 写点迁移（第一步只做"可加总量"这一路）

- 新增桥接函数 `treasury_add(obj, fld, delta, state=None)` / `treasury_set(...)`：
  `state` 为 `None` → 返回 `None`（未下沉/旧路径回落）；给了 `state` → 落到治所真账并刷新镜像。
- 调用点改法沿用既有惯例：`if treasury_add(...) is None: <原写法>`。
- **测试构造前置同样要桥接**（直写镜像清不掉真账——POP 那条踩过）。

## 6. 守恒与验收断言

| 断言 | 说明 |
|---|---|
| Σ 治所 == 路级镜像 | 逐字段、恒为 0 差（与 POP 同型） |
| 新局覆盖 | `commands.new_game()` 后 **20/20 路 seats 有 `treasury`** |
| **P0 第 5 门** | **只冲击一路，不得带动全图同变**（这是 A-粮价债务的验收目标） |
| M0–M3 对账 | 货币口径恒等式仍成立（`货币口径规范_M0M1M2.md`） |
| 缺失语义 | 未定义处返回 `None`，界面显示"未定义"，**不回落 0** |
| 旧档迁移 | 旧档读入后幂等补齐，往返一致 |
| 守卫 | 装 POP 守卫跑满 15 月**零违规**（`SONGZUO_POPS_GUARD=1`） |

## 8. 与 A-粮价债务的收口关系

有本地真账后，`game_state_econ.py:315` 的 `wine_share` 与 `:327-328` 的 `_gran_share`
