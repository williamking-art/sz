# 主线 F 外贸**逐笔真账**：只读设计（2026-10-13 · M141）

> 前置：M139 取证（常量齐备 · **无对外入口** · **无逐笔容器**）· M140 第 18 项读数
> `trade_line_status=4`（已把"素材就绪度 + 真账缺口"变成可下钻读数）。
> 🔴 本件**只出设计**：不写 state、不改结算、不建容器。**三条口径待你裁定**（见 §4）。

## 1. 目标（要能回答的四个问句）

「**哪一路**、**哪一货**、**跟谁**、**多少**（数量/价格/运费/税费）」，且**钱与货双守恒**。
对应 P5 验收问句链的「谁本来应供」与「结果影响了谁」。

## 2. 硬约束（不得违反）

| 约束 | 含义 |
|---|---|
| §3-1 **禁与 POP 平行的账本** | **存量**（钱/货）只能落 POP `wealth`/`goods`、国库/内帑、`resources`；**不得**新建"外贸库存" |
| §3-2 口径单点 | 费率/税率/地形距离乘数**已在 `trade_shadow`**（`LOGISTICS_FEE`/`SEA_FREIGHT`/`OVER_TAX_SHARE`/`STAY_TAX_SHARE`/`DISTANCE_BAND`/`TERRAIN_MULT`）⇒ **不得复制** |
| §3-3 缺失≠0 | 无该路数据 ⇒ `None` + reason（例如未通水路的路不报 0，报"未通"） |
| 钱守恒 | 任何一笔：出口方钱↑ ⇒ 进口方钱↓（同额）；运费/税费**各有归属**，不得蒸发 |

## 3. 载体候选（**待裁**）

| 候选 | 做法 | 是否新增账本 | 优点 | 风险 |
|---|---|---|---|---|
| **甲（推荐）** | **只记流水**：新增 `state.trade_journal`（**append-only 逐笔事件**：路/政权/商品/量/价/运费/税费/去向）＋存量仍落既有载体 | 否（**流水不是账本**：不含余额、不可被当存量查询；与既有"转账日志"同级） | 四问全可答；**存量仍在 POP/国库** ⇒ 不碰 §3-1；便于审计与回放 | 需定义事件 schema 与容量上限（长局膨胀） |
| 乙 | 新增 `state.trade_legs`（**带余额/在途的容器**） | **是**（若含余额即在造平行账本） | 查询快 | **违反 §3-1（除非只放"在途"且明证非存量）** |
| 丙 | 不建容器：只把影子函数结果做成读数（现状 = M140） | 否 | 零风险 | **无法回答四问**（只能报素材就绪度） |

**我的建议：甲**——"**流水可留、余额不新造**"。若你更保守，可先走**丙 + 逐笔只读采样**（不落 state）。

## 4. **三条口径待你裁定**（本设计的核心问题）

1. **账本载体**：甲（只记流水）/ 乙（含在途容器）/ 丙（不建，仅读数）——见 §3。
2. **过税 vs 住税**：`OVER_TAX_SHARE`/`STAY_TAX_SHARE` 已有，但"**谁收、入哪个账户**"未定：
   - 候选：过税 ⇒ **沿途路级地方府库**；住税 ⇒ **交易发生地治所所在路**；两者皆入 `local_treasury_bridge`。
   - 影响：地方府库收入结构（是 D 线营运资金的潜在来源之一，与 M122 的"营运资金来源"**相互影响**）。
3. **与 `statistics` 的关系**：外贸税费是否计入既有 `statistics`（月报/财政口径）？
   - 候选：① 计入（与既有税目同表，需防**双重计数**——本会话已修过一次同类缺陷 M74）；
   - ② 单列（新表项，前端另栏显示）；③ 暂不计入（只做流水，待口径）。

## 5. 验收断言（实施时写死）

- [ ] **双守恒**：`Σ货`（出口减 + 进口增）与 `M_ALL`（钱只在账户间转移）逐笔可对账
- [ ] **运费/税费归属明确**：每笔的运费与两税都有**明确收款方**，不得"消失"
- [ ] **不新增平行账本**：`trade_journal` 内**无余额字段**（用断言锁定：不得出现 `balance`/`stock` 语义键）
- [ ] **口径单点**：费率/税率一律取自 `trade_shadow` 常量，**不得**在结算里重写数字
- [ ] **缺失≠0**：未通水路/无该政权 ⇒ `None` + reason
- [ ] **同种子 A/B**：接线 vs 不接线逐月对账（**接线必然改数值** ⇒ 须标定 + ≥60 月长局 + 全量回归）

## 6. 回滚

只需清空 `trade_journal` 与接线开关（存量从未被本设计改动 ⇒ 回滚不动钱货）。
