## P1 产能：**判定优先级**与**转档阈值**（M198 实测 · M199 Jev 裁定甲 0.764）

### 判定优先级（`p1_pilot_chain.diagnose_route`，`verdict = reasons[0]["code"]`）

```
undefined_data → no_workshop → raw_shortage → **capacity_shortage** → demand_far_exceeds_supply → ok
```

🔴 **含义**：**只要 `cap < demand`，主瓶颈恒为 `capacity_shortage`**——即使成品覆盖不足一成，
那也只是**次级**原因（`demand_far_exceeds_supply` 排在它之后）。

### 阈值公式（**转档条件**）

| 量 | 算法 | 实测（开局/60 月） |
|---|---|---|
| `cap`（产能上限/轮） | `yield × 座数`（丝坊 `yield = 8000`） | 28 座 ⇒ **224,000** |
| `demand`（需求） | `_route_demand(state, route, "绸")`（走 **M74 的 max 口径**） | ≈ **4,556,740** |

⇒ **`capacity_shortage` 不再出现 ⇔ `座数 ≥ demand ÷ yield ≈ 4,556,740 ÷ 8,000 ≈ **570 座****
（当前 28 座的 **≈20 倍**；20 路平均每路 ≈28 座）

### 验收口径（M199 裁定）

🔴 **不得把「转档」当作本批验收标准**（等价于要求 ≈570 座）。
**验收改为**：① 座数/产能按裁决**已提升**（7 → 28，产量实测 ×4）；② **单路覆盖显著改善**
（京畿路单路口径 2.3% → 约 9%）；③ 恒等式与守恒不变（**未造钱物**）。
**远期目标**（若需要）应单列：`cap ≥ demand`（≈570 座），并**重开量级裁定**（须重估工匠 POP 用工与丝需求）。
