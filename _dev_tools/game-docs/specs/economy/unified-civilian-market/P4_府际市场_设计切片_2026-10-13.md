## 二、第①段「府际市场」设计（**先不做所有路线任意互通**）

**口径**
1. **路线表（新增、可复原）**：`(from_路, to_路, 距离km, 路况, 运力/月, 损耗率, 关卡状态)` —— 由 `transport` 原语**派生**（不手抄），**缺失即不启用该路线**（无来源不启用）。
2. **在途批次**：`{批次id, 货主(既有词表), dim, qty, from, to, 发运月, 到达月, 运费, 状态}` —— 复用 `transport.dispatch/arrive_due`；**未到货不得使用**（验收门原文）。
3. **成交**：月初**意向快照** ⇒ 当月约束（预算/运力/库存/关卡）下撮合；**价差只在扣除运费+税费+资金占用+风险后才算套利**（原文）。
4. **运力与损耗**：每路线每月**有限运力**；损耗按路况；**无预算或运力不成交**（验收门）。
5. **税费与记录**：**没有实际贸易记录不得计市舶税或外销收入**（原文）⇒ 税基＝**逐笔成交记录之和**。

**调用链（拟定，不动手）**
```
月初：route_table(派生) → 意向快照（谁想把什么从哪运到哪）
当月：intent × 约束(预算/运力/关卡/库存) → 成交 → 落「在途批次」
月末：batch.arrive_due → 到货入目的地账本 → 记 逐笔贸易记录 → 税/费按记录计
```
**数据形态**：所有新容器**逐笔**（可下钻），**不新增与 POP 平行的存量账本**（货主一律用既有词表 `pop:<路>:<阶层>` / `local:<路>` / `state_treasury` / `imperial`）。

**验收断言（先写死，实施时照此测）**
- [ ] **关路后**贸易量/价格/税基**逐月变化**（可回放）
- [ ] **无预算或运力时不成交**（构造性用例）
- [ ] **在途货未到不得使用**（到位前读不到）
- [ ] **沿途转售不重复计收入**（逐笔唯一）
- [ ] **无贸易记录 ⇒ 市舶税/外销收入 = 0**（且**不是** `None`，因为"确实没有记录"≠"不可读"）

**非目标（明确不做）**：不做"全世界一个市场"；不做所有路线任意互通；本段**不接**欧洲终端需求（属第④段）。
