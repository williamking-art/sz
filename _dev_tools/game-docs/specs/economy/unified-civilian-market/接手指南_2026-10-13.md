## 6. 本会话踩过的坑（**照抄能省一整轮**）

1. **JSON 内层直引号**：写 `decisions/`/`tasks/` 时用 **「」**；`check` 报「id 与文件名不一致」**真因常是
   `json.load` 失败**。提交前必 lint（本会话 lint 门**四次**挡住非法提交）。
2. **段落截断 / 同名键**：`edit` 的 `old_string` 必须带**完整边界**；**成对投影（建筑 vs 作坊）里同名键
   （`methods`/`maintenance`/`income_to`）出现两处时，先用 `grep -n` 定唯一锚点**（用两侧互不相同的
   邻行），改后**复查键计数**——Python **字典重复键是静默的**（本会话因此回滚过一次）。
3. **`replace_all` 仅适用于两处文本确实同构**（曾把作坊分支替换成引用 `_meta` 的建筑版本 ⇒ 三红）。
4. **性能门**：`test_situations.py::test_readout_performance_gate` 会因读数**全量扫描**变红
   ⇒ 读数里遍历实体**必须设采样上限并如实标注**。
5. **断言绑语义不绑计数**：`defined_count == N` 每加一个派生字段就误红（本会话 3 次）⇒ 用集合成员断言。
6. **PowerShell**：含引号/反引号的文本一律 **here-string 写文件**再传；用反引号拼 `handover.py log`
   位置参数会**解析失败且输出丢失**（本会话复发过一次）。
7. **索引坑**：新模块/新文档未回填 README ⇒ `test_readme_sync` 红（本会话 **4 次**，含 `DECISIONS-INDEX.md`）。
