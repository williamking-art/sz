## 0 · 一句话

`local_treasury`（州郡府库）**只有"进"和"买粮"，没有"花"**——留州只完成了"分层"（P1 三分），
没有完成"支用"：行政/治安/水利/救灾/仓廪**五条消费性出口一条都没接**。V2 就是把出口接上，
且**不新造账本**（写口＝既有的 `transfer_money("local:<路>", "pop:<路>:<阶层>")`）。

## 1 · 现状（代码事实 · 带行号）

### 1.1 入口（流入）

| # | 通道 | 位置 | 口径 |
|---|---|---|---|
| 1 | 田赋折色**留州**三分腿 | `settlement_finance._settle_land_tax_color`（P1） | `paid × keep`（开局 keep＝0.04）→ `pref["local_treasury"] +=` |
| 2 | 州郡赈济**拨款** | `commands_decree.py:78` | 国库 → 各州郡府库（成对划转、按路均分、余数归首路；国库不足则拒付） |
| 3 | 常平**平粜回收** | `settlement_granary.py:224/261` → `settlement_common._changping_trade(sell)` | 本路民间 POP 买粮 → 钱入本路府库（`statistics["changping_recycled"]` 累计） |
| 4 | 常平**平籴支付**＝**流出** | 同上 `(buy)` | 府库现金 → 本路民间 POP，粮入 `changping_stock`（**资产形态转换**，非消费） |

### 1.2 出口（流出）——**只有平籴**

- 除 `_changping_trade(buy)` 外，**全库无任何** `local_treasury` 消费性支出写点
  （`settlement_common` 4 处 / `settlement_granary` 3 处 / `settlement_finance` 5 处全部是
  流入、平籴支付或读数）；
- 即：**"只进不出"应精确表述为「只进 ＋ 只买资产（粮），无消费性支用」**。

### 1.3 规模实测（同种子 12 月，`_dev_tools/_scratch/m34_local_probe.py`）

| 指标 | 开局 | 12 月后 | 增量 |
|---|---|---|---|

| Σ`changping_stock`（常平仓·石） | 14,735,443 | 26,101,817 | +11,366,374 |
| Σ`storage`（太仓·石） | 60,100,000 | 60,936,549 | +836,549 |

**规模对照（月度）**：常支 `MONTHLY_EXP_CIVIL_BASE` **880,000**；官俸 `calc_official_cash()` **871,457**（均 **43,573/路**）；军费 `calc_army_cash()` **1,124,462**。

**逐路府库（12 月末，极不均）**：京畿路 1,812,179／河北路 1,346,608／京东东路 1,070,518／河东路 993,345／陕西路 948,532／京西路 877,552 … **荆湖北路 仅 2,877**、淮南东路 2,958、荆湖南路 3,728。

⇒ 三条硬事实：
1. 府库**并非"死水"**：平籴（买粮）12 个月抽走 ≈770k/月（含平粜回收冲抵），余量在 8.7–12.2M 之间**波动**；
2. 但**消费性支用＝0**：留州只换成了粮，没有换回治理；
3. 府库**逐路差三个数量级**（京畿 1.8M ↔ 荆湖 2.9k）⇒ 任何"按路固定额"的支出设计都会让穷路立刻欠费，必须同 `_settle_upkeep` 的**按可付截断＋欠费科目**。

## 2 · 可复用的唯一范式（守恒三律 · 禁止另造）

**范式 A · 结算期支出（`_settle_upkeep`，`core/domains/administration/settlement_officialdom.py:87`）**
```
due  = 资产折算 × 费率                # 派生（单点公式）
paid = min(due, 支付能力)             # 不穿底
缺口 → statistics["upkeep_arrears"]   # 欠费科目（与「欠饷」「欠税」同构）
change_treasury(-paid)                # 出账
distribute_cash(state, paid, 表)       # 全额给民间 POP（精确守恒，尾差兜底退回国库）
```
**范式 B · 逐路划转（`GameState.transfer_money`，`game_state.py:1139`）**
```
state.transfer_money(f"local:{路}", f"pop:{路}:{阶层}", amt)   # 按 src 可付截断，返回实转额
```
- 账户语法**已支持** `local:<路>`（`game_state.py:1165-1195` 读写＋`_writable` 校验）与 `pop:<路>:<阶层>`；
- `money.ACCOUNTS` 的 `local_treasury_total()` **已聚合**（不双计）；
- ⇒ **V2 的写口零新增**：`transfer_money` 即单点；**禁止**任何模块直写 `pref["local_treasury"]`。

**范式 C · 逐路成对（`_changping_trade`）**：钱腿＝本路府库，粮腿＝本路民间 POP，ΣΔ==0。

## 4 · 守恒与不双计（验收断言草案）

| # | 断言 |
|---|---|
| C1 | `ΣΔ(府库) + ΣΔ(本路民间 POP wealth) == 0`（每科目、逐月） |
| C2 | `paid ≤ pref["local_treasury"]`（不穿底、不造币）；缺口 == `statistics["local_arrears"]` 增量 |
| C3 | **不双计**：地方支出**不进**国库 `total_out` / `statistics["total_expenditure"]`（不同主体）；总账面另立只读科目 |
| C4 | 只读纪律不破：`income_readout`（`pref_local_treasury` / `grant_pool_upper_bound`）仍纯投影 |
| C5 | 月报「度支录」账目行新增地方科目后，**掩护拆分和 ≡ total** 不被破坏（P2 契约） |
| C6 | 存档往返（`save_load`）后 `local_arrears` 与各科目累计一致 |

## 6 · 方案（三选一）

| 方案 | 内容 | 代价/风险 |
|---|---|---|
| **甲（推荐）搬移为主＋触发式新增** | ① 行政：州郡官俸的**地方承担份额**（史实：公使钱/职田/州郡经费，初值 **5–10%**）由府库出、**国库同额少出**（国库不受损）；② 水利/粮仓：**地方性资产**（水利/常平仓等 POP 建筑）维持费从国库搬入府库（同额）；③ 救灾：**仅灾月**净新增（付本路贫民）；④ 治安：随 `unrest` 净新增（**小比例**）。常规月净烧库≈0，灾/乱时才烧 | 需改 `_settle_upkeep` / 常支的**分腿**（一处口径改动，风险中）；穷路按可付截断 → 欠费正常化 |
| **乙 纯新增** | 五科目全部净新增（府库单方面出钱） | 府库 12 月已 −46.5%、且平籴月均 −770k ⇒ **必须**同时给月支出**封顶**（≤ 当月留州流入的 x%），否则 3–6 月见底、常平稳定器被挤死 |
| **丙 只做账目/观测（不动钱）** | 把现状（只买粮、无支用）显性化到读数/月报 | 不解决"留州支用名不副实"；改革轴（keep↑）依旧无意义 |

**推荐甲**：与史实"公使钱/州郡经费自筹"一致；常规月**不改变五项目标**（搬移），只在灾/乱月增加府库消耗——长局可控、校准门易过。
