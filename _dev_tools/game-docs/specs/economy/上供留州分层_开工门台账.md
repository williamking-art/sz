## 3 · 守恒口径（公式）

```
令 G = 本路田赋全额税基（钱，来自 calc_monthly_tax_income 未乘 arrival 的基数）
POP 实付 = G                         ← 钱真出 POP（_pop_obj_add wealth −G）
国库     += arrival × G
地方库   += (1 − arrival) × G × keep       keep ∈[0,1] 入库比例
吏 POP   += (1 − arrival) × G × (1 − keep) 侵渔入袋
────────────────────────────────────────────
ΣΔM_ALL  = −G（POP） + arrival·G + (1−arrival)·G·keep + (1−arrival)·G·(1−keep)
         = −G + arrival·G + (1−arrival)·G = 0   ✅ 纯转移，守恒闭合
```

**关键约束**：POP 必须付**全额 G**（比现状多付，因为现在付的是打过折的税基）。截留的那份 `(1−arrival)·G` **必须**落到地方库或吏囊，不得凭空消失——这是唯一会被守恒测试盯的地方。

## 4 · 丙方案分流：keep 派生（**待裁 B**，唯一需拍板项）

用现成路级字段 `state.corruption[路]`（0-1）与治理度派生入库比例：

```
keep = clamp( keep_base − corruption[路] × keep_corr_w , keep_min, keep_max )
```

- 腐败低 → keep 高（多入府库）；腐败高 → keep 低（多入吏囊）
- **待裁**：`keep_base / keep_corr_w / keep_min / keep_max` 四个系数取值
