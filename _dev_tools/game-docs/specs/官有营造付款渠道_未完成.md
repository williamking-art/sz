
### 1.2 🔴 `local_treasury` **不是可划转账户**

`money.py:68` `ACCOUNTS` 含 `"local_treasury"  # Σ 各路地方府库`，
但它是**聚合投影**：

```python
# money.py:180
def local_treasury_total(state) -> float:
    return float(sum((p.get("local_treasury", 0) or 0)
                     for p in ...))
```

⇒ **逐路 `p["local_treasury"]` 是普通字段**，
**无对应的 `transfer_money` 账户 id**。

⇒ ⚠️ **若自行发明 `"local:{路}:treasury"` 之类账户名 ⇒ 即造「与钱账本并行的账本」**，
违反 POP 挂载律律条 4（钱只落 POP `wealth` 或国库/内帑）。**本轮明确不做。**
