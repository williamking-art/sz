## 一、侦察结论

### 1.1 🟢 **外邦数据很丰富**（可直接支撑贸易）

`content/data_external._ext()` 每个政权提供：

```
name / type / hotspot    \u540d\u79f0\u00b7\u7c7b\u578b\u00b7\u5730\u56fe\u5750\u6807
power / population       \u5b9e\u529b\u00b7\u4eba\u53e3
storage / grain / land   \u50a8\u5907\u00b7\u7cae\u00b7\u7530\u4ea9
attitude                 \u5173\u7cfb\uff08\u9ed8\u8ba4 50\uff09        \u2190 **\u8d38\u6613\u9a71\u52a8\u56e0\u5b50**
monthly_tax / growth_curve
```

另有 `_ext_pop_by_heads()` 按类型派生**六阶 POP**（农/士绅/工匠/商人/官僚/兵）
⇒ **外邦有完整的人口与阶层结构**。

### 1.2 🔴 **宋 ↔ 外邦之间没有任何货物贸易**

```
\u5168\u5e93\u68c0\u7d22\u300cexternal.*trade / \u5916\u90a6\u8d38\u6613 / \u901a\u5546\u300d  \u21d2  \u4ec5\u4e00\u5904\u53ec\u5bf9\u6587\u672c
```

现状是：**外邦经济独立模拟**（`_settle_external_economy`，**宋总账零变化**）——
即**两条平行经济，互不往来**。

### 1.3 已有可复用件

|---|---|---|
| 外邦数据 | `content/data_external.py` | 人口/态度/储备 |

## 二、设计总纲

### 2.1 两类伙伴（用户明定）

| 类 | 名单 | 建模深度 |
|---|---|---|
| **已有外邦** | **辽 · 西夏 · 吐蕃 · 大理 · 高丽 · 日本** | **完整**：有 POP、有态度、有储备、有货种 |
| **抽象化身** | **中亚 · 欧洲** | **简化**：只提供**进口货种**与**需求**，**不建 POP** |

⚠️ 与《主要国家与外邦设定分层》一致：**主要国家（辽/西夏/大理/高丽/日本）应有完整底层**；
中亚/欧洲按「抽象化身」处理。

## 三、货腿设计（核心）

### 3.1 出口（宋 → 外邦）

| 项 | 规则 |
|---|---|
| **货种** | 丝 · 茶 · 布 · 绸 · 瓷（宋的优势品）|
| **货源** | **优先取商人的 goods**（商人本就经营）；不足则取官仓 |
| **扣减** | 按 `trade_goods` 同口径，**受真实存量约束**（不凭空给货）|
| **去向** | 计入外邦 `storage`（外邦侧变量，**宋侧只减不增**）|

### 3.2 进口（外邦 → 宋）

| 外邦 | 主进口货种（**依史实**）|
|---|---|
| **辽** | 马 · 皮毛 · 药材 |
| **西夏** | 马 · 青盐 · 药材 |
| **吐蕃** | 马 · 药材 · 硇砂 |
| **大理** | 马 · 麝香 · 贝 |
| **高丽** | 人参 · 布 · 纸 |
| **日本** | 硫黄 · 刀剑 · 漆器 |
| **中亚/欧洲**（化身）| 香料 · 珠宝 · 玻璃 · 良马 |

⇒ 进口货入**宋方池**：商人 goods 优先，或官仓（**须裁定**）。

### 3.3 🔴 对账恒等式（必须在设计里写死）

```
\u5b8b\u65b9\uff1a\u51fa\u53e3\u8d27\u51cf\u5c11 + \u8fdb\u53e3\u8d27\u589e\u52a0 + \u51c0\u94b1\u6d41\u5165\uff08external\uff09
\u5916\u90a6\u65b9\uff1a\u51fa\u53e3\u8d27\u589e\u52a0 + \u8fdb\u53e3\u8d27\u51cf\u5c11 + \u51c0\u94b1\u6d41\u51fa
\u21d2 **\u4e24\u8fb9\u5404\u81ea\u5b88\u6052**\uff1b\u8de8\u653f\u6743\u4e0d\u5b58\u5728\u201c\u51ed\u7a7a\u201d\uff08\u9664\u975e\u660e\u786e\u6807\u4e3a\u4f53\u5916\u6ce8\u5165\uff09
```

⚠️ **关键**：市舶现有实现**只做钱腿**，注释自称「货出、外银入」但**无货腿** ⇒
**本次要补的正是这个不对称**。

## 四、驱动设计

### 4.1 贸易额（`attitude` 驱动）

```
\u8d38\u6613\u989d = \u57fa\u6570 \u00d7 f(attitude) \u00d7 \u4ea7\u54c1\u4f9b\u7ed9\u80fd\u529b
f(attitude)\uff1a\u4f4e\uff08<30\uff09\u21d2 \u51e0\u4e4e\u65ad\u7edd\uff1b\u4e2d\uff0850\uff09\u21d2 \u5e38\u6001\uff1b\u9ad8\uff08>70\uff09\u21d2 \u5174\u76db
```

### 4.2 与既有 `attitude` 的联动

- 贸易**提升** attitude（互市通好）；
- 战乱/岁币**降低** attitude；
- ⇒ 形成**「关系 ↔ 贸易」双向环**（**须防振荡**，需收敛机制）。

## 五、抽象化身（中亚 / 欧洲）

| 项 | 规则 |
|---|---|
| **不建 POP** | 只作**贸易对手**（用户明定「只是个抽象的化身」）|
| **提供** | 进口货种（香料/珠宝/玻璃）+ 需求（买丝/瓷）|
| **驱动** | 固定基数 + 时代/科技加成（不参与态度环）|
| **接入点** | 复用同一货腿函数，`regime` 传抽象名 |

⇒ **实现上与「已有外邦」共用同一套货腿**，只是对方**无状态**（不需要扣它的货）。
