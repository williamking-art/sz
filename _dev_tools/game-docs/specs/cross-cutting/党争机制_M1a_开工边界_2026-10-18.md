## 3. 份额口径（五类，守恒）

```
Σfaction_share
+ vacant_share
+ unaffiliated_share
+ concurrent_discount_share
+ acting_discount_share
= 1.0
```

- 分母 `W_org = Σ_{i∈established} w_i`，**固定不随人事变动**。
- M1a `acting_supported=False` ⇒ `acting_discount_share=0.0`（退化为四项守恒）。
- `vacant_share` **只表示真实空缺**，不再吸收兼任/代理折损。
- `filled_posts` = 实际有人任职的槽位数（户部 3 岗中 2 岗有人 ⇒ 2）。

## 4. 输出 schema

```python
{
  "as_of_turn": int,
  "weight_mode": "headcount",
  "acting_supported": False,
  "excluded_orgs": ["..."],              # abolished=True
  "orgs": {
    "户部": {
      "defined": True,
      "posts_total": 3,
      "filled_posts": 2,
      "vacant_share": 1/3,               # 真实空缺 1 岗 / 3
      "unaffiliated_share": 0.0,
      "concurrent_discount_share": 0.5/3, # 次职折损 0.5 / 3
      "acting_discount_share": 0.0,
      "faction_share": {"中立派": 1.5/3},
      "holders_detail": [
        {"post": "户部尚书", "holder": "王古", "faction": "中立派",
         "post_weight": 1.0, "faction_counted_weight": 1.0,
         "unaffiliated_weight": 0.0, "concurrent_discount_weight": 0.0,
         "acting_discount_weight": 0.0,
         "is_primary": True, "concurrent": True, "acting": False},
        {"post": "户部侍郎", "holder": "", "faction": None,
         "post_weight": 1.0, "faction_counted_weight": 0.0,
         "unaffiliated_weight": 0.0, "concurrent_discount_weight": 0.0,
         "acting_discount_weight": 0.0,
         "is_primary": False, "concurrent": False, "acting": False},
        {"post": "抵当所提举", "holder": "王古", "faction": "中立派",
         "post_weight": 1.0, "faction_counted_weight": 0.5,
         "unaffiliated_weight": 0.0, "concurrent_discount_weight": 0.5,
         "acting_discount_weight": 0.0,
         "is_primary": False, "concurrent": True, "acting": False}
      ],
      "concurrent_holders": ["王古"],
      "notes": []
    }
  }
}
```

**字段约定**：
- 所有权重字段类型为 **float**（主职 1.0、次职 0.5、空缺 0.0）。
- `concurrent=True`：同一人在该机构持有**多于一个岗位**时，其**全部岗位条目**都标 True；`is_primary` 区分主职。
- `concurrent_holders`：按首次出现顺序去重记录人名。
- 汇总值必须等于明细逐项加总；测试同时断言两者一致。

## 5. 规则（逐条，全部要有测试）

1. **真实空缺**：`holders.get(title) in (None, "")` ⇒ `vacant_share`；`faction_counted_weight=0`。
2. **主职**：同一人在同机构多岗时，按 `posts` 顺序第一个为主职（或最高权重）；主职全额计入其派系/未归属。
3. **次职**：其余每个岗位 `0.5` 计入其派系/未归属，`0.5` 计入 `concurrent_discount_share`。
4. **≥3 个兼职**：除主职外每个都按 `0.5/0.5` 拆。
5. **未登记派系兼任**：主职全额计入 `unaffiliated_share`；次职 `0.5` 计入 `unaffiliated_share`、`0.5` 计入 `concurrent_discount_share`。
6. **代理**：当前无字段 ⇒ `acting=False`、`acting_discount_share=0.0`；未来启用时与次职同口径（0.5 派系/未归属 + 0.5 `acting_discount_share`）。
7. **全部岗位空缺**：`defined=True`、`vacant_share=1.0`、其余 0。
8. **无岗位定义 / 空列表**：`defined=False`、`vacant_share=None`，不得输出 0/1。
9. **岗位标题重复**：`defined=False` + `error="duplicate_post_title"`（数据错误，不静默）。
10. **机构废置**：不进入 `orgs`，列入 `excluded_orgs`。
11. **纯函数**：不写 `state`；调用前后 `state` 深比较相等；返回对象被调用方修改不影响 `state` 或后续调用。
12. **确定性**：同一 state 多次调用输出完全相同。

| 类型 | 验收 |
|---|---|
| 状态不变 | 调用前后 `state` 深比较相等 |
