## 4. 输出 schema

```python
{
  "as_of_turn": int,
  "weight_mode": "headcount",          # 本阶段唯一支持
  "acting_supported": False,           # 当前无代理字段
  "excluded_orgs": ["..."],            # abolished=True
  "orgs": {
    "吏部": {
      "defined": True,                 # False = 无岗位定义（undefined）
      "posts_total": 2,
      "filled_posts": 1,
      "vacant_share": 0.5,             # 空缺岗位 / 应设岗位
      "unaffiliated_share": 0.0,       # 未登记派系 / 应设岗位
      "faction_share": {"新党": 0.5},  # 不含空缺与未归属；与上面两项合计 = 1.0
      "holders_detail": [
        {"post": "吏部尚书", "holder": "邓洵武", "faction": "新党",
         "counted_weight": 1, "concurrent": False, "acting": False},
        {"post": "吏部侍郎", "holder": "", "faction": None,
         "counted_weight": 0, "concurrent": False, "acting": False}
      ],
      "concurrent_holders": [],
      "notes": []
    }
  }
}
```

**份额口径**：`faction_share + vacant_share + unaffiliated_share == 1.0`（分母 = 应设岗位数）。
`faction_share` 内部各派相加 = `1 - vacant_share - unaffiliated_share`。

---

## 5. 规则（逐条，全部要有测试）

1. **空缺**：`holders.get(title) in (None, "")` ⇒ 计入 `vacant_share`，不进任何派系。
2. **兼任（分母守恒）**：分母固定为机构**全编制岗位权重之和** `W_org = Σ established w_i`，不因人事变动缩减。同一人在同一机构多岗时：
   - **主职**（权重最高；并列取 `posts` 顺序第一个）：全额 `w_i` 计入其派系；
   - **次要职**：`0.5 w_i` 计入其派系，剩余 `0.5 w_i` 计入 `vacant_share`；
   - 3 个及以上兼职：除主职外每个都按 `0.5/0.5` 拆；
   - 恒等式仍为 `Σfaction_share + vacant_share + unaffiliated_share = 1.0`；
   - 法定事权仍按岗位逐个计（两套口径分开），`concurrent=True`。
3. **未登记派系**：任职人不在 `MINISTERS`，或 `faction` 为空/未知 ⇒ 计入 `unaffiliated_share`。
4. **全部空缺**：`defined=True`、`vacant_share=1.0`、`faction_share={}`。
5. **无岗位定义**：`defined=False`、`faction_share={}`、`vacant_share=None`（**不得输出 0/1**）。
6. **机构废置**：`abolished=True` ⇒ 不进入 `orgs`，列入 `excluded_orgs`。
7. **代理**：当前无字段 ⇒ `acting=False`、`acting_supported=False`；**不得默认 0.5**。
8. **权重**：当前无权重字段 ⇒ `weight_mode="headcount"`；`position` 模式为待建制度。
9. **纯函数**：不写 `state`；调用前后对 `state` 做深比较必须相等。
10. **确定性**：同一 state 多次调用输出完全相同（无随机、无时间依赖）。

## 6. 验收测试（10 条，基于 `new_game()` 实测）

| # | 场景 | 期望 |
|---|---|---|
| 1 | 吏部（2 岗：尚书=邓洵武/新党，侍郎空缺） | `faction_share={"新党":0.5}`、`vacant_share=0.5`、`unaffiliated=0` |
| 2 | 户部（3 岗：王古/中立派 兼 尚书+抵当所提举，侍郎空缺） | 主职尚书全额 1.0 + 次职抵当所 0.5 计入中立派 = 1.5；次职剩余 0.5 + 侍郎空缺 1.0 = vacant 1.5；即 `faction_share={"中立派":0.5}`、`vacant=0.5`、`concurrent=True` |
| 3 | 门下省（1 岗：李清臣/旧党） | `faction_share={"旧党":1.0}`、`vacant=0` |
| 4 | 中书省（1 岗：曾布/中立派） | `faction_share={"中立派":1.0}` |
| 5 | 构造全空缺机构 | `defined=True`、`vacant_share=1.0`、`faction_share={}` |
| 6 | 构造无 `posts` 机构 | `defined=False`、`vacant_share=None` |
| 7 | 构造 `abolished=True` 机构 | 不进 `orgs`，进 `excluded_orgs` |
| 8 | 构造未登记派系任职人 | `unaffiliated_share>0` |
| 9 | 同一人跨两个机构 | 两个机构各计一次（机构级） |
| 10 | 纯函数/确定性 | state 深比较不变；两次输出相等 |
