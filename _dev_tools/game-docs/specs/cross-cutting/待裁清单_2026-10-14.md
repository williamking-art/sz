## 1. 外贸真账（主线 F）—— 三条口径

**问题**：外贸逐笔真账的**载体**、**税费归属**、**与 `statistics` 的关系**怎么定？

| 口径 | 选项 | 我的建议 |
|---|---|---|
| ① 载体 | 甲 `trade_journal`（**append-only 流水、无余额**）／乙 含余额容器／丙 只做读数 | **甲**（不触 §3-1「禁平行账本」；乙含余额即违规） |
| ② 过税/住税归属 | 过税→沿途路级地方府库 · 住税→交易地所在路 · 或全入国库 | **过税→沿途地方府库（40%）· 住税→交易地（60%）**，走 `local_treasury_bridge` |
| ③ 与 `statistics` | 计入／**单列**／暂不计 | **单列**（混入税目极易**双重计数**；本会话已修过同类缺陷 M74） |

**实测证据**：两税份额 **40:60**（`tax_split(0.05)`＝过 0.02／住 0.03）· 税 **500 贯/万货值** ·
海运 `{fee 50.8, loss 500}`（**fixed 50 主导**）· 陆运个位数贯/万 · `trade_net` 公式自洽 ·
水路覆盖 强 7／有 11／弱 3（多出键**唯一为 `黔中路`**，20 路全覆盖无缺 ⇒ **建议保留加注释**）。

**成本**：中等（注入点 + 桥接 + 记录转账 + **同种子 A/B** + **≥60 月长局** + 全量回归）。
**不定的后果**：外贸**永远只能答"有没有素材"**（第 18 项读数），无法回答「哪一路、哪一货、跟谁、多少」。

## 3. 产能（M82 实证真瓶颈）

**问题**：绸的缺口是**产能**（不是缺料/缺钱），动哪个旋钮？

**实测证据**：7 路主瓶颈**全部** `capacity_shortage`；京畿路 产能上限 **8,000/轮** vs 需求 **341,141**
⇒ **满产也只覆盖 2.3%**（成品覆盖 0.47%）；原料充足（丝 33–92 万/路）。
**选项**：作坊**数量** / **单轮产出**（`WORKSHOP_RECIPES.yield`）/ **一轮时长**。
**成本**：低—中（改参数 + 同种子标定 + 验收读数）。
**不定的后果**：P1 试点链条的缺口（**1,850,540**）不会缩小；`pilot_bottleneck` 恒为 `capacity_shortage`。
