## 0 · 一句话

**现有市场太小**：物资仓开局全空、民间持钱 3.15 亿几乎不花、市价长期 1.2 不涨。
根本驱动应是**百姓衣食住行的需求**，营造材料只是"住"这一环的载体。
政府营造**不是**市场的替代品，而是市场里最大的一个买家，要与百姓竞价拿料。

## 2 · 用户定论（2026-10-01，不可再议）

1. **民间消费跟"各等级的需求"挂钩，也跟"金钱余量"挂钩**——两者相乘，不是相加。
2. **营造材料要接入贸易**，不单是政府能营造，**民间也有消费需求**。
3. **造价跟材料挂钩**；**加大投入能缩短工期**。
4. 加速曲线取**凹函数**（钱 ×2 → 工期 ÷1.4 左右）。
5. 造价口径取**"基准工期/造价为默认 ＋ 另设赶工预算"**（两者都要）。
6. 建材含**木、石、砖**，以及**玩家科研解锁的水泥、钢筋**。
7. 市场整体规模不足，**衣食住行是根本驱动**。

## 4 · 设计口径

### 4.1 民间消费（阶层需求 × 财富余量）

```
月消费额(cls) = Σ_品类 需求(cls, 品类) × 余量释放(cls) × 价格敏感(品类)
余量释放(cls) = clamp((wealth(cls) − 温饱线(cls)) / 余量尺度, 0, 1)   # 贫者不释放
```

- **相乘而非相加**：贫民不会因等级低就不消费，富人不会因余量大就买得起超出等级的量；
- **温饱线** = 保命所需（粮＋布最低档）的钱；温饱线之外才是可选消费；
- **价格敏感**：涨价则降档或减量，避免钱被单向吸纳；
- **量入为出**：消费上限受 `min(余量, 等级需求上限)` 约束。

**待定（需用户确认）**：温饱线是否按阶层各设不同标准；品类是"阶层固定偏好"还是"权重不锁死品类"。

### 4.2 营造材料三层域

| 层 | 材料 | 计价 | 取得 |
|---|---|---|---|
| **L1 实物大宗** | 木(50)、石(30)、铁(250) | 扣**物资仓实物** ＋ 派生钱 | 开局即有 |
| **L2 实物新材** | 砖 | 扣物资仓实物 ＋ 派生钱 | 需新增维度 ＋ 科技解锁生产 |
| **L3 工业制成品** | 水泥、钢筋 | **按加工费计价**（只扣钱，**不占物资仓**） | 科技节点解锁"可用性" |

**L3 为何不入仓**：水泥/钢筋是工厂制成品；若要求仓中有实物，则"先建水泥厂→才有水泥→才能建房子"，
链路过长。科技解锁的是**能不能用**，钱已代表**造它花了多少**。

**建议**：砖走 L2 实物（可囤积、可调拨、可被劫掠，是玩法）；水泥/钢筋走 L3。
**金/银/铜排除**在营造材料白名单外（与"金属≠钱"冲突），蓝图若声明则**拒绝式**报错。

**待定**：砖/水泥/钢筋的单价与解锁节点。

### 4.3 造价与工期

```
基准造价 = Σ(材料数量 × 单价)              ← 派生，不落第二份账
基准工期 = 蓝图 cost.months
投入倍数 k = 实际月投入 / 基准月投入        （缺省 k=1）
工期倍率 = k^α                             （α≈0.5，凹函数）
月度应付 = 基准月投入 × k，且总额封顶 = 基准造价
赶工溢价 = 基准造价 × (工期倍率 − 1) × 溢价系数   ← 不占基准预算，从赶工预算另拨
```

**根治的三个病**：
1. `cost_coin` 与 `cost_material` 各自独立 → **语义冲突**，改为单一材料真源、钱为派生；
2. 营建期**每月重复支付全额**且不递减 → 现实测工期 N 月即付 N 倍
   （1月✓1×／2月✗2×／3月✗4月／6月✗6×），改为总额封顶；
3. 材料同样被逐月重复扣除（与钱同源同病）。

**待定**：赶工预算未用完的资金去向（退还国库／留作维护基金／没收）；锁价 vs 随行就市。

### 4.4 锁价（默认）与贸易的关系

**建议：立项锁价 + 可选调价条款。** 贸易**不改变已签合同的价格**，但改变
**能否按基准价拿到材料**——供不应求时要么等、要么加价、要么换料。
这样既让贸易有意义，又不让物价波动把国库曲线打成不可解释的尖峰
（长局里物资价格会剧烈波动，随行就市将违反"账要可解释"这条硬约束）。

## 5 · 实施顺序（依赖排序，建议分批）

1. **衣食之市**：布帛消费（民间→工商业者 POP，守恒转移）——物资仓第一次有吞吐。
2. **住之市**：民居按人口增长消耗木/砖/石。
3. **物资价格发现**：供需因子 → 动态价（否则贸易无信号）。
4. **营造三件套**：材料计价、投入强度、赶工预算。
5. **民间营造**：民居/商铺存量（依赖第二层）。

---

## 6 · 验收断言（每批必测）

- **守恒**：民间消费与材料采购均为"民间→民间/国库→民间"内部转移，`ΔM_ALL == 0`；
- **有用才买**：余量低于温饱线的阶层消费为 0，不得出现"穷鬼买绸"；
- **价格响应**：需求放量 → 物价上行；供给放量 → 回落（有上限，单月不失控）；
- **守恒优先**：任何价格机制不得破坏 M0/M1/M2 对账与月度残差为 0；
- **不臆造**：物资仓为 0 时不得凭空生成消费（需开局存量或本地生产，二选一须先定）。
