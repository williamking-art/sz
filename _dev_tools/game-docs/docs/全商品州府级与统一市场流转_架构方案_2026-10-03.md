# 全商品州府级 + 统一市场流转 · 架构口径方案（2026-10-03）

> **性质**：口径方案；**批次 G-1 已落地（2026-10-03，纯目录不改行为）**，G-2 起待推进。
> **性质（旧）**：口径方案，尚未动代码。承接用户 2026-10-03 裁定：
> ① 不单是建材，**所有商品都州府级**；② 所有商品**参与经济流转**；
> ③ **工坊消耗的原料应在市场采买**，因而受**物流与产地**影响。
> 本文给出统一模型与分批实施顺序，并标出**一处须用户裁定的硬约束**。

## 一、目标（一句话）

一切商品——原料、成品、粮食——都是**州府级的商品**，落在该州府 POP 的
`goods[治所][dim]` 上，经**市场撮合**按「产地 → 运输 → 成交 → 再投料」流转；
产地分布决定哪里有货，物流决定货多快、多贵地到，**工坊投料必须走市场而非内部直扣**。

本方案不是从零开始，以下地基已在 `865cc251d6` 入库、全量 2178 passed：

**当前只覆盖建材三维**（`MATERIAL_DIMS = ("木","石","铁")`）——本方案要把它扩到**全部商品**。

## 三、统一模型

### 3.1 商品目录（单点）

```
GOODS_DIMS = RAW_DIMS(原料15) + FINISHED_DIMS(成品) + ["米", "麦"]   # 粮并入
```

`米`/`麦` **从 `RAW_DIMS_14` 的「粮」拆分而来**（南方稻、北方麦，宋制粮运与税粮分区皆源于此）。
粮不再是独立于商品的特例，而是 `GOODS_DIMS` 里两个普通维度。

### 3.2 承载与州府归属

- 一切商品存 `pops[].goods[治所][dim]`；治所主键 `路|治所`。
- 扁平项 `goods[dim]` 只作**无州府归属**的残量（如跨府成交未标注来源），总量 = 扁平 + Σ桶。
- **产地决定初始落桶**：某州府产出的料，先落**该州府**的桶（不是按人口摊到全路）。
  现有「按人口拆桶」只在**无产地信息**时兜底（如国家配给）。

### 3.3 流转链条（工坊投料必须走市场）

```
产地(州府A) --supply--> A 的商人/工匠 POP 州府桶
工坊(州府B) --market 撮合 + transport.dispatch--> B 的州府桶（真实付款 + 在途）
工坊消耗州府桶 -> 产出成品入 goods[治所][成品维]
```

🔴 **废除的暗管道**：`WORKSHOP_RECIPES` 的 `grain_feed` 现在是「从 `state.granary` 直扣」
（`settlement_econ.py:1542-1555`），**不付款、不经物流**——这正是你要改的：
工坊买粮必须像其它商品一样**从市场买**，于是它**吃产地分布与运价**，也**付钱给卖方**。

### 3.4 价格发现

全商品进 `dynamic_price`，供需**同域**（同州府的 demand 与 supply），物流费率按距离；
现有 `GOODS_DEMAND` 是**路级**且只覆盖绸/布，须扩到州府级并覆盖 `GOODS_DIMS`。

## 四、🔴 须你裁定的一处硬约束

`AGENTS.md` §3 第 1 条 **POP 挂载律**原文：

> **POP 挂载律**：人（官/吏/宗室/兵/编制）只落 6 类 POP 的 `size`；**钱粮只落 POP `wealth`/`grain`**
> 或国库/内帑；**禁与 POP 平行的账本**；……

按此原文，**粮食住 `pops[].grain`**，而商品住 `pops[].goods`。要让米/麦「作为商品」进市场，
就得让粮住 `goods`（或让 `.grain` 变派生视图），这**与条文里点名的字段不符**。

三种走法，请择一：

| 选项 | 做法 | 影响 |
|---|---|---|
| **甲（改条文，推荐）** | 粮迁入 `goods[治所][米/麦]`，`pops[].grain` 降为**派生视图**（读时求和，不单独记账） | 需同步改 `AGENTS.md` §3-1 措辞为「钱粮只落 POP `wealth`/`grain` **或商品 goods**」；`grain` 87 处 + 太仓 + 守恒重写 |
| **乙（保条文）** | 粮仍住 `pops[].grain`，但**市场与物流对它透明**：撮合/在途/价格照走，只是载体字段不同 | 挂载律零改动；代价是存在**两个载体**（`.grain` 与 `.goods`），访问层要同时懂两者，「单点」打折 |
| **丙（粮为特例）** | 粮只做「州府级细分」（`grain:{米,麦}`）与南北分产，**不进市场** | 改动最小；但违背你「都参与流转」的要求 |

我倾向 **甲** —— 你的目标是「都做为商品、都参与经济流转」，只有甲能让粮与其它商品共用
同一条 `goods[治所][dim]` 通道；而「派生视图」保证不出现平行账本（挂载律的**本意**是
「禁与 POP 平行的账本」，而不是「粮必须住在某个字段」）。

## 五、分批实施顺序（每批可独立验证、独立回滚）

| 批 | 内容 | 不变量 / 验收 | 依赖 |
|---|---|---|---|
| **1** | **商品目录单点**：新增 `GOODS_DIMS`，`米`/`麦` 并入；旧 `RAW_DIMS_14` 的「粮」标注为拆分来源 | 目录唯一、无重复登记；不改任何行为 | 无 |
| **2** | **供给侧全商品化**：`supply_goods_to_seats()` 取代只服务建材的供给钩子，**所有**原料/成品按产地落桶 | 各维 Σ桶 == 供给量；路级总量与批前一致 | 1 |
| **3** | **粮迁移**：`pops[].grain:int` → `goods[治所][米/麦]`；`.grain` 变派生视图；旧档迁移；太仓 `granary` 同步 | 粮总量守恒（迁移前后 Σ 相等）；`grain` 读数不变 | 2 + **§四裁定** |
| **4** | **工坊改市场采买**：`grain_feed` 直扣太仓 ⇒ 改为市场撮合 + `transport.dispatch`，**真付款 + 真实在途** | 钱粮两组 ΣΔ==0；工坊无货时**缺料停产**而非白用；跨府取料须在途 | 3 |
| **5** | **州府级价格发现**：`GOODS_DEMAND`/供给同域扩到州府，覆盖 `GOODS_DIMS`；物流费率按距离 | 供需同域无错位；粮价波动反映产地与运距 | 4 |

⚠️ **批 4 是历史上「收窄版 B」失败之处**（料款与工钱共用出资阶层互相抢钱 / 判定与采购口径分叉 /
失败集合随用例顺序漂移）。相较上次，本批已有三项有利条件：① 州府桶让「有没有到货」可判定；
② `transport` 已提供真实在途；③ 单点访问层杜绝口径分叉。仍须**料款与工钱分腿**并各自断言守恒。

## 六、本方案的边界（不做）

- 不臆造路况（`ROAD_QUALITY` 仍空，耗时按平地常数，**读数自述是设定值非史料**）；
- 不做市场圈派生、断路/改道、季节性封冻（无地理与路况史料，**没有就不做**）；
- 盐/茶/丝/麻等现有产地的**数值**不在本方案改动范围（只改它们的**流转**方式）。
