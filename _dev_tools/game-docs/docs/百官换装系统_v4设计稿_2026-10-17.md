## 0.1 核心机制（先读这一句）

> **人物 = 骨架（坐标/socket） × 脸型 × 五官（眉·眼·鼻·口·耳） × 须发 × 服饰。**
> 七条不变量：I1 同画布零偏移 · I2 脸型与五官共享 socket · I3 脸型不含五官 · I4 空片段合法 · I5 确定性

## 2. 比例系统：一切用头身单位（HU）

### 2.1 定义

- **HU（head unit）** = 头高（发顶 → 颏）。
- 画布 = **4.11H 宽 × 5.71H 高**（比例 0.72，接近 3:4，为展角留出横向余量）。
- 取 **HU = 175px** ⇒ 1x 画布 **720×1000**；@2x 资产 **1440×2000**。
- 换分辨率（例如将来要 4K 展示）只改 HU 的像素值，**锚点与包络全部不变**。

## 3. 管线：3D 母偶 → 固定相机 → 2D 分层（核心）

~~~text
┌────────────────────────────┐
│ 3D 参数化母偶（程序生成）    │  关节层级 + 体型参数（年龄 3 档 × 体态 2 档）
│  · 关节：pelvis/spine/chest/│  姿态：默认站立微侧 6°、双臂持笏（P2 可增）
│    neck/head、clavicle/     │  材质：松烟墨线 + 矿物设色 + 绢底（统一风格）
│    arm/hand、thigh/shin     │
└─────────────┬──────────────┘
              │ 固定正交相机（无透视、固定视距、固定画幅 720×1000@2x）
              ▼
┌────────────────────────────┐
│ 逐件隔离渲染（每件单独一帧） │  只显示该部件 → 全画幅 RGBA
│  跳过深度/遮挡，保留透明通道 │  ⇒ 天然零偏移、天然同源
└─────────────┬──────────────┘
              ▼
┌────────────────────────────┐
│ 产物：parts/*.webp + rig.json + anchors.json + manifest.json
│ 锚点由相机投影自动导出（禁止手填）；manifest 带资产指纹
└─────────────┬──────────────┘
              ▼
┌────────────────────────────┐
│ 运行时 2D 合成（两端同源）   │  Python/PIL：接口、缩略、导出
│ 层序 = z 升序、坐标恒 (0,0)  │  Canvas2D：召对、名册、调试台
└────────────────────────────┘
~~~

**为什么这条路能一次性解决"比例一致 + 同源对齐 + 风格统一"**：
三个问题都来自"每件资产各自为政"。固定相机后，所有部件的坐标系**由相机唯一确定**，
人再怎么画也不可能错位；姿态变化只需换姿势重渲，不与比例耦合。

**3D 母偶规格（首版）**

| 项 | 规格 |
|---|---|
| 关节 | pelvis / spine1 / spine2 / chest / neck / head；clavicle_l·r / upperarm / forearm / hand；thigh / shin / foot（足在画外） |
| 体型参数 | age ∈ {青年, 中年, 老年} × build ∈ {文臣, 武将} = 6 种素体（首版先做 3 种） |
| 面部 | 素模无五官；面部区域留平整"脸床"，供 2D 脸型贴附 |
| 姿态 | 默认微侧 6° + 双手端笏（对应你 10-16 12:03 的"持笏角度微调"） |
| 材质 | 统一墨线粗细、肤色、绢底；**同一材质包渲染全部部件** |
| 相机 | 正交（无透视畸变）、视距固定、画幅固定、像素密度 2x |
| 输出 | (slot, variant, pose) → 一张 1440×2000 RGBA WebP |

## 5. 视觉 DNA 与规制

| 字段 | 来源 | 说明 |
|---|---|---|
| seed | hash(姓名+籍贯+生年) | 稳定；名臣与进士同规则 |
| face/hair/ear/brow/eye/nose/mouth/beard | PRNG + 权重 | 千人千面主体 |
| body | age → {青年,中年,老年} | 与须髯联动 |
| robe/belt/pouch/seal/hu/futou | **品级推导**，恩赏覆盖 | 不是随机项 |
| tilt / flip | 姿态 / 朝堂对坐 | 交互层 |

**规制（可测）**：三品↑紫+金玉带+金鱼袋+象牙笏+长展角；四五品绯+银带+银鱼袋；六七品绿+黑/角带+无鱼袋+木笏+短展角；
青年少须、>60 花白长髯；赐紫/借绯/赐金鱼袋/赐玉带为**覆盖层**；明代补子/龙纹/清红缨/折角帽/京剧靴**一律拦截**。

**组合空间口径（诚实三档）**：理论 ≈ 6(face)×6(hair)×2(ear)×6(brow)×6(eye)×5(nose)×5(mouth)×8(beard) ≈ **5.2×10⁵**；规则可达 10⁵ 量级；**验收看随机 300 人 distinct ≥ 99%**，
不用任何"几千万"的宣传数字。

## 6. 双端合成契约

- manifest（前后端唯一输入）：canvas / HU / anchors / slots[z] / parts(含 sha1 与 bbox) / rules / fingerprint。
- 不变量：① 层序 = z 升序，未选中的可关槽位不参与；② 每层坐标恒 (0,0)，**运行时禁止平移/缩放/旋转**；
  ③ 翻转 = 整幅水平镜像；④ 缺件抛错；⑤ 同 DNA 双端像素差均值 < 2/255。
- 缓存键 = DNA hash（含部件 id、tilt、flip、age_group、恩赏覆盖键）——评审曾指出旧实现漏键导致陈旧图。

### 8.0 质感路线结论（2026-10-17 实测）

AI 工笔母版切件实测：**衣料/冠帽可用，脸与五官分件不可行**（模型无像素级锚点约束、素脸被加回五官、眼件带眉、肤色光晕）。
详见 [sz/_dev_tools/paperdoll_experiment/QUALITY_PILOT_2026-10-17.md](../../_dev_tools/paperdoll_experiment/QUALITY_PILOT_2026-10-17.md)。

**第二轮（2026-10-17 晚）追加结论**：用户指出"母版手的大小不合比例"且"整幅母版=一人一图"，与"零件复用"目标直接矛盾。
⇒ 路线收敛为：**几何/比例由程序定，只有材质交给 AI**。
具体：**程序化 2.5D 参数人偶（头身/肩宽/腰 200px/手长全部参数化）+ AI 材质贴图（布纹/肤色/发丝/绢底）+ 统一墨线描边**；
3D 母偶作为后续升级（本机当前无 Blender，已实测）。B（整脸不可拆）降为备选。

### 8.1 风格锁（R16）与部件独立（R17）

**风格锁** = 一份数据文件 [`sz/_dev_tools/paperdoll_experiment/spec/style.pack.json`](../../_dev_tools/paperdoll_experiment/spec/style.pack.json)，
所有部件**只允许**按它渲染，偏离即判不合格（断言 A25）：

| 维度 | 锁定内容 |
|---|---|
| 墨线 | 铁线描 · 墨色 #2A2320（禁纯黑/禁发光）· 线宽 **4px @2x（2px @1x）±1** |
| 调色板 | 肤色 / 白中单 / 紫绯绿青袍 / 革带 / 金玉 / 象牙木笏 **共 14 色**，部件色彩必须落在该色集（ΔE 阈值） |
| 绢底与肌理 | 统一绢本底 + 肌理强度 0.16（禁纯平涂无肌理） |
| 光照 | 左上 45°、低反差（禁强高光/硬投影） |
| 合成 | 二元 alpha 或 2–3px 窄过渡（禁大面积渐变、禁半透明叠加、禁投影层） |

**部件独立** = 每件必须能**单独导出、单独替换、单独验收**（断言 A26/A27）：

- 一件只占一个槽位；**禁止合成件**：袍+带、脸+五官、帽+发 一律不许出现在同一张图；
- 单件渲染必须非空、bbox 必须落在 §8 自己的包络内；
- **跨槽位零烘焙重叠**：袍层不得在五官区域有像素、帽层不得画进脸、须不得画进口；
- 单件导出命令：`python -m paperdoll render --single robe:robe_03_purple -o out/robe.webp`（P0 提供）。

> 这两条是把"贴纸感"挡在门外的关键：**风格锁管"像不像同一个画师"，独立性管"能不能单独换"**。

## 12. 验收（你能逐条打勾）

5. 帽檐/发际/眉/眼/腰/膝六条线肉眼对齐；
6. 资产 68 件（或 13 件最小版）全部来自母偶渲染，**零旧图**；
7. 旧三代资产**全部下线**；
8. **风格统一**：随机抽 10 件与母版并排看，墨线粗细/色感/绢底是同一套（A25）；
9. **部件独立**：任一件单独导出都能正常显示，且换任意一件都不牵连其它件（A26/A27）。
