## 一、总原则

1. **半 V3 化（v4 修正表述）**：**农业就业不市场化**（农不领工资，自种自留口粮），
   但**粮食完全市场化**——非农（工匠/商人/官僚/兵）的口粮**必须购买**，农的余粮是其
   收入来源。v3 曾误写"非农自带口粮"，既非史实也非本意，**以此条为准**：
   半 V3 的"农业自给"指**生产者自己的口粮自给**，不是全社会的口粮自给。
2. **粮 = 硬通货（✅用户修正，v4 新增）**：粮在古代是准货币（本色饷俸、赃罚折粮、以粮易钱）。
   设计体现四点：① 本色兵粮/官禄米（粮直接发饷）；② 民间"粜粮完税"（缺钱先卖粮换钱，
   镜像宋农税通道）；③ 官仓平粜（价高放粮、价低籴入，外邦版常平）；④ 粮的**计价位**
   （审计与面板上按当期粮价折贯展示，**不并入货币存量**，防双计）。
3. **外邦经济闭合（✅用户修正，v4 新增）**：辽/夏/大理有**完整的财政收支闭环**——
   税收（农税本色粮+工商钱税）+ 岁币入，支出（兵粮本色+军饷折色+禄米本色+官俸折色+
   官运费+营造+救济）出，**两个池子（treasury 钱池 / 官仓粮池）各自闭合**，
   不靠岁币单向输血（岁币只是外源增量，不是循环本身）。
4. **POP 挂载律**（既有硬约束）：凡"人"落六类 POP `size`；凡"钱"落 POP `wealth`／国库；
   禁建与 POP 平行的存量账本。新增实物仓（原料/官仓粮/goods）只能挂**州/府**或**政权级**
   且**仓里只有实物、不走钱**。
5. **单一真账**：同一实物一个权威账；同一商品一个产出通道。
6. **产出挂州/府**（✅已拍板）：产量与库存以州/府为单位；两级仓（州/府仓 ↔ 政权仓），
   **不设省级中间层**。
7. **建筑是岗、POP 是工**（✅已拍板）：等级定岗位数，在岗人数定产量；
   **粮维豁免岗位制**（v3）：粮是农的生计产物（全员有效不占岗），其余 13 维走岗位轨。
8. **去建筑折旧**（✅已拍板）：等级不随时间衰减，只随省政兴衰与就业状况升降。
9. **物流成本是钱、跟距离地理相关**（✅已拍板）；**民间/政府双账隔离**（✅已拍板）。
10. **一切改动配守恒断言并进回归**（既有纪律）。

## 三、建筑-岗位-就业模型（核心）

### 3.1 建筑类型（6 类）

| 建筑类型 | 承载 | 在岗 POP | 备注 |
|---|---|---|---|
| 粮田 | **只做粮的效率乘数**（不占岗） | —（全体农生计） | 等级→单位产量加成 |
| 桑麻田 | 麻、丝 | 农 | 经济作物 |
| 林果蔗田 | 木、石、果、蔗 | 农 | |
| 牧场 | 牲畜、马、药材 | 农 | 药材归牧/采集 |
| 矿场 | 金、铁、铜、银 | **工匠** | 冶采 |
| 工坊 | 成品 12 类 | **工匠** | 成品**唯一**产出通道 |

> "商铺"作流通设施（本省物流费率×0.9/成交上限↑）🟡待确认是否纳入。

### 3.2 产出口径：两轨制（v3 定，v4 补余粮商品化）

**轨 A——生计轨（粮，全员有效，不占岗）**：

```
粮食月产 = 农 POP size × PER_CAPITA_GRAIN[type] × 粮田效率乘数(1+0.05×(lv−1))

农的粮食处置（v5 修正：「一年口粮 + 种粮」储备制，余粮才出售）：
  ① 本月口粮      = size × 月口粮率                        → 直接消费
  ② 储备补充      = max(0, 一年口粮额 − 当前 grain 存量)     → 留仓不售
                    （一年口粮额 = size × 月口粮率 × 12）
  ③ 种粮预留      = 播种月预留 SEED_GRAIN（🟡对齐宋 SEED_GRAIN_PER_MU 口径，按 type）
  ④ 余粮出售      = max(0, 月产 − ① − ② − ③)               → 省域粮市供给池
                    售出得钱 → **农 POP wealth**（农的收入来源）
```

- **这才是农有钱的机制**：农不领工资，其现金收入＝卖余粮＋经济岗工资（§3.6）；
  有余粮才卖、无余粮不卖（灾年自动断供，无需额外规则）；
- 储备制让农有**抗灾缓冲**（一年口粮）——灾月不卖粮也不饿死，与宋农"常余终岁之资"的
  形态一致；储备耗尽仍遇灾 → 才进入饥荒/逃荒通道（既有机制）；
- **粮维豁免岗位的理由不变**（否则失业农无岗即无粮=结构性饥荒），
  但"豁免占岗"≠"豁免市场化"——余粮商品化正是农的现金流入口。

**轨 B——岗位轨（其余 13 维原料＋全部成品）**：

```
岗位数 jobs[bt]    = lv[bt] × JOBS_PER_LEVEL[bt]
在岗数 staffed[bt] = min(jobs[bt], 分配给该建筑的 POP 人数)
月产[维 r]         = Σ_bt staffed[bt]→r × PER_WORKER_OUTPUT[type][r] × (1 + LV_OUTPUT_BONUS×(lv−1))
```

### 3.3 就业分配：优先队列（口粮已豁免，只剩经济岗）

```
农职岗序：牧场 → 桑麻田 → 林果蔗田
工匠岗序：工坊 → 矿场
分配：按岗序顺序填满；同月内不重复计入
```

- 经济岗竞争农的**剩余劳动力**（口粮之外可投入的劳动，上限按 `JOB_SHARE[type]`）；
- 余工 → **失业人口**（派生读数）；
- 上岗人数是月度视图，不改 POP `size`。

### 3.4 建筑等级演化（✅去折旧）

```
升级：省域上月「财政结余 = 税入 − 饷出 + 营造支出回流」> 0 且 当月无饥荒
      → 月 5% 概率择一类 lv+1（封顶 5）
降级（主动事件，非时间衰减）：
      ① 灾荒命中 → 随机一类 lv−1
      ② 欠饷（arrears>0）→ 牧场/工坊优先 lv−1
      ③ 持续空置（在岗率 < 40% 连续 3 月）→ 该类 lv−1
节流：同一州/府同月最多 1 次降级事件
审计：econ_audit["building_lv_changes"] = [{省, 类, Δlv, 原因}]
```

### 3.5 建筑营造费与出资（外邦禁 burn）

```
升级费 = BUILDING_COST[bt] × BUILDING_COST_GROWTH^lv
出资：1) 本省 士绅 POP wealth；2) 不足 → 政权 treasury 补（宋：国库）
外邦/宋统一：营造费全额**转给出资工程的工匠 POP wealth**（含 treasury 补出部分），
             不得注销/burn（外邦唯一货币源禁抽水，§4.4）
```

### 3.6 就业驱动的阶层流动（✅用户拍板的落地条款）

```
每月末：
 失业农（未进任何经济岗）→ 月 2% 迁 工匠/商人（若该省有空岗）
 失业工匠（未进工坊/矿场）→ 月 2% 迁 农（**生计兜底：回农即回口粮轨**）
约束：Σ六类 size 守恒（整数尾差归迁出方）
读数：audit {"flow_out": n, "flow_in": m, "unemployed": k}
```

- **回农兜底是安全阀**：非农无生计产粮，失业工匠若不能回流农轨领口粮，只能买粮——
  钱花光即饿死（这是允许的真实压力，但必须有回流通道兜底）。

### 3.7 农的三层结构：自耕农 / 佃农 / 隐户（✅用户修正，v5 新增）

农 POP **不是均质整体**——宋既有土地口径已经把田分成自耕田/地主田/官田/皇庄/隐田
（`self_farm_land`/`gentry_land`/`official_land`/`imperial_land`/`hidden_land`），
农按"种谁的田"分三层（对应三种国民身份与经济地位）：

| 层 | 占农 POP 比例（🟡初值） | 土地关系 | 产出归属 | 税负结构（✅用户修正） | 余粮处置 |
|---|---|---|---|---|---|
| **自耕农** | 0.55 | 自有田（自耕田） | 全产归己 | **无地租**，但有**国税＋摊派**（田赋正税＋徭役/科配，按自有田亩征） | 留一年口粮+种粮后**正价出售** |
| **佃农** | 0.33 | 佃种士绅/官僚田（地主田） | **主佃对半分成**（宋既有口径：`_settle_economy` 地主田产 佃户半+士绅半） | **无国税、无摊派**，但有**地租**（即主佃对半分成中被田主取走的那一半——田主代纳土地税） | 就自己半分处置（留口粮后出售） |
| **隐户** | 0.12 | 不籍于官（隐田） | 全产归己但不登记 | **不纳税、不应役**（逃籍） | 暗市出售，折价 70%（无市籍壁垒） |

- **子池口径（POP 挂载律合规）**：农 POP 挂 `{"自耕农": n, "佃农": m, "隐户": k}` 子池，
  恒等式 `自耕农+佃农+隐户 == size`（同官僚 POP 的 `officials/clerks` 子池先例）；
  面板/审计可分层读数，**不建平行账本**；
- **收入分层是消费分层的基础**：自耕农 > 佃农 > 隐户 的收入差 → 商品消费率分层
  （自耕农买布、佃农买少量、隐户几乎不买），消费结构自然分层；
- **税负的两个方向**（✅用户修正）：自耕农"有国税无地租"、佃农"有地租无国税"——
  同亩产量下**自耕农税痛感更直接**（官府正税+摊派全额落自己头上），
  这是"税重→逃籍"的源逻辑（自耕农最易滑向隐户）；佃农税负隐于租中，
  税加重时田主先转嫁（租率上升）→ 逼佃农也逃籍；
- **隐户是阶层下滑的终点通道**（与 §3.6 的就业驱动力方向相反）：
  税重/灾荒/苛敛时 → 自耕农/佃农流入隐户（逃籍）；清丈/轻徭时 → 隐户归籍复业
  （镜像宋隐户口既有动态：`_settle_hidden_pop` 的"在籍→隐户/隐户→在籍"双通道）；
- **州/府级土地结构**（🟡初值，按 type 分化）：
  游牧帝国 自耕田 0.50/地主田 0.30/官田 0.08/隐田 0.12；
  党项蕃国 0.45/0.35/0.08/0.12；西南属国 0.60/0.20/0.10/0.10；
- **宋侧直接复用**：宋已有全部五个土地键与对半分成、本色征收、隐户通道——
  外邦三层结构就是把宋的成熟口径**下沉复制**到外邦（同一套公式，两层规模）。

**三层 × 钱粮流（闭合的关键一环）**：

```
自耕农：全产归己 → 留一年口粮+种粮 → 余粮正价出售（钱入农POP）
        → 但承担 国税(钱+本色)+摊派（钱入treasury、本色入官仓）
佃  农：主佃对半分成 → 自留半分（留口粮）→ 余粮正价出售（钱入农POP）
        → 无国税/摊派，地租即对半分成中被田主流走的那一半
田  主（士绅/官僚）：收佃租半分（grain 或折钱）→ 代纳土地税（钱入treasury）
隐  户：全产归己 → 暗市售粮（折价70%）→ 不纳税不应役（收入最低但无税痛）
```

### 4.3 金属 ≠ 钱（边界声明）

金/银/铜/铁是实物存量，与"贯"不得自动折算：
唯一合法兑钱通道是**显式配方**（如大理铜+锡→币材折价入 treasury，熔耗 20%）；
银器/金器是消费品走市场；**禁止"仓里有银→自动加 treasury"**。

### 4.4 外邦财政闭合与货币源（v4 重写：闭合≠外源）

**外源（货币唯一源头）**：

```
外邦货币外源 = 岁币（辽 15k + 夏 10k/月，attitude≥60）＋（🟡可选铸币配方：铜→币材，熔耗 20%）
```

**闭合（内部循环，不创造货币，但让钱转起来）**——完整收支表：

| 方向 | 项目 | 载体 | 对手方 |
|---|---|---|---|
| 入 | **自耕农国税**（钱） | 自耕农POP wealth → treasury | 田赋正税（只征自耕田） |
| 入 | **田主代纳土地税**（钱） | 士绅/官僚POP wealth → treasury | 地主田之税（佃农不直接纳） |
| 入 | 本色粮税 | 自耕农POP grain → 州/府官仓 | 田赋本色（只征自耕田+官田） |
| 入 | 工商税 | 工/商POP wealth → treasury | — |
| 入 | 士绅税 | 士绅POP wealth → treasury | — |
| 入 | 岁币 | 宋 → 外邦 treasury | 外源 |
| 循环 | **地租（佃农→田主）** | 佃农POP grain/wealth → 士绅/官僚POP | 主佃对半分成中田主所得（§3.7） |
| 出 | **兵粮（本色）** | 官仓 grain → 兵POP | 硬通货发饷（v4 新增） |
| 出 | **军饷（折色）** | treasury → 兵POP wealth | — |
| 出 | **禄米（本色）** | 官仓 grain → 官僚POP | v4 新增 |
| 出 | 官俸（折色） | treasury → 官僚POP wealth | — |
| 出 | 官运费 | treasury → 起运州/府工匠/商人 POP | §9.3 |
| 出 | 营造款 | treasury|士绅 → 工匠 POP | §3.5 |
| 出 | 灾年救济 | 官仓 grain／treasury → 灾省 | 饥荒月 |
| 循环 | **非农购粮** | 工/商/官/兵POP wealth → 农POP／官仓 grain | §6.4 |
| 循环 | 民间商品 | 各POP wealth → 工匠/商人 POP | §6.1 |
| 循环 | 民间运费 | 买家POP wealth → 货源省商人 POP | §9.2 |
| 循环 | 营造回流 | 工匠POP wealth →（消费 goods/缴税） | §3.5 |

**闭合断言**（§10.1 表格化）：

```
Δtreasury == (自耕农国税 + 田主代纳土地税 + 工商税 + 士绅税 + 岁币) − (军饷+官俸+官运费+营造补款+救济折色)   [钱池]
Δ官仓粮   == (本色粮税 + 平粜籴入) − (兵粮+禄米+作坊耗粮+官运出粮+救济+仓耗)                              [粮池]
Δ外邦货币存量 == 岁币(+铸币)                                                                              [总量只随外源]
Σ地租     == Σ田主从地主田分成所得                                                                          [主佃对半守恒]
```

> **摊派**（✅用户修正口径）：只落**自耕农**（徭役/科配按自耕田亩派），
> 折算 `apportion[type]` × 自耕农 wealth（🟡参数 20，初值 0.2% 财富/月）或折实物。
> 佃农无国税无摊派（税负已含在地租内）、隐户两项皆无。

- **两个池子各自闭合**：钱池（treasury）与粮池（官仓）都有出有入，缺一即"输血型/枯竭型"经济；
- v3 只有税入+军饷官俸两笔，"闭合"空转——v4 补本色兵粮/禄米/救济/购粮回路、
  v5 补农三层税负结构（自耕农纳税/佃农交租/隐户两无）后真正闭环；
- treasury 单调累积（现探针辽 300 万）＝ 闭合未成；闭合后应由"建设+军费+购粮回流"摊薄。

## 六、V3 式雇佣/发薪/利润/倒闭 ＋ 粮食市场化（v4 修正 §6.4）

### 6.1 雇佣与发薪

```
建筑营收 revenue = Σ(卖出商品量 × 当前市场价)
工资池 wages      = min(revenue, Σ(在岗工 × 工资率[type][岗位]))
发薪：按在岗比例分给 农/工匠 POP wealth（只有上岗者分）
欠薪：记 arrears_building，在岗工只拿实发
```

- 买家付款**先进建筑营收**再发薪分利（替换现 7/3 分账）；
- 商人保留：**运费收入**＋**利润分成**（🟡待定比例）。

### 6.2 利润 → 士绅 → 扩建

```
利润 = revenue − wages − 建筑承担运费 → 本省 士绅 POP wealth
士绅财富 ≥ 升级费 且 满岗 → 出资升级
```

### 6.3 轻量倒闭（✅已拍板）

```
连续 2 月 arrears_building > 0 → 强制解雇 20% 在岗工 ＋ lv−1
lv=0 且欠薪 → "closed"（岗位 0）
恢复：省域结余＋无欠薪 → 士绅可重新出资 → lv1
```

### 6.4 粮食市场化（v4 重写：v3"非农自带口粮"作废）

```
非农口粮来源（硬性）：工匠/商人/官僚/兵的月度口粮**全部从省域粮市购**，
   POP 存量 grain 仅作 1–2 月缓冲；缓冲耗尽仍买不起 → 饥荒（unrest↑，毋须新机制）
卖方（按序）：① 农 POP 余粮（轨 A 商品化部分，钱入农 wealth）
             ② 州/府官仓（平粜价，钱入 treasury 或 local_treasury）
             ③ 政权仓（跨州/府调入后进省域粮市供给池）
工资的意义：非农工资的第一用途是**买粮**，其次买 goods、缴税——
   这就是"粮是硬通货"在经济结构里的位置：非农的一切收入先过粮这一关
```

- **农 = 余粮卖方**：农不领工资，其现金收入来自卖余粮＋经济岗工资（§3.6 流动后的农也可能上岗）；
- 这正是半 V3 与全 V3 的边界：**农不领工资**（就业不市场化），但粮食完全市场化；
- 与外邦既有实现的关系：`_ext_econ_phases` Phase C 的"缺口购买"制**就是要保留并强化的口径**，
  v3 的"自带口粮"表述与实现相反，以此条为准；
- 破产压力：非农买不起粮 → 饥荒 → 阶层流动（回农）→ 结构再平衡。允许，不兜底。

### 6.5 本色饷与禄米（v4 新增：硬通货发饷）

```
兵粮（本色）：月额 = 兵 POP size × 军粮率[type]（🟡初值 1.2 石/兵/月）
              从州/府官仓拨 → 兵 POP grain；官仓不足 → 按实拨，缺口记 arrears_grain
禄米（本色）：月额 = 官僚 POP size × 禄米率[type]（🟡初值 1.5 石/官/月）
              从州/府官仓拨 → 官僚 POP grain
折色（钱）：  军饷/官俸照旧从 treasury 发（§6.1/既有）
```

- 本色+折色并行 = 史实俸饷结构，也让官仓粮池有明确出口（闭合的一环）。

### 6.6 官仓平粜（v4 新增：外邦版常平）

```
省域粮价 > 平粜上线（🟡基准价×1.5）→ 官仓放粮 min(库存 20%, 缺口) 入省域粮市供给池（低价成交）
省域粮价 < 平粜下线（🟡基准价×0.7）→ treasury 籴入（高收储，钱 → 卖方农 POP）
目的：抑制粮价极端波动（硬通货价格失控 = 社会失控），同时给官仓吞吐一个市场回路
```

## 七、粮的双角色与官仓（守恒公式的前提）

```

```
ΔPOP粮   == 轨A总产 − Σ口粮消费 + 跨省粮调入 − 跨省粮调出 − 本色税粮出 − 余粮市场净出 + 本色入账 +市场净入   [恒 0]

```

## 八、动态价格（✅已拍板）

```
