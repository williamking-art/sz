## 2. 判据：什么才算"事实扩展点"

一个位置只有同时满足三条才进本清单（否则只是"内部函数"）：

1. **有稳定接口**：注册表 / dataclass / 文档化签名的函数，**外部只需提供数据或回调**，不必改宿主逻辑；
2. **接线成本可估**：实际改动 ≤ 1 个文件 + ≤ 50 行，且**不需要动结算顺序、守恒通道、存档 schema**；
3. **有或能有守卫**：加错了能被测试抓到（注册表拼写、面板 kind 缺失、效果路径越界）。

> 反面例子（**不算**扩展点）：`core/settlement_econ`（34 个出依赖的大杂烩）、
> `backend/server.py` 的 22 个直连（薄壳越界，见耦合报告 §6.3）——它们是"待拆"而不是"待插"。
