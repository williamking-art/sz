# 主要国家 / 外邦 设定分层（2026-10-05 用户裁定）

> **用户裁定**：「辽宋夏大理朝鲜日本这种算**主要国家**的设定要**一致**，其他外邦可以简化」；
> 追加：「**吐蕃不算**主要国家」「**底层一样**，但各国**文化不同，阶层、派系肯定都不一样**」。

---

## 一、判定原则

| 层级 | 名单 | 设定要求 |
|---|---|---|
| **主要国家** | **宋 · 辽 · 西夏 · 大理 · 高丽 · 日本**（6 个）| **底层一致** + 各自完整的**阶层/派系/文化** |
| **外邦（简化）** | 吐蕃 · 琉球 · 安南 · 占城 · 真腊 · 蒙古诸部 · 女真诸部 · … | 可简化（沿用类型模板）|

⚠️ **吐蕃虽是大地域、且在图上有名**，但按裁定**属简化外邦**（非统一政权）。

## 二、两层架构（🔴 核心概念）

```
┌─ 底层（主要国家之间**一致**）─────────────────┐
│  字段集 / 结算模型 / 口径                          │
│  · 建筑-岗位-就业（生产轨）                        │
│  · 产出/消费/价格/税基/家计                        │
│  · 月度结算流水线、守恒与对账恒等式                │
│  ⇒ **同一套模型，只是数值不同**                    │
└──────────────────────────────────────────────┘
                      ×
┌─ 差异层（**各国不同**）──────────────────────┐
│  · **阶层**（POP 类别）                            │
│  · **派系**（政治派系）                            │
│  · **文化**（礼制/习俗/名号）                      │
└──────────────────────────────────────────────┘
```

### 参照：宋侧现状

```
POP_CLASSES = ("\u519c", "\u58eb\u7eb3", "\u5546\u4eba", "\u5b98\u50da", "\u5175", "\u5de5\u5320")
```

⇒ 宋的 **6 类阶层**是**宋的差异层**，**不是底层**。
辽（游牧/部族）、西夏（党项）、大理（西南）、高丽、日本**各自应有自己的阶层表**。

## 三、🔴 现状差距（违反该原则）

### 3.1 所有境外政权挤在一张扁平表

`content/data_external.py: EXTERNAL_REGIMES` —— 每个政权只多一个**类型标签**：

```
"辽":   _ext("辽",   "游牧帝国", ...)
"西夏": _ext("西夏", "党项蕃国", ...)
"高丽": _ext("高丽", "东方藩属", ...)
"日本": _ext("日本", "海东岛国", ...)
"大理": _ext("大理", "西南属国", ...)
"吐蕃": _ext("吐蕃", "高原诸部", ...)     ← 外邦（按裁定）
"琉球": _ext("琉球", "海岛番社", ...)     ← 外邦
```

### 3.2 产出/消费表**按「类型」索引，不按「国家」**

`PER_WORKER_OUTPUT` / `JOB_SHARE` / `RAW_YIELDS` / `grain_yield` **只有**：

```
游牧帝国 / 党项蕃国 / 西南属国 / default
```

⇒ **主要国家没有国家级设定**：

| 国家 | 实际落到 |
|---|---|
| **宋** | `default`（**连类型都没有**）|
| **辽** | `游牧帝国` 模板 |
| **西夏** | `党项蕃国` 模板 |
| **大理** | `西南属国` 模板 |
| **高丽** | `东方藩属` —— 该类型**在产出表里不存在** ⇒ 落 `default` |
| **日本** | `海东岛国` —— 同上 ⇒ 落 `default` |

**⇒ 主要国家与小国用同一张简化表，而主要国家「该有的那套」根本不存在。**

### 3.3 已区分「主要势力」，但只是**显示标志**

```
content/data.py: EXTERNAL_ALWAYS_SHOW = {"辽", "西夏", "吐蕃", "高丽", "日本"}
```

⇐ 这是**舆图显示**用的，**未对应到设定层级**。
⚠️ 注意它含**吐蕃**、不含**大理** —— 与本次裁定**不一致**，需另行处置（见 §五）。

## 四、目标架构

```
REGIME_PROFILES = {
    "\u5b8b": {...},   "\u8fbd": {...},  "\u897f\u590f": {...},
    "\u5927\u7406": {...}, "\u9ad8\u4e3d": {...}, "\u65e5\u672c": {...},
}
```

每个 profile 含**两层**：

| 层 | 字段 | 是否各国一致 |
|---|---|---|
| 底层 | 建筑/岗位/产出/消费/价格/税/家计 的**字段与模型** | ✅ 一致（数值不同）|
| 差异 | `pop_classes` / `factions` / `culture` | ❌ **各国不同** |

**外邦**继续走类型模板（现表保留作简化层）。

### 纪律

- 🔴 **主要国家不得落 `default`** —— 缺失应**显式报错**（承 §3-3「缺失≠0」），
  不得静默套用简化模板（现状 `宋`/`高丽`/`日本` 正在犯此错）；
- 新增主要国家 ⇒ 必须同时给出 `pop_classes` 与 `factions`，**不得只给数值**。
