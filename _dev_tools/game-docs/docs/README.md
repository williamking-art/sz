## 维护约定（防再次膨胀）

- 只有标 **现行** 的文档可写“当前如何工作”；设计/依据不复制成现行口径；
- 实现细节/批次号/审查过程 → `specs/`、`analysis/`、`archive/`；
- 新增机制先更新 [`游戏机制说明.md`](游戏机制说明.md) 对应小节 + 链接，不把完整设计稿复制进主文档；
- 旧版不追改，统一进 `archive/` 并在主文档顶部标注；
- 主文档目标 **≤300 行**；超过时优先拆专题。
