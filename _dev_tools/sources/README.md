## `songshi/` 说明

**原文件**：`songshi_085.txt` ～ `songshi_090.txt`（维基文库 raw 文本，含 `{{}}` 标记需清理）。
⚠️ 该批为**四库全书本/异本**，条目较简；**完整正文**以工作区 `_scratch/song86~090.txt`（简体全）为准。

**派生数据集**：`gong_prefecture.json` —— 从《宋史·地理志》正文抽取的**州府级贡物**：

```
[ { "vol": "086", "circuit": "河东路", "seat": "xxx州", "goods": "人参、蜜、墨" }, ... ]
```

- **规模**：195 条 / 210 种物产 / 覆盖 17 路（成都府路35·河东29·荆湖北24·江南东14·福建11·广南26…）；
- **粒度**：**州府级**（`贡` 紧随某府/州的户口数之后），非路级；
- **用法**：G-2「按产地落州府桶」与 G-6-L3「治所级 yields 差异化」的**史料依据**。

## 纪律

- 本目录**只增不改**：史料原文不可编辑，派生数据如需修正应重跑抽取脚本并说明口径；
- 引用时**必须注明卷次**（如「《宋史·地理志》卷86 河东路」），便于复核；
- 抽取脚本与中间产物在**工作区外**（`D:\codebuddy\_scratch`），不入库。
