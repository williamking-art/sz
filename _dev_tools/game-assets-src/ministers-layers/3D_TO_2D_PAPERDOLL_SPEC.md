# 北宋官员公服 RPG 3D转2D骨架对齐与多年龄多动作布娃娃规范全案

> **归属工程**：《宋祚》官员多脸谱与可复用公服 RPG 美术资源框架  
> **核心规范**：3D 角色骨骼/姿态规范（Rigging Anchors） $\rightarrow$ 院体工笔设色 Shader / AI ControlNet $\rightarrow$ 2D 绢本肖像（`810 × 1080`，3:4 比例，老绢底 `#C4A877`）。  
> **核心价值**：所有布娃娃在统一 3D 骨架下生成，透视与锚点绝对统一，装备层（官袍、幞头、革带、鱼袋、朝笏）可以作为通用透明切片无缝穿戴在任意同姿态布娃娃上，杜绝任何穿模与错位。

## 三、 3 大年龄层 × 多样化气质布娃娃矩阵（Dolls Matrix）

### 3.1 青年层（20~35 岁 · 少壮及第）
- **形象定位**：新科状元/及第进士、青年知县、县丞、主簿、初仕清流；
- **面相选择**：
  - `doll_y_scholar`：清秀修竹，玉面无须，儒雅英挺，书卷之气；
  - `doll_y_resolute`：英武方额，目如朗星，少年意气，刚毅敢为；
  - `doll_y_pragmatic`：朴厚精整，端庄稳重，循序渐进。
- **动作优选**：`pose_chihu`（殿试持笏）、`pose_gongshou`（见师拜揖）。

### 3.2 中年层（36~50 岁 · 骨干中坚）
- **形象定位**：知州知府、各路提刑转运监司、六部侍郎、御史知院；
- **面相选择**：
  - `doll_m_slender`：清瘦刚直，双眸如炬，蓄文人短髭，铁骨御史；
  - `doll_m_square`：方阔重颌，浓眉直鼻，蓄刚正美髯，经略帅臣；
  - `doll_m_round`：丰腴温润，耳大颐满，蓄精修短髭，财赋度支官；
  - `doll_m_counselor`：眉清目秀，深思熟虑，纵横机变谋士。
- **动作优选**：`pose_chihu`（持笏视事）、`pose_fuxu`（筹算国策）、`pose_anjian`（边防帅意）。

### 3.3 老年层（51~75+ 岁 · 耆宿元老）
- **形象定位**：中枢宰相、执政知院、致仕名公、三朝宿老知州；
- **面相选择**：
  - `doll_e_veteran`：苍老清癯，额刻沧桑，长髯飘逸雪白，一代宗师；
  - `doll_e_round`：雍容从容，天庭饱满，三绺花白美髯，元老宰辅；
  - `doll_e_iron`：白发苍苍而目光如铁，老当益壮，百战宿将。
- **动作优选**：`pose_longxiu`（宰相长袖垂立）、`pose_fuxu`（老谋深算）、`pose_gongshou`（老成持重）。

## 四、 3D 转 2D 渲染管线（Blender / ControlNet Shader）

1. **几何体与光影标准**：
   - 模型使用宋代标准身材人形，中单内衬白绢，顶束发髻；
   - 采用正面偏右 5 度的经典宋画正面微侧视角（四分之三正面）；
   - 灯光采用漫射平光（Diffuse Ambient），模拟北宋院体工笔无强阴影、重固有色与白粉提亮的设色法；
2. **线条与材质渲染（NPR / Gongbi Cel-Shading）**：
   - 提取模型轮廓线（Outline）与主要骨骼结构线，转为宋画铁线描与兰叶描；
   - 贴图叠加天然微颗粒古老绢本底纹（`#C4A877`）；
3. **装备透明贴图分层输出**：
   - 外袍、幞头、革带、鱼袋、朝笏分别在 3D 软件中以独立 Object 开启透明通道（RGBA），分层渲染并导出为透明 PNG；
   - 运行时由游戏引擎在布娃娃素体上依品级直接叠加 Alpha 合成。
