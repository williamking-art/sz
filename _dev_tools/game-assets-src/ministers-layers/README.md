# ministers-layers · 大臣立绘分层管线

> 层归属：**开发工具**（资产生产管线；运行期不依赖本目录）。

## 关键内容
| 文件/目录 | 说明 |
|---|---|
| `PORTRAIT_PIPELINE.md` | **管线规范**：分层体系、命名、规格（810×1080、3:4）、验收标准 |
| `_lay2.py` | 分层合成脚本（头层 + 身体层 → 组合立绘） |
| `_src/` | 源图（未裁切的原始素材） |

## 为什么分层
官级会变（升贬换服色），人脸不会变 → 换官服只是一次贴换，无需重画整张。
运行期由 `game/core/minister_profile.py::compose_portrait` 按 `game/content/ministers/layers/` 合成，
成品缓存到 `_composed/`（按需再生、不入库）。
